# 第一部分：离子推力器

## 一、离子推力器概述

### 1.1 定义与地位

离子推进是电推进中的主流技术路线，是目前仅有的得到较多应用的几种电推进方式之一（其他包括霍尔推进、电阻式推进、Arcjet、PPT）。离子推进已逐步成为长寿命通信卫星的标准配置和深空探测航天器的必需技术。

离子推力器的核心特点：

| 特性 | 数值/描述 |
|------|----------|
| 比冲 | 超过 30,000 m/s，除微推进外是目前比冲最高的电推进方式 |
| 推力 | 几十 mN 量级（小推力） |
| 寿命 | 可达上万小时 |
| 结构复杂度 | 结构和配电系统复杂 |

### 1.2 分类与基本组成

离子推力器按产生等离子体的方式分为三类：

1. **电子轰击式（直流放电式）**：利用空心阴极发射的电子碰撞推进剂原子使之电离。
2. **微波电子回旋共振式（ECR）**：采用处于磁场中的微波来产生等离子体。
3. **射频式（RF Ion Thruster）**：利用射频线圈产生的感应电场电离工质气体。

离子推力器由三个主要部分构成：

1. **放电室**：产生等离子体。
2. **光学系统（栅极）**：将离子从等离子体中引出并加速。
3. **中和器**：离子被加速到所要求的速度后，中和器发射等量的电子到离子束中，使航天器表面呈电中性。

## 二、离子推力器工作原理

### 2.1 电子轰击式（直流放电式）

**工作原理**：在离子源内由空心阴极发射的电子碰撞推进剂原子使之电离，被电离的离子由离子光学系统引出加速产生推力。

**核心构件**：
- 放电阴极（空心阴极）：发射电子
- 离子光学系统（栅极）：引出并加速离子

**特点**：
- 需要放电阴极（空心阴极）
- 需要磁场
- 效率高，效率随尺寸的增大而增大
- 电源数量多（需要多路直流源）
- 使用直流源，电能易传输，能量损失小
- 性能难预测

### 2.2 射频式（RF Ion Thruster）

**工作原理**：基本构件包括一个由射频发生感应线圈缠绕的放电室（由石英或氧化铝制成）、两或三个栅极系统用作离子光学引出，以及一个中和器。射频线圈在放电室内产生感应电场，通过电感耦合产生并加速电子，之后高能电子电离工质气体的中性粒子，得到可用来产生推力的离子。整个离子化过程中不需要电极提供电子来维持放电。

**电感耦合放电机制**：把射频功率输入到非谐振感应线圈，通过电感耦合将能量输送给等离子体。当线圈中加上射频电流时，通过石英玻璃介质窗在反应器真空室内产生射频交变磁场。根据法拉第定律，交变的磁场又会感应出交变的电场，从而使气体电离产生等离子体。该装置内无电极，不需要外加磁场。

**特点**：
- 不需要放电阴极，无阴极腐蚀
- 不需要磁场
- 效率稍低，效率随尺寸的增大而增大
- 电源数量较少
- 使用射频源，射频能量的传输要求源阻抗、传输线特性阻抗和负载阻抗均需匹配
- 性能易预测
- 放电室强度低；绝缘表面会因覆盖导体层而产生寿命问题

### 2.3 微波电子回旋共振式（ECR）

**工作原理**：微波离子推力器采用处于磁场中的微波来产生等离子体。这种方式不需要空心阴极，在放电室中也不需要施加直流电压。在引入磁场的情况下，如果在放电区域内输入的微波频率和电子回旋频率相等就会产生共振，即电子回旋共振（Electron Cyclotron Resonance，ECR），此时微波的能量可以高效地耦合给电子，从而形成高密度的等离子体。

**ECR 物理原理**：
- 微波右旋极化电场方向与电子绕磁力线做回旋运动的方向一致
- 电子回旋频率：**ω_ce = eB / m_e**
- 通过调整磁场在放电室的轴向分布，使得回旋频率 ω_ce 在轴向某一位置上等于微波电场的极化频率 ω，即 **ω = ω_ce**
- 一般地，微波的频率为 **2.45 GHz**，则对应的磁场为 **875 G**

**结构特点**：
- 放电室和中和器采用磁性极强的钐-钴永磁铁，靠近工作频率谐振场布置
- 中和器也利用 ECR 微波放电驱动，由一个微波发生器同时供给离子发生器和中和器
- 不需要放电阴极，无阴极腐蚀问题
- 需要磁场

**特点**：
- 效率稍低，效率不随尺寸的增大而增大
- 电源数量较少
- 使用微波源，微波源相比于射频源更难实现
- 等离子体密度受共振频率和磁场的限制，一般在低电流密度和小尺寸条件下使用

### 2.4 三类推力器优缺点对比

| 项目 | 电子轰击式 | 射频式 | 微波ECR式 |
|------|-----------|--------|----------|
| 放电阴极 | 需要 | 不需要，无阴极腐蚀 | 不需要，无阴极腐蚀 |
| 磁场 | 需要 | 不需要 | 需要 |
| 效率 | 高，效率随尺寸的增大而增大 | 稍低，效率随尺寸的增大而增大 | 稍低，效率不随尺寸的增大而增大 |
| 电源数量 | 多 | 较少 | 较少 |
| 射频/微波源 | 不需要 | 射频源，需阻抗匹配 | 微波源，更难实现 |
| 电源类型 | 直流源，电能易传输，损失小 | — | — |
| 性能预测 | 难预测 | 易预测 | — |
| 主要缺点 | 结构复杂，电源多 | 放电室强度低；绝缘表面覆导体层致寿命问题 | 等离子体密度受限，适合小尺寸低电流密度 |

**总结**：
- **电子轰击式**：效率最高，但结构复杂，需要阴极和磁场，性能预测困难，电源数量多。
- **射频式**：无阴极腐蚀问题，无需磁场，性能可预测，但效率稍低，射频传输需要阻抗匹配，放电室有寿命问题。
- **微波ECR式**：无阴极腐蚀问题，结构相对简单（一个微波源同时供离子发生器和中和器），但等离子体密度受限，适合小尺寸、低电流密度应用。

## 三、放电室

### 3.1 放电室结构与组成

放电室（电离室）是电子轰击式离子推力器的核心部件，由金属材料制作而成，其作用是为推进剂电离后形成的等离子体提供容器。放电室在电离推进剂原子的过程中还充当阳极的作用，其电压为阳极电压，电子最终会撞击到电离室壁上而被吸收。此外，放电室还充当整个发动机的结构支撑部件，空心阴极、永磁体、推进剂供给环、栅极和中和器等均安装在电离室上。

电离室有两种结构形式：

| 结构形式 | 特点 |
|---------|------|
| **圆柱形结构** | 最基本的放电室构型 |
| **圆柱加圆锥结构** | 发动机上游为圆锥去掉尖端，可提高放电室结构稳定性，减小放电室粒子损失面积；通过减小上游端面面积降低等离子体在壁面上的损失，提高推进剂电离效率和推力器性能 |

### 3.2 放电室磁场的作用与构型

**磁场的作用**：磁场是提升放电室和推力器性能的关键，主要用来约束电离室内由气体放电形成的等离子体。没有磁场的电离室几乎是无法正常工作的。

使推进剂原子电离的主要是空心阴极发射的原初电子，而原初电子的平均自由程远大于电离室的尺寸。如果不采取措施，大部分原初电子会直接撞击到阳极（电离室壁）上，起不到电离的作用。在电离室中加入磁场后，电子在磁场的作用下做螺旋运动，增加了电子在电离室中运动的距离，从而增加了电子与中性原子撞击的机会，提高了电离效果。

**磁场构型的发展历程**：发散场 -> 径向场 -> 多极场 -> 尖角场 -> 环尖场。发展过程中推力器性能不断得到提高。目前只有两种磁场构型仍在离子推力器中得到使用：(1) 发散式螺线管磁场；(2) 环尖磁场（环形会切磁场）。除英国的 T5 和 T6 离子推力器外，其余离子推力器都采用环尖磁场构型。

**永磁体布置实现会切磁场**：

(1) **环形会切场**：在电离室底面上靠近空心阴极的外圈安装一个永磁环，在电离室圆柱壁面上安装两排永磁块，形成环形会切磁场，磁力线中止于阳极表面。一般采用钐钴永磁体（SmCo）。

(2) **柱形会切场**：采用柱状永磁体配合极靴（软磁材料）形成柱形会切磁场。

**两种会切磁场对比**：

| 对比项目 | 环形会切场 | 柱形会切场 |
|---------|-----------|-----------|
| 重量 | 较轻（无需屏栅筒和极靴） | 较重（增加了屏栅筒和极靴，极靴为软磁材料，密度较大） |
| 放电损耗 | 较高 | 较低 |
| 束流均匀性 | 较好 | 较差 |
| 放电电压 | 较低 | 较高 |
| 双荷离子比 | 较低 | 较高 |
| 寿命与可靠性 | 较好 | 较差 |

环形会切场在重量方面较柱形会切场存在优势（无需屏栅筒和极靴），柱形会切场比环形会切场具有放电损耗低的优点，但其较差的束流均匀性、较高的放电电压和双荷离子比，使其在寿命和可靠性方面劣于环形会切场。

### 3.3 放电室性能参数

放电室性能主要用三个参数来表征：

**(1) 推进剂利用率（η_ud）**

衡量推进剂原子被电离并形成离子束流的比例。推进剂利用率越高，说明推进剂的利用效率越高，中性原子逃逸越少。推进剂利用率与放电损耗之间存在相互制约的关系。

**(2) 放电损耗**

表征每产生一个束流离子所消耗的能量，是衡量放电室能量利用效率的重要指标。放电损耗越低，说明产生离子的能量"成本"越低。

**推进剂利用率与放电损耗的物理解释**：
- 若主阴极的**电子发射电流较低**，大多数能量提供给原子用来产生离子，但许多中性原子仍不能被电离，以原子形式逃逸出栅极，推进剂利用率 η_ud 比较低。
- 当电子发射电流**增大到一定值**时，大多数推进剂都可以被电离，但同时有许多电子没有参与推进剂原子的电离，它们携带一部分能量到达阳极，束离子能量"成本"剧增（放电损耗增大）。

这表明推进剂利用率和放电损耗之间存在**权衡关系**：提高推进剂利用率往往以增加放电损耗为代价。

**(3) 束流均匀度（束流平整度）**

表征引出离子束流在径向分布的均匀程度。一项重要发现是：**由临界磁力线和栅极围成的初始电子区形状与发射束流轮廓近于互为镜像**。这一发现提供了一个重要的判断依据——用初始电子区包络判断束流轮廓，束流密度径向分布是初始电子区轴向深度的函数。如想改善束流均匀度，就必须使原初电子区形状趋于矩形。

### 3.4 等离子体组成与分布

放电室等离子体由以下四种粒子组成：

| 粒子类型 | 说明 |
|---------|------|
| **原初电子（Primary Electron）** | 由空心阴极发射，是电离推进剂原子的主要能量来源。沿阴极附近的弱发散磁场运动，被充分磁化，在放电室表面附近被不断反射，直到通过碰撞损失能量或通过磁尖到达阳极 |
| **二次电子（Secondary Electron）** | 被原初电子从推进剂原子中轰击出的电子，能量较低，最终到达阳极 |
| **离子（一价、二价）** | 推进剂原子被电子轰击电离后产生的离子。部分到达阳极、屏栅极、阴极；部分被屏栅极引出，经加速栅极加速后产生推力 |
| **中性原子（Neutral）** | 未被电离的推进剂原子，不受电磁场影响，通过栅极孔流出放电室。中性原子逃逸会降低推进剂利用率 |

放电室中等离子体的分布是非均匀的。原初电子在磁场约束下在放电室中做螺旋运动和反射，形成特定的等离子体密度分布。等离子体密度的径向和轴向分布直接影响束流的均匀性和推力器性能。原初电子发射后沿阴极附近的弱发散磁场运动，被充分磁化，在放电室表面附近被不断反射。磁场的构型和强度决定了原初电子的约束效果和等离子体的空间分布。

### 3.5 放电室电流的组成与获取

**放电室电流组成**：

| 符号 | 名称 | 说明 |
|------|------|------|
| I_e | 阴极电子电流 | 空心阴极发射的电子电流 |
| I_k | 返回阴极的离子电流 | 离子返回到阴极形成的电流 |
| I_L | 阳极原初电子电流 | 原初电子到达阳极的电流 |
| I_a | 阳极二次电子电流 | 二次电子到达阳极的电流 |
| I_ia | 阳极离子电流 | 离子到达阳极的电流 |
| I_B | 离子束流电流 | 通过栅极引出的离子束流 |
| I_s | 屏栅极（离子）电流 | 离子打到屏栅极形成的电流 |

**电流平衡关系**：
- **阴极处**：屏栅电势与阴极相等，发射电子电流与返回离子电流之间满足电流平衡。
- **阳极处**：原初电子电流、二次电子电流和离子电流之和满足阳极电流守恒。

**电流获取方法**：

| 方法 | 描述 | 优缺点 |
|------|------|--------|
| **实验测量** | 直接测量放电电压和放电电流获取电参数 | 直接获得宏观电气参数 |
| **零维模型**（Goebel, 2006） | 对放电室进行整体能量和粒子平衡分析，估算各电流成分 | 简单快速，但假设等离子体参数均匀分布，忽略空间变化，不精确 |
| **PIC/MCC 粒子模拟** | 追踪每个粒子的运动轨迹和碰撞过程，涉及磁势 A_θ 和磁场强度 H_c | 可给出粒子分布、电场和磁场的详细信息，精度高 |

## 四、栅极系统

### 4.1 栅极系统的组成与功能

离子光学系统（栅极系统）位于电离室的下游，是推力器推进剂的出口。其主要功能是将电离室中的推进剂离子引出，并加速到极高的速度，向后喷出以产生推力。

**双栅系统**：

双栅系统由屏栅（Screen Grid）和加速栅（Accelerator Grid）组成。

| 栅极 | 电压 | 主要作用 |
|------|------|---------|
| **屏栅（Screen Grid）** | 正电，一般 **1000V** 以上 | (1) 将放电室等离子体边界限制在栅极上游；(2) 将放电室等离子体中的电子限制在放电室内（屏栅电压等于放电室阴极电压，低于阳极电压，实现屏蔽电子功能）；(3) 将离子通过屏栅孔聚焦引出 |
| **加速栅（Accelerator Grid）** | 负电，约 **-200V** 左右 | (1) 进一步增加离子束流的引出；(2) 屏蔽加速栅下游中和器发射的电子，使电子不能经过栅极孔向放电室回流 |

**三栅系统**：除屏栅和加速栅外，还有一块减速栅极（Decelerator Grid），安装在加速栅极的外侧。减速栅极电势接近于零伏，可有效减少下游的交换电荷离子对栅极的溅射腐蚀。

**栅极的加工与装配**：
- 栅极都是很薄的电极板，由导电材料制作，上面打有几千或上万个栅极孔。屏栅孔与加速栅孔必须按设计要求**对中**。
- 栅极材料包括钼、钛和 C-C 复合材料等，一般由液压成型方法制造。
- **C-C 复合材料**：具有负的热膨胀系数，可将栅极加工成**平面**。
- **钼栅极**：需加工成**球面**，以避免热膨胀引起栅极之间接触短路；也有做成凹面的（如英国 T5、T6 离子推力器）。

### 4.2 束流的引出与聚焦

离子引出依赖于屏栅与加速栅之间形成的电场分布。屏栅上游的等离子体鞘层结构和栅极间的电势分布决定了离子运动轨迹和聚焦效果。

**三种束流引出状态**：

| 状态 | 条件 | 特征 |
|------|------|------|
| **交叉极限（Crossover Limit）** | 抽取电流（等离子体密度）过小 | 离子束交叉过度，部分离子直接撞击到加速栅极上 |
| **导流极限（Perveance Limit）** | 抽取电流（等离子体密度）过大 | 束流过度发散，离子撞击到栅极 |
| **正常聚焦** | 介于两者之间 | 正常引出，典型束流密度参考值 j_b = **0.24 mA** |

**等离子体密度对鞘层的影响**：改变放电室等离子体密度会导致屏栅上游鞘层面形状和位置的变化，进而导致离子轨迹的变化。等离子体密度较低时，鞘层面向栅极移动；等离子体密度变化时（如 j_e = 0.02 mA、0.16 mA、0.24 mA），鞘层形状和离子轨迹均发生明显变化。

**屏栅电压对聚焦的影响**：在加速电压不变的情况下，随着屏栅电压的减小，逐渐出现欠聚焦，导致部分离子入射到加速栅。这是因为屏栅和加速栅之间的电势差发生变化，导致屏栅上游等离子体鞘层结构发生变化。鞘面的形状和相对位置由放电室等离子体密度、栅极间电势和距离等因素决定。

**净总加速电压比 R**：

**R = V_N / V_T**

其中：
- **净加速电压 V_N**：与等离子体电位 V_P 和屏栅电压 V_S 相关
- **总加速电压 V_T**：与等离子体电位 V_P 和加速栅电压 V_A（取绝对值）相关

净总加速电压比 R 反映了加速场和减速场对离子聚焦和散焦的程度，是决定离子推力器离子束发散角的一个重要参数。

- **R 值越大**，说明加速栅上施加的负电压值相对越小（或屏栅电压越大），离子束发散角就越小，聚焦效果越好。
- 通常，离子推力器的净总加速电压比值在 **0.85 ~ 0.90** 之间。

### 4.3 束流密度极限

离子推力器受空间电荷极限的限制，其离子流量存在一个极限。空间电荷效应导致推力密度（F/A，推力与栅极面积之比）也存在极限。

**Child-Langmuir 方程（Child 定律）**：描述空间电荷限制下两电极间电流密度极限的基础方程。该方程给出了在给定电压和电极间距条件下，空间电荷效应所能允许的最大电流密度。对于离子推力器的栅极系统，Child-Langmuir 定律限定了单位面积上可以引出的最大离子束流密度。

**归一化导流系数**：基于 Child-Langmuir 方程定义的参数，用于表征栅极系统的离子引出能力。

**推力器口径对比**：由于栅极束流密度极限的存在，对于相同的推力需求，离子推力器通常需要比霍尔推力器更大的口径：

| 推力器类型 | 型号 | 推力 |
|-----------|------|------|
| 霍尔推力器 | LHT100 | 80 mN |
| 离子推力器 | LIPS200 | 40 mN |

离子推力器受限于 Child-Langmuir 定律，单位面积的推力输出受到限制，这决定了其需要更大的栅极面积。

### 4.4 电子回流问题

**概念**：电子回流（Electron Backstreaming）是指加速栅下游中和器发射的电子穿过栅极孔返流回放电室的现象。电子回流会降低推力器效率和性能，是需要避免的工作状态。

**影响因素**：

**(1) 加速栅极电压**：改变加速栅极电压是影响电子回流的关键因素。加速栅极施加负电压的目的是建立一个势垒，阻止下游电子穿过栅极孔进入放电室。如果加速栅极负电压的绝对值不够大，势垒不足以阻止电子回流。

**(2) 加速栅极孔半径**：栅极腐蚀引起的加速栅极孔半径扩大会导致电子回流。随着推力器工作时间增加，加速栅极孔因离子溅射腐蚀而逐渐扩大，使得下游电子更容易穿过栅极孔进入放电室，从而引发电子回流问题。这是制约栅极寿命的重要因素之一。

### 4.5 电荷交换离子与栅极腐蚀

**电荷交换碰撞（CEX）**：高速离子与低速中性原子之间发生电荷转移的碰撞过程。高速离子从低速中性原子中获取一个电子变为高速中性原子，而原来的中性原子失去电子变为低速离子（即电荷交换离子）。电荷交换离子的生成率与电荷交换碰撞截面有关。

**栅极腐蚀的重要性**：
- 决定离子推力器寿命的一个重要因素就是栅极的腐蚀
- 加速栅极下游表面腐蚀最为严重，是由电荷交换碰撞形成的慢速离子撞击栅极造成的
- 寿命实验消耗巨大，需要上万小时（NSTAR 超过 3 万小时），数值方法可以大大降低费用、节约时间

**腐蚀机理**：电荷交换碰撞产生的慢速氙离子在加速栅极电场的作用下加速轰击加速栅极下游表面，造成溅射腐蚀。氙离子的空间分布决定了腐蚀的空间分布模式。

**腐蚀率计算公式**：

**腐蚀率 ∝ (J × Y) / (ρ × M_g)**

其中：
- **J**：离子入射电流密度
- **Y**：溅射产额（Sputtering Yield），每个入射离子所轰击出的材料原子的个数
- **ρ**：被轰击材料的密度
- **M_g**：被轰击材料原子的质量

**溅射产额 Y 的影响因素**：

| 因素 | 说明 |
|------|------|
| **离子入射能量** | 溅射产额与离子入射能量关系通过试验点拟合出曲线；氙离子对不同金属的溅射产额曲线存在差异 |
| **离子入射角** | 通过修正拟合出的溅射产额获得；例如入射能量为 350 eV 时，氙离子对钼材料的溅射产额随入射角变化明显 |

**延长栅极寿命的措施**：
1. **采用三栅极**：减速栅极可有效减少交换电荷离子对栅极的溅射腐蚀
2. **降低加速极电压**：但可能造成电子回流
3. **更换栅极材料**：选择更耐溅射的材料

数值模拟可以给出加速栅极下游表面腐蚀深度分布（单位 μm）和三维形貌，对评估推力器寿命和优化设计具有重要意义。

### 4.6 栅极间短路问题

栅极间短路是指屏栅极与加速栅极之间发生电气短路的现象。由于两块栅极之间的间距非常小，且栅极板上布有几千到上万个孔，在工作过程中可能因热变形、碎片污染或制造误差等原因导致栅极相互接触，从而引起短路。

**解决方法**：

| 方法 | 具体措施 |
|------|---------|
| **控制栅极间距** | 精确设计和严格控制屏栅与加速栅之间的间距，确保在热膨胀和工作振动条件下仍能维持足够的间隙。需选择合适的栅极材料（如具有负热膨胀系数的 C-C 复合材料）和合理的栅极面形设计（如钼栅极加工成球面） |
| **控制放电室碎片的大小** | 防止放电室中产生的碎片（如溅射产物、剥落颗粒等）进入栅极间隙，因为这些导电碎片一旦搭接在两块栅极之间就会引发短路 |

### 4.7 离子推力器配电

**配电要点**：

| 参数 | 数值/条件 | 说明 |
|------|----------|------|
| 放电电压 | **20~40V** | 阳极和阴极之间的电压 |
| 屏栅极电压 | **~1000V** | 决定引出离子的能量 |
| 加速栅极电压 | **~-200V** | 负值，阻止下游电子返流 |
| 阴极与屏栅极电位 | 相等 | 保证等离子体电势比屏栅极电势高，有利于离子被屏栅极引出 |
| 阳极与阴极电位关系 | 阳极更高 | 阳极和阴极之间为放电电压 |

**需配电的部件及所需电源数量**：

| 部件 | 所需电源数量 |
|------|------------|
| 阳极 | 1 个电源 |
| （空心）阴极 | 3 个电源 |
| 屏栅极 | 1 个电源 |
| 加速栅极 | 1 个电源 |
| 中和器 | 3 个电源 |

**接线方式**：

离子推力器有两种主要接线方式：

1. **接线方式 1**：屏栅极电源位于阳极和中和器之间，阳极电源与屏栅电源的输出正线合并，输出为同一端。NSTAR、LIPS200 均为此方式。
2. **接线方式 2**：主要区别在于电源接地参考点的选择和屏栅极电源的连接位置。

不同推力器型号（如 NSTAR、LIPS200）可能采用不同的配电拓扑，但都需满足上述电压分配要求，确保等离子体稳定产生、离子有效引出以及电子返流的抑制。

## 五、离子推力器设计方法

### 5.1 总体设计思路与参数选择

离子推力器设计过程包括四个主要环节：离子推力器参数选择、放电室设计、栅极组件设计、以及离子推力器耦合匹配设计。

放电室设计分为两种主要磁场构型方案：**环形会切磁场**（磁路结构简单，无极靴，适合大口径离子推力器）和**柱形会切磁场**（锥段磁场较强，极靴深入放电室内部）。

参数选择的步骤为：

1. 根据任务和推进剂类型，确定离子推力器**比冲**；
2. 根据任务确定推力器**推力**和**所需功率**；
3. 根据推力、比冲，确定所需的**束流大小**和**束流电压**；
4. 确定适当的**束流密度**（不超过极限束流密度的60%），由此得出推力器的**束径**；
5. 根据上述参数，估算出**阳极电流**（约为束流的4~7倍），再由电流平衡关系估算**主阴极发射电流**。

### 5.2 放电室磁场设计准则

放电室磁场设计遵循以下三个准则：

**准则一：表面磁场/多级磁场。** 磁极在阳极筒内表面区域形成磁场（称为"表面磁场"或"多级磁场"），磁力线不和阳极筒相交，实现放电等离子体的低气压化、高密度化和均匀化。

**准则二：无场区。** 理想磁力线分布将磁场限制在阳极附近区域，使放电室内部特别是栅极附近的大部分区域接近为无场区，增强引出束流的分布均匀性。由临界磁力线和栅极围成的初始电子区形状与发射束流轮廓近于互为镜像。

**准则三：锥段与柱段磁场强度分布。** 锥段磁感应强度要强于柱段磁感应强度，放电室轴线上的磁场强度在阴极触持极顶附近达到最大值；在柱段区域，磁场强度要求迅速衰减，以兼顾电离效率和束流均匀性。

### 5.3 环形会切场放电室设计

#### 5.3.1 概述与特点

环形会切场的主要特点包括：
- 磁路结构简单，无极靴；
- 放电室阳极为整体密封结构，无屏栅筒；
- 遭受离子轰击的零件较少（仅屏栅极和阴极），溅射多余物较少；
- 磁空区较大，束流均匀性好，非常适合大口径离子推力器；
- 无法用电磁铁实现放电室优化实验，磁场优化成本较高，只能在有限实验基础上通过理论计算确定。

#### 5.3.2 工作参数设计

**放电电流**：放电电流取决于所要求的束流和放电损耗，一般按下式估算：

$$I_d = (5 \sim 7) I_b$$

其中 $I_d$ 为放电电流（阳极电流），$I_b$ 为束流。

**放电电压与流率**：放电电压一般在 **24~30V**，放电室工质利用率在 **70%~95%**。放电电压主要取决于放电室磁场、阴极流率和推进剂利用率。三者之间存在制约相关性，推进剂利用率越高越好，放电电压和放电损耗越低越好，须根据推力器用途权衡确定。

#### 5.3.3 几何参数设计

**口径设计**：放电室口径一般大于束口径，但不超过束口径的1.2倍。放电室柱段阳极直径一般为"栅极最大开孔区域直径 + (20~30mm)"。栅极最大工作束流密度不超过其极限束流密度的60%。

**几何构型**：一般采用锥段-直段型放电室结构，因其具有最长的原初电子约束长度，放电效率最高，且随束流口径增加优势更明显。

**长径比**：一般在 **0.4~1** 范围内分布。较长的放电室长度有利于提高工质利用率（增大工质分子存留时间），但会降低电离效率（减小原初电子密度）。

**主阴极位置**：阴极顶位于最大轴向场强处，使磁力线在阴极出口处沿径向发散，磁场强度沿轴线快速衰减，原初电子远离中心轴，兼顾电离效率和束流均匀性。

**供气方式**：一般采用栅极出口反向供气方式，有助于实现高束流均匀性。

#### 5.3.4 磁路与磁场设计

**磁极数设计**：磁极越多，磁间距越小，特征磁场线越靠近阳极，束流均匀性越好，但电子在阳极上的损耗面积也越大、原初电子约束路径越短、放电损耗越高。设计原则是在**最小磁极数**下实现**最佳放电室磁场构型**。

**磁极位置**：相邻磁极对之间的间距一般设计值为 **11~16cm**，具体值需根据磁极数、放电室尺寸和构型通过磁场仿真和试验优化确定。

**磁体材料**：要求具有大磁能积、高矫顽力和耐高温特性。磁体与放电室壁面间距应尽可能小，常将环形磁极组件直接固定在放电室阳极壁上。

**磁体尺寸与磁场要求**：
- 放电室内部闭合磁等势线为 **50Gauss** 左右；
- 放电室内部出口区域磁感应强度小于 **5Gauss**，接近无场区，且无场区尽量大；
- 通过仿真计算软件进行优化。

**磁场优化**：磁场越强，原初电子约束时间越长、放电效率越高，但磁场增强将减小磁空区，使束流均匀性变差，需要折中。

### 5.4 柱形会切场放电室设计

#### 5.4.1 概述与特点

柱形会切场的主要优点：
- 锥段磁场较强，柱段磁场较弱；
- 极靴深入放电室内部，更有利于形成平行于阳极表面的磁场分布；
- 磁铁置于屏栅筒外，降低了对磁体材料工作温度的要求。

不利之处：
- 磁柱数量有限，垂直于轴线的切面磁场均匀性较差；
- 放电室为屏栅筒与阳极筒双层结构，重量较大；
- 磁极深入放电室内部，存在离子刻蚀产生多余物的潜在隐患。

柱形会切场放电室目前没有完整设计方法可借鉴，多采用**理论与经验公式相结合、仿真与试验相迭代**的技术途径。

#### 5.4.2 几何参数设计

**口径设计**：放电室口径一般大于束口径，但不超过束口径的1.2倍。最大引出束流不超过栅极最大引出能力的60%，由半经验公式表述：

$$I_{\text{max}} \leq 0.6 \cdot n \cdot P_{\text{max}} \cdot V_T^{3/2}$$

其中 $n$ 为栅极孔数，$P_{\text{max}}$ 为最大导流系数，$V_T$ 为总加速电压。

**几何构型**：仿真计算表明，锥段-柱段型放电室具有最长原初电子约束长度，放电效率最高。

| 放电室几何构型 | 原初电子约束长度/m |
|---|---|
| 锥形放电室 | 23.4 |
| 柱形放电室 | 50.5 |
| 锥段-柱段放电室 | 58.9 |

**特征几何参数定义与经验公式**：

| 参数符号 | 含义 | 经验公式 |
|---|---|---|
| $D_d$ | 柱段阳极筒内径 | $D_h + 28$ |
| $L / D_d$ | 长径比 | 2/3 |
| $L_1, L_2, H, D_2$ | 柱段长度、锥段长度、锥段高度、锥段小圆内径 | $L/2$ |
| $\phi_1$ | 上极靴内径 | $D - 14$ |
| $\phi_3$ | 下极靴内径 | $D - 6$ |
| $D_4$ | （中间参数） | $D_2 - 8$ |
| $L_3$ | 上极靴长度 | $\leq 0.1 \cdot L_2$ |
| $L_4$ | 下极靴长度 | $\leq 0.1 \cdot L_1$ |
| $L_5$ | 阴极深入放电室长度 | $0.3 \cdot L_1$ |

#### 5.4.3 工作参数设计

**阳极电流估算**：

$$I_d \approx (4 \sim 6.5) I_b$$

口径较小的推力器取上限，口径较大的取下限。例如：LIPS-200 约为 5.6，LIPS-300 在不同工况下为 4.0~5.0。

**阳极电压估算**：柱形会切场放电室阳极电压低于发散场放电室但高于环形会切场放电室，一般按 **35~38V** 估算。

#### 5.4.4 磁路与磁场设计

柱形会切场磁路设计遵循四个准则（与放电室磁场设计准则一致），此外还包括：

**磁场强度要求**：
- 柱段阳极筒中间表面沿轴线方向的磁感应强度为 **50~60G**；
- 锥段阳极筒中间表面沿壁面方向的磁感应强度为 **60~70G**；
- 放电室内闭合磁场等势线范围基本在 **0.003~0.005T**。

**磁极数设计**：
- 口径 30cm 以下：可采用**三极场**；
- 口径 30cm 以上：应采用**四极场**或更多极场。
- 两个磁极之间横断面上闭合磁等值线的最大磁场强度取 **0.005T** 附近时，可使阳极壁面离子损失电流下降约10%。
- 对30cm放电室直径，优选磁极间距在 **110~130mm**（参考 LIPS-300 四磁极设计）。

**磁极位置**：磁极间距设计最佳值为 **11~16cm**，阴极磁环半径设计最佳值为 **3~4cm**。

**设计方法**：首先按经验准则完成电磁铁磁场仿真设计并通过电磁铁试验获得最佳磁场的励磁电流，再以特征点磁场强度匹配方式将电磁铁最佳磁场转换为永磁铁结构。

**性能优化**：包括磁场优化试验和流率优化试验（在总流率不变前提下调节阴极流率和阳极流率占比）；利用 PIC/MCC 数值仿真方法对不同工况下的放电室气体放电过程进行数值仿真。

### 5.5 栅极组件设计

#### 5.5.1 几何参数设计

栅极几何参数设计需综合考虑以下影响因素：束流密度需求、栅极热形变、溅射腐蚀防护、加速栅电压与电子返流的制约、束流发散角控制等。

栅极结构参数优选值（以屏栅孔径 $d_s$ 为基准）：

| 参数 | 符号 | 优选范围 |
|---|---|---|
| 屏栅厚度相关参数 | $t_s / d_s$ | 0.125 ~ 0.175 |
| 加速栅厚度相关参数 | $t_a / d_s$ | 0.2 ~ 0.4 |
| 加速栅孔径相关参数 | $d_a / d_s$ | 0.6 ~ 0.7 |
| 减速栅厚度相关参数 | $t_d / d_s$ | 0.2 ~ 0.4 |
| 减速栅孔径参数 | $d_d / d_s$ | 0.8 ~ 0.9 |

**补偿设计（大口径球面栅极）**：大口径离子光学系统采用球面栅极以保证热循环工况和力学环境中形变方向一致性，但会增大束流发散（包括球面形状产生的发散和加工误差造成的发散）。通过对其中一个栅极的孔中心距进行调整（"补偿"），孔中心距小于 **0.5%** 的改变量即可显著减小束流发散。

**结构形式**：小口径组件采用平面屏栅、碟状加速栅；大口径组件采用球形屏栅和加速栅。

#### 5.5.2 束流引出性能设计

束流引出性能由三个关键参数决定：

**归一化导流系数 $K$**：对于氙工质，最佳取值为 **$2.0 \sim 2.4 \times 10^{-9} \text{ A/V}^{3/2}$**（一般为最大值的35%~50%）。当栅极出现明显离子截获时对应的 $K$ 为使用上限值。

**净加速电压与总加速电压之比 $R$**：最佳取值 **0.75~0.9**。

**栅极间距与屏栅孔径之比 $L_g / d_s$**：最佳取值 **1~0.75**。

**设计示例**（某3cm射频离子推力器）：

| 参数 | 屏栅极（s） | 加速栅极（a） |
|---|---|---|
| 栅极材料 | 316不锈钢 | 钼 |
| 栅极厚度 | 0.3 mm | 1.0 mm |
| 栅极间距 | 0.7 mm | — |
| 栅极孔径 | 1.9 mm | 1.2 mm |
| 栅极孔数目 | 91 | 91 |
| 栅极透明度 | 36.5% | 14.56% |

设计工况：推进剂利用率55%，电效率40%，束流18mA，推力1.2mN，比冲2931s，推进剂流量0.5sccm。

#### 5.5.3 安装设计

**基本结构**：由双栅、双栅极支撑环、绝缘支撑等组成，双栅极必须互相平行。两块支撑环通过栅极绝缘体（陶瓷件）联接，每个陶瓷件都有屏蔽罩减少溅射污染。

**绝缘设计**：
- 栅极片之间需保证安全距离，考虑冷热交变情形下的热变形余量；
- 连接固定结构需防止外界等离子体进入连接支撑区域，以及与放电室之间做好隔离设计；
- 小口径栅极采用碟状加速栅，增加绝缘壁面路径，减少沿绝缘面击穿概率。

**材料选用**：

| 材料种类 | 热膨胀系数 (K$^{-1}$) | 溅射产额 (E=200eV) | 溅射产额 (E=400eV) |
|---|---|---|---|
| 钼 | $5.2 \times 10^{-6}$ | 0.29 | 0.70 |
| 钛 | $10.8 \times 10^{-6}$ | 0.13 | 0.34 |
| 碳基 | 接近0甚至负值 | 0.04 | 0.12 |

碳基材料具有优异的热稳定性和耐离子溅射特性，是较为理想的栅极材料，但力学强度较低、加工工艺复杂。现阶段国内外大多数栅极材料仍采用金属钼。栅极安装环材料应与栅极材料热膨胀系数接近（钛合金、钼配套钼栅极；碳基配套碳栅极）。绝缘支撑材料一般选用 **A95氧化铝陶瓷**。

**抗力学设计**：
- 口径大于10cm的栅极采用球面设计增加刚性；
- 栅极间距在满足安全电场条件下尽量小，但需考虑振动冲击下的碰撞风险；
- 拱高与弦的比值一般取值 **0.5~0.6**；
- 可在安装接口处增加减振缓冲装置。

### 5.6 离子推力器耦合匹配设计

离子推力器耦合匹配设计是确保各部件协调工作的关键环节，包含四个方面。

#### 5.6.1 放电室与阴极匹配设计

目的：减小放电损耗、阳极电压及电压纹波（峰-峰值）、触持极电压及电压纹波，提高屏栅极上游面离子密度均匀性。

方法：在工质气体流率、束流、栅极电压等额定参数不变的条件下，分别调节阴极流率和阴极轴向位置，获得各参数的关系曲线，综合得到优化匹配流率和位置。该优化需要迭代，且仿真计算和试验相结合。

#### 5.6.2 放电室与栅极匹配设计

目的：降低放电电压、减少放电损耗、提高离子密度均匀性。

方法：通过磁场、工质流量分配、放电室结构、栅极间距和变孔栅极的仿真优化和试验优化得到。各项要求不能在同一状态下均达到最优值，需综合考虑，**优先考虑可靠性**。

#### 5.6.3 中和器与束流匹配设计

目的：降低浮动电位、减小中和器触持极电压及其纹波、提高中和器抗熄弧能力。

优化方法：
1. 在安装结构允许条件下，尽可能选择较小的中和器与推力器轴向距离；
2. 在最小允许轴间距离下，对应最小和最大束流工作点，组合调节触持极电流和流率，选择最小浮动电位、最小触持极电压及其纹波的电气工作点，必要时折中选择。

#### 5.6.4 推力器与电气参数匹配设计

在满足推力器性能指标要求的前提下，优先考虑提高推力器工作可靠性，包括：减少放电室和中和器熄弧、减少非预期电击穿打火、提高束流均匀性。

## 七、离子推进发展历程

### 7.1 国外发展历程

国外离子推进经历了五个主要发展阶段：

| 时期 | 阶段 | 主要内容 |
|---|---|---|
| 1960年代 | 第一代离子推力器研制和试验阶段 | 初步研制与地面验证 |
| 1970年代 | 改进和扩展性能阶段 | 提升推力器性能 |
| 1980年代 | 氙离子推力器研制阶段 | 从汞推进剂转向氙推进剂 |
| 1993-1998 | 氙离子推力器初步应用阶段 | 工程应用开始（XIPS-13, 1997年 PAS-5） |
| 1998-至今 | 高速发展阶段 | 广泛工程应用（NSTAR, NEXT, XIPS等） |

重要里程碑：
- 2000年开始，世界范围内卫星电推进进入扩展阶段，目前在轨混合电推进通信卫星超过百颗；
- 2015年全电推进卫星相继升空，美国、欧洲进入全电推进时代。

### 7.2 美国早期发展

1960年，NASA刘易斯研究中心（Lewis Research Center）的考夫曼（Kaufman）运行了第一台电子轰击式离子推力器，开启了离子推进时代。

**早期飞行试验**：

| 试验项目 | 时间 | 推进剂 | 成果 |
|---|---|---|---|
| SERT-I | 1964年7月 | 汞 | 亚轨道飞行，一台工作31分16秒——首次在空间中启动的离子推力器 |
| SERT-II | 1970年 | 汞 | 极轨道（1000km高度），两台分别工作2011小时和3781小时，共完成300次开关 |

美国在工程应用前共进行十次、十五台离子推力器飞行试验，包括 661A 计划、SERT I、SERT II、ATS-4、ATS-5、ATS-6 卫星等。

**早期挑战**：电子轰击式离子推力器比冲可达3000秒，但结构复杂、可靠性不高；配电装置难度大；汞和铯需加热产生气体；离子喷出后凝结附着于飞行器表面。

### 7.3 日本发展

日本离子推进研究涵盖电子轰击式和微波ECR两种路线。

**电子轰击式**：

| 型号 | 规格 | 用途 |
|---|---|---|
| ETS-III | 5 cm 汞离子推力器 | 工程试验卫星 |
| ETS-VI | 12 cm 氙离子推力器 | 工程试验卫星 |
| — | 13/14/30/35 cm 氙离子推力器 | 工程研制 |

**微波ECR式——μ10**：

## 八、霍尔推力器概述

### 8.1 定义与特点

霍尔推力器（Hall Thruster）是一种技术成熟、应用广泛的电推进装置，最早由前苏联（俄罗斯）发明并实现工程应用。其核心特点包括：

- **结构简单**：相比离子推力器，省去了复杂的栅极系统
- **效率较高**：典型效率在 30%~60% 之间
- **工作寿命长**：SPT-100 通道寿命已达 8000 小时以上
- **比冲适中**：1500~2000 s（典型值约 1600 s），覆盖范围 1000~3500 s
- **推力密度高**：推力功率比约 60 mN/kW，约为离子推力器的两倍

### 8.2 在电推进中的分类地位

按加速机理，电推进分为静电式推进、电磁式推进和电热式推进三大类。霍尔推力器的加速过程是多种机制的综合效果，其中**电磁加速效应大于其他加速效应**。目前主流观点将霍尔推力器归于**电磁推进**范畴。

### 8.3 两种主要类型（SPT 与 TAL）

霍尔推力器主要分为两种类型：

#### 稳态等离子体推力器（SPT, Stationary Plasma Thruster）

| 特征 | 说明 |
|------|------|
| 放电室壁材料 | BN（氮化硼）陶瓷等绝缘材料 |
| 加速通道 | 较长，轴向长度与径向长度之比大于 1 |
| 研究应用现状 | 目前研究和应用的主流 |

#### 阳极层推力器（TAL, Thruster with Anode Layer）

| 特征 | 说明 |
|------|------|
| 放电室壁材料 | 金属材料 |
| 加速通道 | 短 |

**SPT 是目前研究和应用最为广泛的主流方案。**

### 8.4 与化学推进、离子推力器的对比

#### 与化学推进对比

| 指标 | 化学推进 | 霍尔推力器（SPT） |
|------|----------|-------------------|
| 比冲 | 约 300 s | 约 1000~3500 s（典型 1600 s） |

霍尔推力器的比冲远高于传统化学推进，这意味着完成相同总冲任务所需的推进剂质量大幅减少。

#### 与离子推力器对比

| 对比维度 | 霍尔推力器（SPT） | 离子推力器 |
|----------|-------------------|------------|
| 比冲 | 较低（约 1600 s） | 较高 |
| 结构和配电系统 | 简单 | 复杂 |
| 技术成熟度 | 高 | 适中 |
| 推力功率比 | **60 mN/kW** | 33 mN/kW |
| 推力密度 | 高 | 较低 |
| 推力重量比 | 大 | 较小 |
| 效率范围 | 30%~60% | 50%~70% |

霍尔推力器的显著优势在于**推力功率比约为离子推力器的两倍**，推力密度高且推力重量比大，适合需要较大推力的轨道转移和位置保持任务。

#### 存在的主要问题

- 等离子体振荡（影响放电稳定性和推力器性能）
- 羽流扩张角大（可能造成羽流污染）

## 九、霍尔推力器工作原理

### 9.1 物理基础：带电粒子在正交电磁场中的运动

霍尔推力器的工作原理建立在带电粒子在正交电磁场中运动的理论基础上。

考虑均匀恒定的电磁场：电场沿 x 方向（E = E_x），磁场沿 z 方向（B = B_z）。带电粒子在此正交场中的运动方程可导出 y 方向的漂移速度：

$$\vec{v}_d = \frac{\vec{E} \times \vec{B}}{B^2}$$

该漂移速度具有以下特征：

- 漂移速度方向与磁场和电场方向均垂直（即 E×B 方向）
- **漂移速度与电荷正负及粒子质量无关**——电子和离子在此机制下漂移速度大小和方向相同

这一漂移运动是霍尔推力器中**电子做周向漂移**（即**霍尔漂移**）的物理基础。

### 9.2 工作过程（六步详细分解）

霍尔推力器的具体工作过程可分为以下六个步骤：

#### 第一步：推进剂注入

推进剂（通常是**氙气 Xe**，高功率推力器也常用氪气 Kr）通过阳极上均匀分布的小孔喷射进入环形放电通道。

#### 第二步：电子发射与分配

空心阴极中的热电子发射体（LaB₆ 或钡钨）被加热后发射热电子。从空心阴极发出的电子分为两部分：

- **进入放电室的部分**：在电场作用下进入放电通道，参与电离过程
- **向下游运动的部分**：与轴向喷出的高速氙离子中和，维持推力器羽流的宏观电中性

#### 第三步：电子周向漂移（霍尔漂移）

阴极发射进入放电室的部分电子，在**径向磁场 B_r** 和**轴向电场 E_z**（正交电磁场）的共同作用下，做周向 E×B 漂移运动——即霍尔漂移。

#### 第四步：碰撞电离

在漂移过程中，电子与从阳极（气体分配器）出来的中性推进剂原子发生碰撞，使氙（Xe）原子电离，产生离子和新的电子：

$$\text{Xe} + e^- \rightarrow \text{Xe}^+ + 2e^-$$

电子漂移运动形成的周向电流称为**霍尔电流**。该霍尔电流极大增加了电子在通道内的滞留时间和路径长度，从而大幅提高了电子与中性原子碰撞电离的概率。

#### 第五步：电子轴向迁移与循环维持

电子在漂移的同时，受到以下因素影响逐渐逃离磁场的约束而向阳极运动：

- 与推进剂原子、离子及电子的碰撞
- 轴向磁场与径向电场的耦合存在
- 与通道壁面的碰撞

这些因素使电子逐渐向阳极运动并最终被阳极收集。与此同时，新电离产生的电子及阴极持续发射的电子不断补偿逃逸的电子。如此循环往复，保证了通道内维持足够的电子数量以及推进剂气体的高电离率。

#### 第六步：离子加速产生推力

由于离子质量远大于电子（m_i >> m_e），其拉莫尔半径远大于通道尺寸，受磁场的影响很小。离子直接在轴向电场的加速下沿轴向高速喷出，从而产生推力：

$$F = \dot{m} \cdot v_{ex}$$

推力来自于离子高速喷出的反作用力。

### 9.3 关键要点总结

| 环节 | 说明 |
|------|------|
| 电子运动方式 | 在正交电磁场（径向 B × 轴向 E）中做周向霍尔漂移 |
| 电离机制 | 漂移电子与中性推进剂原子碰撞电离 |
| 霍尔电流 | 电子漂移运动形成的周向电流 |
| 电子循环 | 逃逸电子 ← 电离新电子 + 阴极电子补偿 → 维持稳态放电 |
| 离子行为 | 质量大，磁场影响小，被轴向电场直接加速喷出 |
| 推力来源 | 离子高速喷射的反作用力 |

```
                    电 子 霍 尔 漂 移 示 意
                          ↑ E_z（轴向电场）
                          |
      霍尔漂移 ← ⊗ B_r（径向磁场，指向纸内）
       （周向）    |
                  电子

     电子在通道内做圆周漂移，大幅增加与中性原子的碰撞概率
              → 高效电离 → 离子轴向加速 → 产生推力
```

## 十、霍尔推力器基本组成与物理过程

### 10.1 基本组成部件

稳态等离子体推力器（SPT）的基本结构组成如下：

#### （1）空心阴极

- 位置：布置在推力器外部，距离推力器出口几个厘米
- 核心发射体材料：**六硼化镧（LaB₆）** 或 **钡钨**
- 功能：加热后发射热电子，电子经由触持极引出
- 电子分配：一部分进入放电室电离推进剂，另一部分中和羽流离子

#### （2）放电室（加速通道）

- 结构：由两个同轴但半径不同的陶瓷套筒组合而成，套筒之间形成环形电离与加速通道
- 壁面材料：

| 材料 | 特点 |
|------|------|
| 氮化硼（BN） | 常用绝缘材料 |
| BN-SiO₂ 复合材料 | 改进型材料 |
| 三氧化二铝（Al₂O₃） | 可选陶瓷材料 |
| 碳化硅（SiC） | 可选陶瓷材料 |

- 结构设计：轴向长度与径向长度之比 **大于 1**
- 壁面材料需具有合适的二次电子发射系数，该特性对放电室等离子体电导率有明显影响

#### （3）阳极（兼气体分配器）

- 位置：位于放电室通道底部
- 双重功能：
  - **正电极**：与空心阴极在放电室中形成轴向电场，阳极电势通常为几百伏
  - **推进剂供应装置**：阳极上布置有周向均匀分布的小孔，推进剂从小孔进入放电室
- 常用推进剂：**氙气（Xe）**；高功率推力器常选用 **氪气（Kr）**

#### （4）磁路系统

- 基本构型：**C 型磁路结构**
- 导磁材料：一般为软铁
- 铁芯结构：中心一个芯柱 + 外围四个芯柱
- 线圈：
  - 中心芯柱 → **内线圈**
  - 外围芯柱 → **外线圈**
- 磁屏：**内磁屏**和**外磁屏**，位于中心芯柱与外围芯柱之间
  - 作用：将部分磁力线导向底板，**降低通道底部磁场强度**，增大通道出口磁场梯度

```
              SPT 磁路结构（C 型磁路）示意

              外线圈           内线圈           外线圈
                │                │                │
         ┌──────┴────────┬───────┴───────┬────────┴──────┐
         │               │               │               │
         │   ┌───────────┼───────────────┼───────────┐   │
         │   │ 外磁屏 →  │               │  ← 外磁屏 │   │
         │   │           │   放 电 室    │           │   │
         │   │   ←───────┼─── 通道 ──────┼───────→   │   │
         │   │           │               │           │   │
         │   └───────────┼───────────────┼───────────┘   │
         │               │  ← 内磁屏     │               │
         └───────────────┴───────────────┴───────────────┘
                        前磁极板（通道出口）
```

#### （5）完整推进系统组成

| 组成部分 | 说明 |
|----------|------|
| 推进剂储箱 | 存储推进剂工质（Xe/Kr） |
| 阀门、减压器、压力传感器 | 推进剂供给管路控制与监测 |
| 流量控制器 | 精确控制推进剂流量 |
| 电源处理单元（PPU） | 为推力器各部件提供电源（阳极、阴极加热/触持、磁路线圈） |

### 10.2 关键物理过程

#### 10.2.1 放电通道的区域划分

根据电流形成原理，SPT 放电通道沿轴向大致分为三个区域：

| 区域 | 位置 | 特征 |
|------|------|------|
| **近阳极区（1 区）** | 靠近阳极（通道底部） | 电离度低，电流以**电子电流**为主，离子电流几乎为零 |
| **电离区（2 区）** | 通道中部 | 电子和离子电流共同组成；等离子体密度达到**峰值** |
| **加速区（3 区）** | 通道出口附近 | 电子电流可忽略，电流以**离子电流**为主；电势急剧下降，离子获得主要轴向加速 |

在轴向加速电场作用下，通道内电离形成的电子将最终到达阳极。到达阳极的电流除了电离形成的电子电流外，还包括部分阴极发射进入通道内的电子电流（**虚假电流 I_假**）。

#### 10.2.2 放电通道内部电子传导机制

核心问题：在正交电磁场中，电子被约束做稳定周向漂移运动，为何还能产生轴向宏观电子电流？

电子在漂移的同时受到多种因素影响（与重粒子碰撞、等离子体振荡、与壁面碰撞），损失动能后漂移被破坏。当再次建立起稳定漂移时，电子已沿轴向电场方向进行了迁移。多次频繁迁移形成宏观轴向电子运动。

三种电子传导机制：

**（a）经典传导（Classical Conduction）**

- 机理：电子与重粒子碰撞（以与中性原子碰撞为主）
- 特征：传导电流与电子密度成正比，与磁场强度的**二次方成反比**，即 $j \propto 1/B^2$

**（b）玻姆传导（Bohm Conduction）**

- 机理：等离子体振荡引起轴向电场同步振荡，加剧电子横越磁场的扩散
- 特征：传导电流与磁场强度 B **成反比**，即 $j \propto 1/B$

**（c）近壁传导（Near-Wall Conduction）**

- 机理：电子与推力器通道壁面碰撞引起
- 特征：在 SPT 通道内起着**较重要的作用**

三种传导的定量分布（示例数据）：

| 通道位置 Z/mm | 10 | 20 | 30 | 35 | 43 |
|--------------|----|----|----|----|-----|
| 近壁传导 I/A | 2.2 | 2.5 | 1.1 | 0.8 | 0.9 |
| 经典传导 I/A | 0.84 | 0.56 | 0.84 | 1.4 | 0.8 |
| 玻姆传导 I/A | 0.9 | 0.9 | 0.9 | 0.62 | 0.7 |

总体而言，**近壁传导起着较重要的作用**。三种传导共同作用，只是在通道不同区域每种机制所占比重不同。

#### 10.2.3 放电通道中的能量损耗机制

SPT 放电通道中的能量损耗主要包括：

1. **气体电离能量损耗**：推进剂原子电离所需的能量
2. **壁面能量损耗**：离子偏离轴线撞击壁面损失全部动能，并与电子复合释放热量；电子和离子对壁面的能量沉积
3. **阳极能量损耗**：电子入射到阳极表面产生的能量沉积
4. **离子和电子复合损耗**：放电室中离子与电子的复合
5. **辐射能量损耗**：等离子体的辐射能量损耗

**LHT100 推力器能量损耗分析（实例）**

| 能量去向 | 占比 | 说明 |
|----------|------|------|
| 束流离子加速 | **65%** | 产生推力的有效能量 |
| 放电室壁面能量损耗 | 21% | 用于陶瓷壁面加热 |
| 阳极能量沉积 | 3.3% | 约 44 W |
| 线圈能量损耗 | 3% | 可试验直接测量 |
| 阴极能量损耗 | 1% | 可试验直接测量 |

假定束流发散角系数为 0.9、双荷离子系数为 0.9、工质利用率为 0.9，则 LHT100 总效率约 **48.8%**，与同类 SPT100 约 50% 的效率相近。

## 十一、霍尔推力器性能指标

### 推力

推力 $F$ 是推力器产生的轴向作用力，与离子质量流量和离子速度相关：

$$F = \dot{m} \cdot v_{ex}$$

加速电压效率是影响推力的重要因素。

### 比冲

比冲 $I_{sp}$ 是单位质量推进剂产生的冲量，表征推进剂利用效率：

$$I_{sp} = \frac{F}{\dot{m} \cdot g_0}$$

- 霍尔推力器比冲范围：**1000~3500 s**
- 典型值：**约 1600 s**

### 推力功率比

推力功率比是给定功率下产生推力的能力指标。霍尔推力器（SPT）约为 **60 mN/kW**，是离子推力器（约 33 mN/kW）的约两倍。

### 推力效率

推力效率 $\eta$ 定义为推力器输出的轴向动能与输入总电功率之比：

$$\eta = \frac{F^2}{2\dot{m} \cdot P_{in}}$$

输入电功率中除产生轴向动能外，还存在多种能量消耗：电离耗能、壁面损失、电子轰击释热、电磁辐射、径向与周向动能损失、阴极与磁铁能量损失等。

推力效率由以下分量构成：

| 效率分量 | 说明 |
|----------|------|
| 电效率 | 电功率转换效率 |
| 推进剂利用率 | 推进剂工质的利用效率 |
| 离子电流效率 | 离子电流占总电流的比例 |
| 离子加速效率 | 离子被电场加速的效率 |
| 推力修正系数 | 多荷离子和束流发散角引起的修正 |

- 霍尔推力器效率范围：**30%~60%**（最高已达 60% 以上）
- 离子推力器效率范围：**50%~70%**

### 典型性能指标范围汇总

|------|------|

| 功率 | 100 W~10 kW |

## 十二、霍尔推力器磁场技术

### 12.1 磁场位型设计

#### 磁场设计的重要性

SPT 以电磁联合工作为基础，电场与磁场结构决定着推力器的内部过程和工作性能。推力器的电极形状对电场影响很小，**电场的构造主要由磁场分布决定**。因此：

> **磁场设计是关键，是整个 SPT 设计的核心。**

霍尔推力器的发展历程本质上就是磁场设计的发展历程。

#### 磁路发展历程

**早期设计问题：**

早期霍尔推力器通道底部磁场较强，导致电离区位于通道底部附近。电离产生的离子在轴向电场和径向磁场的共同作用下受到洛伦兹力产生周向运动，使大量离子未喷出通道而直接撞击壁面，造成：

1. **推力器性能降低**
2. **高能离子轰击壁面造成材料腐蚀，降低推力器寿命**

**磁透镜解决方案：**

前苏联研究人员提出将通道磁场设计为**磁透镜**形式——大部分磁通集中在通道出口附近，通道底部磁场几乎为零。这样电离区由通道底部移至通道出口附近，大部分离子可顺利喷出通道。

#### 径向磁场分布特征

典型加速通道径向磁场分布特征为：沿通道轴线方向**从底部至出口磁场逐渐变大**（即**正梯度径向磁场**），并在通道出口处达到最大值。

```
       径向磁场沿通道轴向分布

  B_r ↑
      │                    ╱
      │                  ╱
      │                ╱
      │              ╱     ← 磁透镜区（通道出口）
      │            ╱
      │          ╱
      │────────╱
      └────────────────────────→ 轴向位置 z
      近阳极区    电离区    加速区（出口）
      （低B）                    （最大B）
```

#### 热化电势物理机制

磁场中电子平行磁力线方向的扩散系数远大于垂直方向。忽略磁镜效应，沿磁力线满足**电子压力与电场力平衡**：

$$e n_e \vec{E} = -\nabla p_e$$

若沿磁力线电子温度为常量，则有：

1. 等离子体密度和电子温度分布**决定**等电势线分布
2. **磁力线影响（决定）等电势线**

来自阴极的电子横越最大磁场时经历焦耳加热，使局部电子温度和等离子体密度更高。强磁场区域中减小的电子迁移率（高电阻）和高的电子温度，使得出口平面附近的**轴向电场最大**。

#### 通道电势分布特征

- 通道前半部分电势基本保持不变
- 电势降主要发生在磁力线集中处——即**电离与加速区**
- 短的电离加速区域减小了等离子体复合损失
- 电离加速区靠近通道出口，减小了散射到壁面的离子损失
- 提高了离子总轴向动能和推力器综合性能

#### 性能演进

| 发展阶段 | 效率 |
|----------|------|
| "正梯度"磁场设计 | 20% 起 |
| 窄磁极设计 | ~40% |
| 通道底部零磁场区 + 磁透镜 | **60%+** |

### 12.2 磁场对性能的影响

磁场设计的优劣直接影响以下性能方面：

1. **电离区位置**：磁透镜位型将电离区推至通道出口附近，降低离子壁面损失
2. **电子约束效率**：强出口磁场约束电子，增加霍尔漂移路径，提高电离率
3. **轴向电场分布**：磁场分布决定等电势线和电场梯度分布
4. **壁面腐蚀速率**：合理磁场位型降低离子对壁面的轰击，延长寿命
5. **推力器效率**：磁场优化是效率从 20% 提升至 60%+ 的核心驱动力

## 十三、放电振荡与磁屏蔽

### 13.1 放电振荡类型与机理

#### 概述

SPT 工作时存在较强烈的电流和电压振荡，主要由推力器内部电离振荡与等离子体参数紊乱造成。**放电稳定技术是霍尔推力器的关键技术之一。**

#### 振荡类型与频率范围

| 振荡类型 | 频率范围 |
|----------|----------|
| 电离振荡 | 低频（1~100 kHz） |
| 轴向等离子体输运振荡 | 低频 |
| 电子周向漂移振荡 | 中频 |
| 电子回旋振荡 | 高频 |
| Langmuir 振荡 | 高频 |

#### 放电振荡的危害

1. **降低推力器性能**：推力、比冲、效率下降，严重时导致放电熄灭
2. **降低安全性与可靠性**：高幅振荡引起的强烈感应电势叠加在工作电压上，增加供电线路峰值电压，可能导致真空放电短路
3. **加重 PPU 及航天器电源负担**：可能影响航天器其他用电负载正常工作
4. **电磁干扰**：高频振荡对航天器电磁波通信产生干扰
5. **增加羽流污染**：增大离子束发散角
6. **降低寿命**：振荡模式下离子对室壁的溅射加强

#### 低频放电振荡（电离振荡）机理

SPT 低频放电振荡（1~100 kHz）主要是由于放电通道内中性原子的**电离振荡**造成的。电离振荡伴随电子密度振荡，对外表现为放电电流振荡。

当振荡过分强烈时，中性原子在电离最强时消耗过甚，导致通道内无法维持足够电子数，从而引发振荡甚至熄火。**振荡周期取决于中性原子通过电离区的补充时间**。

> 低频振荡幅值大，对推力器放电稳定性和性能影响最大，相关研究最早、成果最多。高频振荡（几十 MHz）由于检测和诊断技术难度大，理论和实验研究相对有限。

#### 放电振荡的影响因素

1. 推进剂流量及其种类
2. 施加的放电电压
3. 阴极特性（工质流率及位置）
4. 磁场的大小与形状
5. PPU 类型及振荡抑制电路的参数配置
6. 放电室的污染程度

#### 放电振荡的抑制方法

- **内部途径**：改进推力器设计（如增加缓冲腔），从工作过程与振荡机理出发
- **外部途径**：
  - 调整推力器工况，使其远离高振荡模式
  - 引入**振荡抑制电路**，从外部控制振荡强度

### 13.2 磁屏蔽技术原理与效果

#### 背景：通道壁面溅射侵蚀

推力器通道壁面溅射侵蚀是制约寿命的重要因素。BN 陶瓷材料通道的寿命：

- SPT-100：已达 **8000 h**
- SPT-70：**5000 h**
- 进一步推高 BN 材料通道寿命已十分困难

#### 磁屏蔽技术的发现

2010 年，JPL 的 Ioannis G. Mikellides 等人在对 **BPT-4000** 霍尔推力器进行 10000 h 长寿命实验时发现：当实验进行到 **5600 h** 时，推力器的磁场与通道几何结构形成一种特殊磁场构型，加速通道腐蚀速率**大幅降低甚至停止**。

由于磁场起到了屏蔽加速通道的效果，这一特殊构型被命名为**磁屏蔽构型**（Magnetic Shielding）。

#### 磁屏蔽的磁场特点与原理

**磁场特点：**

磁力线深入通道内部到达阳极附近，且**与通道壁面不相交**。

```
      传统构型                         磁屏蔽构型

  壁面 ←→ 磁力线相交              壁面 ∥ 磁力线（不交叉）
        ╱  ╲                             ╱          ╲
   ╱════╗    ╚════╲                ╱════╗          ╚════╲
  ╱ 通道║      通道 ╲              ╱ 通道║          通道  ╲
 ╱  ═══╝    ╔════  ╲            ╱  ═══╝          ╔════  ╲
       ╲  ╱                             ╲          ╱
  磁力线与壁面交叉                 磁力线深入阳极，与壁面平行
  → 离子轰击壁面                   → 屏蔽保护壁面
```

**原理：**

1. 利用磁力线的**等温、等势特性**，将阳极附近的高电势、低电子温度引到通道壁面
2. 通过壁面低电子温度**降低壁面鞘层电势**，减弱对进入鞘层内离子的加速；同时等势特性使轴向电势梯度较弱，降低壁面附近离子的轴向加速
3. 两者共同作用，**大大减弱离子对壁面的撞击**，显著提高寿命

#### 磁屏蔽技术的验证与影响

磁屏蔽技术在多个中等功率级推力器上得到效果验证：

- BPT-4000
- NASA-300-MS
- H6MS

**磁屏蔽的附加影响：**

| 方面 | 影响 |
|------|------|
| 壁面削蚀 | **大幅降低** |
| 壁面热流密度 | **降低**，推力器整体温度下降 |
| 高比冲模式（高放电电压） | 会降低磁屏蔽效果 |
| 振荡特征 | 比传统霍尔推力器多出一个振荡频率范围（**75~90 kHz**） |
| 磁极顶表面 | 磁屏蔽磁力线收尾于磁极顶表面，导致磁极顶产生削蚀，一定程度上影响羽流场粒子成分 |
| 小功率推力器 | 应用磁屏蔽技术时会出现**性能严重下降**的问题 |

磁屏蔽技术代表了霍尔推力器长寿命化的重要突破方向，但其在小功率推力器上的适用性、高放电电压下的效果衰减等问题仍需进一步研究。

## 十四、霍尔推力器设计方法

### 14.1 原理样机总体设计

SPT放电通道能稳定、高效地工作的前提是各结构尺寸之间满足特定的关系。俄罗斯火炬设计局公开发表了他们多年来的设计经验，确立了**经验公式 + 实验测试**的基本设计方法论。

关键设计参数包括：

| 参数 | 符号 | 说明 |
|------|------|------|
| 放电通道长度 | Lb | 放电通道内电离区及加速区的总长度 |
| 放电通道宽度 | b0 | 离子束宽度 |
| 内外磁极间距 | — | — |
| 放电通道中心线上磁感应强度 | — | — |
| 放电通道中心线上磁感应强度最大值 | Brmax | — |
| 放电通道外直径 | — | — |
| Brmax与0.5Brmax的间距 | — | 磁场半宽 |

推进剂流量与放电通道特征尺寸之间通过经验公式关联。

**以300mN推力器为例的设计参考值**：

- **放电室直径**：调研国内外成熟的200-500mN级别推力器尺寸设计，线性插值求得
- **内外磁极间距**：通过经验公式确定
- **放电通道宽度**：通过经验公式确定
- **放电通道长度**：通过经验公式确定
- **磁感应强度**：300V放电电压下通常为140~220 Gs

> 上述设计参数未考虑磁屏的情况。

### 14.2 放电室设计

放电室设计需满足五项重要要求：

1. 材料的二次电子发射性能
2. 材料的耐离子溅射能力
3. 结构的力学性能
4. 材料的耐高温能力
5. 绝缘性能

**材料选择**：放电室材料的二次电子发射系数是关键选择依据。

| 材料 | 二次电子发射系数评估 |
|------|----------------------|
| Al2O3 | 过高，不适用 |
| BN/SiO2 | 合适 |
| 纯BN | 合适 |

BN/SiO2综合优势突出：二次电子发射系数合适、耐溅射能力较好、加工性能好。因此BN/SiO2是当前霍尔推力器放电室最常用的材料选择。

**结构设计**：在保证结构强度和绝缘性能良好的同时，通道出口处需增加**翻边结构**以延长寿命。

**热设计**：放电室温度最高，但导磁材料温度不能过高。设计上应尽可能减少放电室与导磁底板的接触面积，降低热传导。放电室与金属接触位置需考虑高温下的热膨胀，预留足够的热胀空间，防止放电室因热应力破裂。热设计结果可通过简单的热学仿真进行确认和调整。

### 14.3 磁路系统设计

磁场设计是霍尔推力器设计的核心，直接关系到霍尔推力器的性能表现。现行设计方法主要依靠设计经验总结与试验测试。

**三条核心设计原则**：

| 原则 | 内容 | 效果 |
|------|------|------|
| 原则一 | 透镜状磁场且两侧沿放电室中线对称 | 减少束流发散角、减少电子壁面损失 |
| 原则二 | 沿轴向方向的径向磁场梯度 > 0（正梯度磁场） | 减少电子的轴向输运，延长电子容留腔道内的时间，提高推力器效率、减小阳极电流振荡 |
| 原则三 | 磁场集中在出口，接近阳极的磁场越小越好 | 集中推力器的电离加速区，减小通道损失，提高推力器比冲和效率 |

**磁路系统的空间分区**：

| 区域 | 特征 |
|------|------|
| 近阳极区 | 低磁场区 |
| 通道出口区 | 高磁场区（对称分布） |

**仿真优化设计**：通过调整推力器磁路设计参数来尽可能贴近三条设计原则，调整参数包括磁屏位置、构型、厚度、高度，线圈数量，励磁电流，线圈位置等。以HET-300推力器为例，在设计过程中开展了70多种不同结构、数百种工况下的磁场仿真分析，最终才获得较为理想的磁路系统结构设计。

### 14.4 阳极与气体分配器设计

一般采用**气体分配器与阳极二合一**方案，通过给气体分配器加阳极电压作为阳极。

**阳极设计**：

- **材料选择**：耐高温、抗电子轰击
- **热设计**：结合磁场设计，尽量降低轰击阳极的电子能量；尽量避免阳极高温向周围的磁极材料扩散

**气体分配器设计**：设计目标是将推进剂气体均匀地喷入放电室通道，并尽可能延长中性气体在通道内的驻留时间。

工质进入放电室的路径：

1. 工质通过进气管进入阳极
2. 工质进入一级、二级缓冲腔
3. 工质通过节流孔减速后被挡板阻拦，损失轴向动能
4. 自由扩散、轴向喷出

采用多级缓冲腔和节流孔+挡板的设计，可以有效地使推进剂气体均匀分布并延长气体在通道内的驻留时间。

### 14.5 绝缘设计

**气路与壳体绝缘**：气路与壳体间绝缘主要依靠**绝缘器**实现。通常绝缘器由中间的绝缘材料气管、两端焊接金属气管制成。绝缘器设计需考虑：

1. 选用致密性、机械强度、耐高温能力较强的绝缘材料，且金属材料与绝缘材料之间要有可焊接性，同时具有相近的热力学特性，防止热胀损坏
2. 为防止推力器点火过程中等离子体区可能的溅射蒸发物质在陶瓷上沉积导致绝缘性能下降，通常在陶瓷外部增加**防沉积罩**；尽可能采取多级串联的思路，提高可靠性

**阳极与壳体绝缘**：霍尔推力器阳极电压范围通常为300-1000V，由于工作环境为高真空环境，可按照1000V/mm进行安全间隙的设计。通常采用陶瓷端子的方式进行绝缘设计，主要绝缘元件包括陶瓷垫片和陶瓷端子。

### 14.6 SPT推力器类型对比

在霍尔推力器原理样机设计中，首先需要进行基本方案选择。目前主要的霍尔推力器类型有三种：稳态等离子体推力器（SPT）、阳极层推力器（TAL）和高效率多级等离子体推力器（HEMP）。

| 特征 | SPT | TAL | HEMP |
|------|-----|-----|------|
| 结构 | 简单 | 比冲高 | 结构复杂、成熟度低 |
| 技术成熟度 | 成熟 | — | — |
| 比冲 | 一般（1200-1600s） | >3000s | >3000s |
| 热负荷 | 高 | — | — |
| 寿命 | 低 | — | 高（>20000h） |

**选型结论**：目前SPT是最广泛使用的霍尔推力器类型，具有结构简单、技术成熟两大核心优势。

# 第三部分：空心阴极

## 十六、空心阴极概述

### 16.1 定义与功能

空心阴极是离子推力器和霍尔推力器的关键组件，其核心功能是发射电子，被称为电推力器的"心脏"。空心阴极的工作基于热电子发射原理：通过将低功函数的发射体加热至高温，使其表面电子获得足够能量克服表面势垒，从而向外发射电子。这些电子在电推进系统中承担两项核心任务：一是为推力器主放电室提供电离所需的电子，使推进剂（氙气）电离产生等离子体；二是作为中和器向推力器羽流发射等量电子，中和喷出的离子束流，防止航天器表面积累电荷。

根据材料和结构的不同，阴极技术可分为以下几类：

1. **金属热阴极**：以钨（W）、钽（Ta）、铼（Re）等难熔金属为发射体。金属阴极的功函较高，相应工作温度也更高。例如钨丝发射体的工作温度高达 2600 K，耗能很高且蒸发速度快，寿命只有几百小时。
2. **薄膜阴极**
3. **厚涂层阴极**
4. **金属陶瓷阴极**：以钡钨阴极（Ba-W）为代表，由烧结的多孔钨浸渍氧化物构成。
5. **其它发射材料阴极**：以六硼化镧（LaB₆）为代表。
6. **场发射阴极**

相比金属阴极，钡钨阴极和镧化物阴极具有明显优势——工作温度更低、发射电流密度更高。

### 16.2 在电推进系统中的作用

空心阴极在电推进系统中扮演着不可或缺的角色，具体应用于：

- **离子推力器**：需要两个空心阴极，一个作为主阴极（放电阴极）为放电室提供电离电子，另一个作为中和器（中和阴极）向羽流发射电子实现束流中和。
- **霍尔推力器**：需要一个空心阴极，既提供电离电子又同时实现羽流中和。

在电推力器中，羽流区的电位一般都高于触持极电位，从而从空心阴极中引出大量电子，供给推力器电离和中和所需。如果下游电位高于触持极电位，将从空心阴极中引出电子；如果下游电位低于触持极电位，将从空心阴极中引出离子。

## 十七、空心阴极工作过程与原理

### 17.1 工作过程详细分解

空心阴极的工作过程可分为三个阶段：

**第一阶段：加热阶段。** 首先将加热器通入加热电流，把发射体加热到额定的发射温度。对于钡钨发射体约需加热至 1100°C，对于 LaB₆ 发射体约需加热至 1700°C。加热器的作用不仅是升温，对于暴露大气后易受污染的钡钨发射体来说，加热器还具有在点火前**活化发射体**以消除污染效应的作用——通过高温使表面吸附的杂质脱附，恢复低功函数表面的活性。

**第二阶段：供气与点火。** 在发射体达到额定温度后，氙气流入到空心阴极管内。随后在触持极（点火电极）对阴极施加约数百伏的点火电压。点火电源为有限流电阻的直流高压电源。当空心阴极加热到足够温度（1100°C）时，逐渐升高点火电源电压，触持极电流逐渐增高（从几微安到几十微安）。当电压上升到某一点时，触持极电流突然跃升到几百毫安，表明气体放电已经建立。此时触持极电压降到很低，甚至降到氙的电离电位以下，也能维持较大的放电电流。

**第三阶段：自持放电。** 气体放电建立起来后，在空心阴极管内产生高密度的等离子体。等离子体与壁面相互作用，在发射体表面产生等离子体鞘层。发射的初始电子在鞘层电位加速下在空心阴极内运动，并与氙原子碰撞，电离氙原子，使得阴极筒内的等离子体得以维持。同时等离子体不断轰击加热发射体，从而维持阴极发射体的温度。一旦自持放电建立，加热器电源即可关闭，空心阴极进入**自持放电状态**——不再需要外部加热即可维持放电。点火电源也自动关闭，由低压触持极电源（直流稳压电源）维持放电。

### 17.2 关键物理机制

空心阴极的自持放电依赖于以下几个关键物理机制：

**热电子发射（Richardson-Dushman 方程）。** 电子发射密度与材料温度和材料固有功函有关，满足 Richardson-Dushman 方程。该方程描述了发射电流密度 J 随温度 T 和功函数 Φ 的变化关系：材料的功函数越低、温度越高，发射电流密度越大。逸出功 Φ 是温度的函数，假设逸出功随温度的变化近似为线性关系，可引入材料修正系数 D 进行修正。理查德森系数（发射常数理论值）对所有发射体均相同，为 120 A/(cm²·K²)。

**等离子体鞘层加速。** 发射体表面形成的等离子体鞘层提供了一个强电场区域，加速初始电子使其获得足够能量与中性氙原子发生碰撞电离。

**碰撞电离与等离子体维持。** 被鞘层加速的电子与氙原子碰撞，产生电离事件，释放出更多电子。这些新生电子继续参与后续的电离过程，形成链式电离反应，维持了阴极筒内的高密度等离子体。

**离子轰击加热。** 等离子体中的离子在鞘层电场作用下回轰发射体表面，其动能转化为热能，使发射体维持高温，从而实现自持。

**双极子单层低功函数表面。** 以钡钨发射体为例，其工作机理是通过浸渍氧化物（BaO、CaO、Al₂O₃）与基体钨在高温下的界面化学反应产生气体钡和氧化钡。这些产物扩散转移并吸附于发射体表面，形成钡在上、氧在下的双极子单层。双极子层有效降低了表面逸出功，氧化钡双极子的功函数为 **2.06 eV**。

## 十八、空心阴极结构

### 18.1 基本结构组成

空心阴极是一个圆柱形金属筒结构，比一般固体棒状阴极寿命长。其基本结构由以下五大组件构成：**阴极管**、**阴极顶板（孔板）**、**发射体**、**加热器**和**触持极**。此外还包括热屏、电接口（电极）、机械接口（法兰、进气管）等辅助组件。

空心阴极的前端有一阴极孔（由孔板小孔形成），金属筒内设有低功函数的发射体，金属筒的外壁缠有加热器，通电后对阴极进行加热。推进剂（氙气）通过空心阴极进入推力室，从空心阴极出来的基本是电子，也包括一些离子和中性原子。

### 18.2 关键部件详解

**阴极管。** 常用材料为抗溅射难熔金属，如铈钨、钽、钼、钼铼等合金。阴极管构成空心阴极的主体外壳，承载内部发射体并以电子束焊接方式与顶板连接。

**阴极顶板（孔板）。** 中心开有小孔（阴极孔），以增加阴极管内部的推进剂气压，从而易于产生内部等离子体放电。顶板材料一般为铈钨、钼、钍钨等合金，用电子束焊接于阴极管，亦可与阴极管组合成整体加工件。孔板的厚度一般大于 1 mm，由加工和焊接的工艺需要确定。孔板下游通常做 45° 倒角，以调整小孔长径比同时保证焊接所需的厚度。

**发射体。** 柱筒形发射体位于阴极管内，并紧贴阴极管内壁和顶板，是空心阴极最核心的部件。最常用的形状为圆筒型发射体；对于大电流空心阴极，可采用多通道发射体以增大发射面积。发射体的表面积由所需发射电流和发射电流密度确定，发射电流密度 J 通常为 **1~10 A/mm²**。

电推进阴极发射体主要有两种材料：

- **钡钨发射体（Ba-W）**：由烧结的多孔钨浸渍氧化钡（BaO）、氧化钙（CaO）和氧化铝（Al₂O₃）的混合物构成，其中多孔钨为基体（空隙度一般约为 80%），混合物为源材料。三种氧化物的分子比例有 5:3:2、4:1:1、3:1:1 等，以 **4:1:1 最常用**。功函数约为 **2.06 eV**。
- **六硼化镧发射体（LaB₆）**：一般由粉末加压烧结的多晶结构棒料经机械加工成型。LaB₆ 通过活性元素镧降低表面功函数，多晶 LaB₆ 的功函数为 **2.67 eV**。

选择有低功函数的发射体可显著增加电流发射密度或降低发射体工作温度。

**加热器。** 作用是将发射体加热至额定的点火温度，保证在发射体上形成低功函数表面并产生需要的电子发射密度，使阴极能在较低电压下可靠点火。加热器的设计参数包括：加热丝直径、螺旋陶瓷槽深、螺旋陶瓷螺距、螺纹陶瓷槽底部直径、螺纹陶瓷内径/外径、陶瓷高度，以及加热丝电阻和功率。根据估算的加热功率，通过热仿真确定是否满足工作温度要求。加热丝的可选材料为熔点较高的钨丝、钨钼合金丝、钨铼合金丝或钽丝，其中**钨铼合金丝**的性能比较理想。

**触持极。** 触持极与阴极的间距一般为 **1~2 mm**。其作用有二：第一，在施加点火电压后，在阴极与触持极间实现电弧放电点火，并在适当的工作电压下维持稳定的工作电流发射；第二，对阴极孔、顶板和加热器提供溅射腐蚀的**防护功能**。触持极应由钼（Mo）、钛（Ti）、石墨（C）等抗溅射腐蚀材料制成。触持极中心孔直径设计遵循：有加热器时，中心孔直径约为孔板小孔直径的 1~10 倍；无加热器时，中心孔直径约为孔板小孔直径的 0.1~2 倍。触持极与其余部分之间需要绝缘，绝缘判据为**帕邢定律**（Paschen's Law）。

**热屏。** 材料选用钼、钽、铌、钛等难熔金属，一般为圆筒状或金属箔卷绕多层，可有规律地开槽以延长热传导路径。要求反射率高、耐高温，以减少辐射热损失，提高热效率。

**电接口与机械接口。** 电极材料可选用钨、钼、铜、不锈钢、镍、钽、瓷封合金。陶瓷绝缘材料可选用氧化铝、氧化铍、刚玉、BN（氮化硼）。空心阴极通过法兰安装到推力器上，安装法兰需满足阴极最小包络尺寸要求。进气管内径与推进剂流量成比例，壁厚需保证气密性、机械强度和装配弯管的工艺性要求，同时保证工作时气管末端温度不能太高。

## 十九、空心阴极配电

空心阴极的配电系统是阴极正常启动和稳定工作的关键保障，涉及点火电源和触持极电源两类电源的协调工作。

**点火电源。** 采用有限流电阻的直流高压电源。当空心阴极加热到足够温度（1100°C）时，逐渐升高点火电源电压。在此过程中，触持极电流逐渐增高（从几微安到几十微安）。当电压上升到某一点时，触持极电流突然跃升到几百毫安，标志着气体放电的建立。此后触持极电压降到很低，甚至降到氙的电离电位以下，也能维持较大的放电电流。

**触持极电源。** 采用直流稳压电源。在阴极成功点火后，点火电源自动关闭，由低压触持极电源接替维持放电。

**工作流程总结**：
1. 加热器通电，将发射体加热至额定点火温度（Ba-W 约 1100°C，LaB₆ 约 1700°C）。
2. 通入氙气至阴极管内。
3. 点火电源施加数百伏高压，在发射体与触持极之间引发放电。
4. 放电建立后，点火电源关闭，触持极电源连续供电维持放电。
5. 自持放电建立后，加热器电源关闭，阴极进入完全自持工作状态。

## 二十、放电特性与放电模式

### 20.1 放电特性曲线

空心阴极的放电特性通过实验测量获得。典型实验中，空心阴极对阳极板放电，且保持阳极板与触持极之间的距离不变。主要采集在固定的放电电流下，放电电压值及其振荡幅度随阴极流率（氙气流量）的变化。

放电性能随流率的变化呈现两种明显不同的模式，两种模式之间的过渡区域对应着放电特性的急剧变化。

### 20.2 主要放电模式

**亮斑状模式（Spot Mode）。**

发生条件：氙气流量比较大时（例如 **≥ 1.50 ml/min**）。

特征：
- 放电电压值**较低**。
- 放电电压的振荡幅度一直维持在**较低**的水平，放电过程稳定。
- 放电羽流比较稀薄，仅在阴极小孔出口附近存在一明显的**亮斑**。
- 整体工作状态稳定可靠，是电推进系统正常运行时希望维持的模式。

**羽毛状模式（Plume Mode）。**

发生条件：氙气流量较小时（例如 **≤ 1.10 ml/min**）。

特征：
- 阴极推进剂流率的略微变化，都会使放电电压值**大幅度**地变化。
- 放电电压的振荡幅度也随阴极流率**大幅度**地变化。
- 阴、阳极间隙内的放电羽流整体上呈现出**羽毛状**。阴极流率越小，羽毛状的放电羽流在间隙内弥漫越强，并且逐渐向间隙外扩展。
- 放电电压**较高**、电压振荡幅度**较大**，工作稳定性差。

### 20.3 不同模式的特征与切换

| 特征 | 亮斑状模式 (Spot Mode) | 羽毛状模式 (Plume Mode) |
|------|----------------------|------------------------|
| 氙气流量 | 较大（≥ 1.50 ml/min） | 较小（≤ 1.10 ml/min） |
| 放电电压 | 较低 | 较高 |
| 电压振荡幅度 | 较小 | 较大 |
| 羽流形态 | 稀薄，小孔附近亮斑 | 羽毛状弥漫 |
| 稳定性 | 稳定 | 对流率变化高度敏感 |
| 对推进剂流率的灵敏度 | 低 | 极高 |

两种模式之间存在过渡区（流量约在 1.10~1.50 ml/min 之间）。在工程应用中，应确保阴极工作在 Spot Mode 下，以保证放电的稳定性和推力器的正常工作。进入 Plume Mode 不仅会导致放电不稳定，还会因电压升高增加溅射腐蚀，缩短阴极寿命。

## 二十一、构型与加热机制

### 21.1 不同构型对比

空心阴极的几何构型和尺寸取决于要求它们发射的电流大小。根据阴极孔板小孔的特征，空心阴极可分为 A 型、B 型和 C 型三种构型。

不同应用场景对应不同的小孔孔径：

| 应用类型 | 孔径范围 |
|----------|----------|
| 离子推力器中和器 | < 0.3 mm |
| 离子和霍尔推力器阴极 | 1~3 mm |
| 大功率离子和霍尔推力器阴极 | > 3 mm |

**A型空心阴极。** 具有一个大长径比的小孔。一般工作在低电流（1 A 或更低）和相对较高的内部气压下。主要加热机制为等离子体电阻加热和孔加热模式加热。

**B型空心阴极。** 具有一个直径通常大于长度的孔。工作在较低的内部气压下，适用于中等电流范围（几安培至几十安培）。加热机理为电子或离子对发射体的轰击，或两者皆有。

**C型空心阴极。** 没有节流孔（无小孔构型）。发射体区的中性气体密度梯度更大，但通常各处有更小的内部压强。通常用于大电流阴极（上百安培）。加热机制一般是离子对发射体的轰击。

三种构型综合对比：

| 构型 | 孔特征 | 内部气压 | 电流范围 | 主要加热机制 |
|------|--------|---------|---------|------------|
| A型 | 大长径比小孔 | 高 | 低电流（1 A 或更低） | 等离子体电阻加热 + 孔加热 |
| B型 | 孔直径 > 长度 | 较低 | 中等电流（几~几十 A） | 电子/离子轰击 |
| C型 | 无节流孔 | 低 | 大电流（上百 A） | 离子轰击 |

### 21.2 加热方式

空心阴极的加热机制与内部气压密切相关。中性气体压强越低，等离子体电阻越低，电子温度升高，鞘层电势高，等离子体电阻加热越小，导致更少的电子轰击和更多的离子轰击加热。

**自加热（自持加热）。** 一旦气体放电建立并进入自持状态，等离子体中的离子在鞘层电场加速下轰击发射体表面，将动能转化为热能，从而维持发射体的高温。在此阶段可以关闭外部加热器电源。不同构型的自加热机制有所差异：
- A 型：以等离子体电阻加热和孔加热为主。
- B 型：电子或离子（或两者）对发射体的轰击加热。
- C 型：以离子对发射体的轰击为主。

**外加热。** 在阴极启动的点火阶段，由于发射体尚未达到足够温度，无法产生足够的热电子发射，需要外部加热器将发射体预热至额定工作温度。此外，对于钡钨发射体，外加热还具有活化发射体、消除表面污染的作用。

## 二十二、发射体材料

### 22.1 常用发射体材料

发射体是空心阴极最核心的部件，其材料选择直接影响阴极的发射性能、工作温度和寿命。可供挑选的发射体材料有：金属、氧化物、钡钨、镧化物和碳材料。电推进空心阴极中最常用的两种发射体材料为钡钨（Ba-W）和六硼化镧（LaB₆）。

**钡钨发射体（Ba-W）。** 由烧结的多孔钨基体浸渍氧化钡（BaO）、氧化钙（CaO）和氧化铝（Al₂O₃）的混合物构成。多孔钨空隙度一般约为 **80%**。三种氧化物的分子比例以 **4:1:1**（BaO:CaO:Al₂O₃）最常用，其他可选比例有 5:3:2、3:1:1 等。工作温度约为 **1100°C**。其工作机理为：浸渍氧化物与基体钨在高温下发生界面化学反应，产生气体钡和氧化钡，这些产物扩散转移并吸附于发射体表面，形成钡在上、氧在下的双极子单层，有效功函数可降至 **2.06 eV**。

**六硼化镧发射体（LaB₆）。** 一般由粉末加压烧结的多晶结构棒料经机械加工成型。通过活性元素镧降低表面功函数，多晶 LaB₆ 的功函数为 **2.67 eV**。工作温度约为 **1700°C**。

### 22.2 材料性能对比

三种发射体材料的主要性能参数综合对比如下：

| 性能参数 | 氧化物阴极 | 钡钨阴极（Ba-W） | 六硼化镧阴极（LaB₆） |
|----------|-----------|----------------|-------------------|
| 工作温度 | ~950°C | ~1100°C | ~1700°C |
| 加热功率 | 小 | 小 | 大 |
| 最大发射电流 | ~2 A/cm² | ~10 A/cm² | 60~100 A/cm² |
| 抗中毒能力 | 差 | 中 | 强 |
| 耐轰击能力 | 差 | 中 | 强 |
| 功函数 | — | ~2.06 eV | ~2.67 eV |

综合比较：
- **钡钨阴极**的突出优势在于功函数低、工作温度适中、加热功率小，但其抗中毒能力和耐轰击能力中等。
- **LaB₆ 阴极**的最大优势在于发射电流密度极高（60~100 A/cm²）、抗中毒和耐轰击能力最强，但需要更高的加热功率和工作温度（1700°C），且功函数（2.67 eV）高于钡钨阴极。
- **氧化物阴极**工作温度最低、加热功率最小，但在抗中毒和耐轰击方面性能较差，最大发射电流也仅为约 2 A/cm²。

"理想"的发射体应同时具备高发射系数、低功函数、强抗中毒能力和寿命期内稳定发射的特点。实际选材时需要根据具体应用需求在这些性能之间做出权衡。

### 22.3 材料退化与失效机制

发射体材料的退化与失效是制约空心阴极寿命的关键因素，主要表现为以下几个方面：

**蒸发损耗。** 发射体在高温工作状态下，表面材料持续蒸发。蒸发速率与工作温度密切相关——温度越高，蒸发越剧烈。例如钨丝发射体在 2600 K 工作温度下蒸发速度很快，寿命只有几百小时。钡钨发射体的活性物质（Ba、BaO）在高温下不断蒸发消耗，导致表面双极子层逐渐衰减，功函数上升，发射能力下降。

**表面污染与中毒。** 发射体暴露大气后，表面会吸附水蒸气、氧气等杂质，形成污染层，导致功函数升高。对于钡钨发射体，这种污染效应尤为显著。因此在每次点火前需要进行活化处理——通过加热器将发射体加热至高温，使表面吸附的杂质脱附，恢复低功函数表面的活性。在轨运行中，推进剂中的微量杂质（如氧、水蒸气）也可能导致发射体逐渐中毒。

**离子溅射腐蚀。** 等离子体中的高能离子持续轰击发射体表面，造成材料溅射。溅射不仅直接减薄发射体，还会破坏表面的低功函数双极子层。在 Plume Mode 下，放电电压较高，离子能量增大，溅射腐蚀加剧。触持极的设计目的之一就是保护阴极孔、顶板和加热器免受溅射腐蚀。

**基体材料退化。** 对于钡钨发射体，多孔钨基体在长期高温运行中可能发生晶粒长大、孔隙结构变化，影响活性物质的浸渍和输送通道。对于 LaB₆ 发射体，多晶结构在高温下可能发生晶界迁移和晶粒粗化。

**热循环疲劳。** 阴极在轨运行中经历多次点火-熄火热循环。各部件由于热膨胀系数的差异产生热应力，可能导致发射体与阴极管之间的界面脱层、焊接裂纹等机械失效。钡钨发射体中浸渍物与钨基体的热膨胀系数不同，反复热循环可能导致浸渍物分布不均和局部耗尽。

综上，发射体寿命受蒸发速率、污染程度、溅射强度和热循环次数等多因素耦合影响。在工程实践中，通过优化工作参数（避免进入 Plume Mode）、选用高抗溅射材料、优化热设计与结构设计等手段来延长发射体寿命。

## 二十三、空心阴极设计方法

### 23.1 设计概述与流程

空心阴极的设计目标是**最大程度地降低阴极功耗和工质流率**，同时保证阴极的电子发射能力和工作寿命，满足推力器工作的需要。空心阴极消耗的功率（包括放电功率和加热功率）不是推力器推进剂加速所必需的，是推力器功率与效率的一大损耗；空心阴极消耗的工质不参与推力器推进剂的加速，是推力器比冲的一大损耗。

**研制流程**分为五个阶段：

1. **研制目标确定**：根据背景任务要求，进行任务分析，制定实现方案，完成关键技术攻关，开展原理样机研制、调试和试验。
2. **技术指标确定**：根据电推力器单机任务指标进行分解，确定放电电流、点火启动时间、寿命、点火次数等主要技术指标，初步确定系统的电源和推进剂供给能力。首次研制的产品以关键技术攻关和功能实现为重点，同时兼顾尺寸、质量、寿命等指标。
3. **原理样机设计**：功能验证阶段。
4. **工程样机设计和验证**：环境适应性、寿命、可靠性验证阶段。
5. **飞行样机设计和应用**：状态固化与批量生产阶段。

**设计考虑因素**涵盖五大类：

| 因素类别 | 具体内容 |
|----------|----------|
| 发射体种类 | 钡钨（Ba-W）、六硼化镧（LaB₆）、氧化物等 |
| 基本结构 | 有无加热器、阴极顶孔板结构、发射体结构、绝缘结构等 |
| 工作点 | 放电电流、工质质量流率 |
| 供电方式 | PPU 的供电参数和方式 |
| 供气 | 推进剂种类、纯度和杂质含量 |

### 23.2 组件设计（发射体、阴极管、加热器等）

#### 23.2.1 孔板设计

孔板（阴极顶板）的小孔构型决定了空心阴极的构型分类和加热机制。根据小孔长径比的不同，分为三种构型：

| 特征 | A型 | B型 | C型 |
|------|-----|-----|-----|
| 小孔长径比 | 大 | 适中 | 无小孔 |
| 内部气压 | 高 | 较低 | 低 |
| 适用范围 | 低电流（≤1 A） | 中等电流（几~几十 A） | 大电流（上百 A） |

孔板厚度一般大于 1 mm，由加工和焊接的工艺需要确定。孔板下游采用外侧 45° 倒角，用于调整小孔长径比同时保证焊接所需的厚度。

#### 23.2.2 发射体设计

**材料选择**：钡钨（Ba-W）发射体工作温度低、加热功率小；六硼化镧（LaB₆）发射体发射电流密度高、抗中毒能力强。

**形状选择**：圆筒型发射体为最常用形式，适用于常规空心阴极；多通道发射体可增大发射面积，适用于大电流空心阴极。

**尺寸确定**：发射体表面积由所需发射电流和发射电流密度确定。关键设计参数包括发射体直径（影响放电电流大小）、发射体长度、发射体厚度（mm），以及发射电流密度 J = **1~10 A/mm²**。

#### 23.2.3 触持极设计

触持极材料选择耐高温、抗溅射材料，如石墨、钛合金等。中心孔直径的设计规则为：

- **有加热器**：中心孔直径约为孔板小孔直径的 **1~10 倍**
- **无加热器**：中心孔直径约为孔板小孔直径的 **0.1~2 倍**

触持极顶厚度根据材料抗溅射性能以及设计寿命计算。触持极与其余部分绝缘，绝缘判据依据**帕邢定律**（Paschen's Law）。

#### 23.2.4 加热器设计

加热器设计参数包括：加热丝直径、螺旋陶瓷槽深、螺旋陶瓷螺距、螺纹陶瓷槽底部直径、螺纹陶瓷内外径、陶瓷高度，以及加热丝电阻和功率。设计需根据估算的加热功率通过热仿真确定是否满足工作温度要求，如不满足则重新调整。

加热丝可选材料为熔点较高的**钨丝、钨钼合金丝、钨铼合金丝或钽丝**，其中**钨铼合金丝**的性能较为理想。

#### 23.2.5 热屏设计

热屏材料选用钼、钽、铌、钛等难熔金属，结构一般为圆筒状或金属箔卷绕多层，可有规律地开槽以延长热传导路径。要求反射率高、耐高温。

#### 23.2.6 电接口与机械接口设计

**电接口**：参考电真空行业电极设计，考虑焊接性能。电极材料包括钨、钼、铜、不锈钢、镍、钽、瓷封合金；陶瓷材料包括氧化铝、氧化铍、刚玉、BN（氮化硼）。

**机械接口**：空心阴极通过安装法兰连接到推力器上，需满足阴极最小包络尺寸要求。进气管内径与推进剂流量成比例，壁厚需保证气密性、机械强度和装配弯管的工艺性，同时需保证工作时气管末端温度不能太高。

### 23.3 关键设计参数

| 设计参数 | 典型数值/范围 |
|----------|---------------|
| 发射电流密度 J | 1~10 A/mm² |
| 孔板小孔构型 | A型（≤1 A）、B型（几~几十 A）、C型（上百 A） |
| 孔板厚度 | >1 mm |
| 孔板外侧倒角 | 45° |
| 有加热器触持极中心孔 / 孔板小孔直径 | 1~10 |
| 无加热器触持极中心孔 / 孔板小孔直径 | 0.1~2 |
| 加热丝材料 | 钨丝、钨钼合金丝、钨铼合金丝（最优）、钽丝 |
| 热屏材料 | 钼、钽、铌、钛 |
| 触持极材料 | 石墨、钛合金 |
| 绝缘判据 | 帕邢定律（Paschen's Law） |

## 二十四、空心阴极寿命

### 24.1 寿命定义与指标

空心阴极的寿命指其在规定工况下保持正常电子发射能力的工作时长，通常以**工作小时数**或**点火循环次数**衡量。寿命指标根据配套推力器的任务需求确定，包括持续工作时间、点火启动次数、放电电流稳定性等。

### 24.2 影响寿命的主要因素

限制空心阴极寿命的主要因素有六项：

1. **发射体源材料耗尽**：发射体中的活性物质（如钡、氧化钡）在高温下持续消耗，最终耗尽导致发射能力丧失。
2. **发射体有效发射表面被难挥发沉积物覆盖**：工作过程中产生的沉积物覆盖发射表面，阻碍电子发射。
3. **源材料活性分子不能到达发射体表面**：发射体内部通道堵塞或表面污染，阻止活性分子扩散迁移。
4. **触持极、顶板、加热器被溅射腐蚀损坏**：等离子体中的高能离子对结构部件的溅射腐蚀，最终导致结构失效。
5. **加热器损坏**：加热丝在高温下的熔断或氧化损坏。
6. **发射体化学中毒**：发射体材料与活性气体（主要是氧和水）发生化学反应，导致功函数升高、发射能力下降。

#### 发射体化学中毒

发射体中毒表现为电子发射能力降低、工作温度升高、工作寿命缩短。对 LaB₆ 和 Ba-W 发射体而言，引起化学中毒的主要活性成分为**氧**和**水**。LaB₆ 相较于 Ba-W 具有更强的抗中毒能力。

### 24.3 寿命评估与延寿方法

**抗中毒措施**（延寿方法）包括：

- **发射体材料选择**：优先选择抗中毒能力强的材料（如 LaB₆）
- **使用和存储条件控制**：避免暴露于含氧和含水环境中
- **真空点火前的预处理措施**：在点火前进行除气和激活处理
- **推进剂纯度控制**：严格控制推进剂中的氧和水分含量
- **充分的寿命试验验证**：通过长期工作试验评估实际寿命
- **结构部件抗溅射设计**：优化触持极顶厚度和材料选择

## 二十五、仿真与试验验证

### 25.1 仿真方法

#### 25.1.1 热仿真

通过数值计算模拟点火过程与热稳态时的温度分布，验证工作温度能否满足需求。验证目标：
- 无超温点
- 发射体达到工作温度
- 点火启动时间符合要求

#### 25.1.2 流场仿真

计算阴极内部放电区域的气压分布，验证孔板小孔和触持极顶孔设计的合理性。可采用两种方法：
- **PIC 法**（Particle-in-Cell，粒子网格法）：追踪粒子运动，模拟等离子体行为
- **MHD 法**（Magneto-hydrodynamics，磁流体动力学法）：建立磁流体模型，仿真阴极工作过程

#### 25.1.3 力学环境仿真

通过有限元分析计算空心阴极在承受力学载荷（震动、冲击、加速度）时各结构组件的可靠性，对结构强度进行评估。

### 25.2 试验验证技术

| 验证类别 | 验证内容 | 关键参数/指标 |
|----------|----------|---------------|
| 加热器性能测试 | 发射体温度与加热器功率的关系 | 温度—功率曲线 |
| 点火启动性能测试 | 加热功率—点火电压—点火时间—工质流量的关系 | 点火时间一般 5~10 分钟 |
| 放电工作性能测试 | 发射电流—工质流量—放电电压的关系 | 发射电流满足配套推力器需求 |
| 持续工作能力测试 | 在要求工况下长时间放电工作的稳定性 | 持续工作时间满足推力器需求 |
| 多次点火能力测试 | 点火放电的重复性和可靠性 | 多次点火次数满足推力器需求 |

## 二十六、工程样机与飞行应用

### 26.1 典型工程样机

工程样机阶段的设计重点在于**环境适应性、寿命、可靠性**等关键技术攻关、原材料选型、工艺可行性及寿命可靠性方面的进一步优化设计。工程设计内容涵盖：

| 设计类别 | 具体内容 |
|----------|----------|
| 结构设计 | 在原理样机的基础上进一步优化 |
| 寿命设计 | 发射体、阴极顶、触持极顶的寿命评估 |
| 可靠性设计 | 加热器可靠性、触持极绝缘性 |
| 安全性设计 | 电安全、气路安全 |
| 原材料选型 | 关键材料的筛选与鉴定 |
| 工艺控制 | 阴极顶小孔加工、陶瓷-金属封接焊接等 |
| 抗中毒设计 | 发射体材料选择、使用和存储条件、真空点火前的措施、推进剂纯度控制 |

工程样机的试验验证包括：工作性能试验、力热环境试验、寿命试验及专项试验。

### 26.2 飞行应用案例

飞行样机以工程样机为**基线**，固化技术状态、工艺参数、试验流程和试验参数，保证批量生产过程中产品的**一致性**，以型号应用的合格产品为研制目标。

**全寿命周期管理**分为三个阶段：

| 阶段 | 工作内容 |
|------|----------|
| 发射前准备阶段 | 发射前更换产品 |
| 在轨飞行初期 | 状态自检、系统气路除气、阴极预处理 |
| 在轨飞行期间 | 故障处理与状态监控 |

**三阶段研制总结**：

| 阶段 | 样机类型 | 研制重点 |
|------|----------|----------|
| 原理验证 | 原理样机 | 关键技术攻关、功能实现 |
| 工程验证 | 工程样机 | 环境适应性、寿命、可靠性、工艺 |
| 飞行应用 | 飞行样机 | 技术状态固化、产品一致性、全寿命周期管理 |
