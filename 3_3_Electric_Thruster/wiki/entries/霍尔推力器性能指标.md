# 霍尔推力器性能指标

> **来源**: [第7课-霍尔推力器_1.pptx](../raw/第7课-霍尔推力器_1.pptx) | **编号**: [REF-0006](../REFERENCES.md#ref-0006)

## 主要性能指标

霍尔推力器的主要性能指标包括[[电推进基本性能参数|推力、比冲、效率和功率]]等。

### 推力

推力是霍尔推力器产生的轴向作用力，其大小与离子质量流量和离子速度相关。加速电压效率是影响推力的重要因素。

### 比冲

比冲（Isp）是单位质量推进剂产生的冲量，表征推进剂的利用效率。霍推力器的比冲通常为1000~3500s，典型值约为1600s。比冲与加速电压效率相关。

### 推力功率比

推力功率比是衡量推力器在给定功率下产生推力能力的重要指标。霍尔推力器（SPT）的推力功率比约为**60 mN/kW**，远高于离子推力器的约33 mN/kW，这意味着在相同功率下霍尔推力器可以产生更大的推力。

### 推力效率

推力效率定义为推力器输出的轴向动能与输入总电功率之比。输入总电功率在SPT中除产生轴向动能外，还存在多种能量消耗机制，包括：

- 离子的电离耗能
- 离子轰击放电室壁并于其上累积电子复合带来的动能与电离能损失
- 电子轰击放电室壁释热
- 电磁辐射能量损失
- 径向与周向动能损失
- 阴极与磁铁能量损失

### 推力效率的组成

推力效率由以下分量构成：

| 效率分量 | 说明 |
|----------|------|
| 电效率 | 电功率转换效率 |
| 推进剂利用率 | 推进剂工质的利用效率 |
| 离子电流效率 | 离子电流占总电流的比例 |
| 离子加速效率 | 离子被电场加速的效率 |
| 推力修正系数 | 由多荷离子和束流发散角引起的修正 |

- 霍尔推力器的效率通常在 **30%~60%** 之间
- 离子推力器的效率通常在 **50%~70%** 之间

霍尔推力器效率通常低于离子推力器，这与其能量损耗机制更为复杂有关（如壁面能量损耗、电子传导损耗等）。

## 典型性能指标范围

| 指标 | 范围 |
|------|------|
| 推力 | 5~650 mN |
| 功率 | 100 W~10 kW |
| 比冲 | 1000~3500 s |
| 效率 | 30%~70% |
| 推力功率比 | ~60 mN/kW |
| 最小冲量 | 0.15~20 N·s |
| 总冲 | 3×10⁴~2×10⁷ N·s |

## 与化学推进和离子推力器的对比

| 对比指标 | 化学推进 | 离子推力器 | 霍尔推力器（SPT） |
|----------|----------|------------|-------------------|
| 比冲 | ~300s | 较高 | ~1600s（1000~3500s） |
| 推力功率比 | - | ~33 mN/kW | ~60 mN/kW |
| 推力密度 | - | 较低 | 高 |
| 推力重量比 | - | 较小 | 大 |
| 结构和配电 | 简单 | 复杂 | 简单 |
| 效率 | - | 50%~70% | 30%~60% |
