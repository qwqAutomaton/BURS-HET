# 电子回流

> **来源**: [第4课-离子推进_2.pptx](../raw/第4课-离子推进_2.pptx) | **编号**: [REF-0003](../REFERENCES.md#ref-0003)

## 概念

电子回流（Electron Backstreaming）是指加速栅下游中和器发射的电子穿过栅极孔返流回放电室的现象。电子回流会降低推力器效率和性能，是需要避免的工作状态。

## 影响因素

### 加速栅极电压

改变加速栅极电压是影响电子回流的关键因素。加速栅极施加负电压的目的是建立一个势垒，阻止下游电子穿过栅极孔进入放电室。如果加速栅极负电压的绝对值不够大，势垒不足以阻止电子回流。

### 加速栅极孔半径

栅极腐蚀引起的加速栅极孔半径扩大会导致电子回流。随着推力器工作时间增加，加速栅极孔因离子溅射腐蚀而逐渐扩大，这使得下游电子更容易穿过栅极孔进入放电室，从而引发电子回流问题。这是制约栅极寿命的重要因素之一。
