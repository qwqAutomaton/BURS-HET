# 俄罗斯与欧洲霍尔推力器应用

> **来源**: [第8课-霍尔推力器_2.pptx](../raw/第8课-霍尔推力器_2.pptx) | **编号**: [REF-0007](../REFERENCES.md#ref-0007)

## 俄罗斯的应用

1972年前苏联研制的SPT在其"流星号"卫星上进行了首次飞行试验。

1976年SPT首次应用于GEO卫星的东西位置保持和重新定位。

此后，前苏联和俄罗斯研制了一系列高性能SPT，先后用于Potok、Louch、Gals、EXPRESS、EXPRESS-A、Sesat、YamaL、Energiya等系列卫星的南北位置保持、东西位置保持、姿态控制、倾角修正及重新定位等任务。

俄罗斯应用力学联合体在MSS-2500等卫星平台应用SPT-100系列霍尔电推进系统完成全部位保任务。

## 欧洲的应用

### 法国的SPT推力器（PPS-1350）

法国从1993年起成立了有CNRS、CNES、SEP和ONERA参加的等离子体推进研究组，并与俄罗斯多个单位合作开始了SPT的研制。

2001年12月，由法国SNECMA生产的两台PPS-1350和由俄罗斯Fakel生产的两台SPT-100用于法国的STENTOR（2210kg）卫星的南北位置保持和偏心率控制任务。

### SMART-1月球探测器

2002年10月，欧空局的SMART-1月球探测卫星采用两台SNECMA生产的PPS-1350G作为主推进器，在完成月球地质化学和月球南极探冰任务的同时，对电推进和相关科学仪器进行飞行验证。

| 参数 | 值 |
|------|-----|
| 电推进系统 | 霍尔电推进系统 (PPS-1350) |
| 推进剂 | 氙气 |
| 比冲 | 1640 s |
| 推力 | 6.80 × 10^-2 N |
| 任务状态 | 工作了6500h |

### 欧洲通信卫星平台

欧洲两大通信卫星制造商从2000年开始发展采用霍尔推力器进行南北位保任务的卫星平台：

- **泰雷兹-阿莱尼亚公司**：以"空间客车"系列卫星平台-4000为主，装有4台SPT-100霍尔推力器，用于南北位保，2005年2月首次发射成功。
- **阿斯特留姆公司**：主打欧洲星-3000，采用4台SPT-100霍尔推力器，卫星最大发射质量可达6150kg，2004年6月首颗星发射成功。
- **"阿尔法"超大型卫星平台（Alphabus）**：采用Snecma公司的PPS-1350霍尔电推进系统完成南北位保任务，2013年完成首发卫星发射。
- **小型GEO平台**：采用SPT-100和HEMP-3050组合的电推进系统完成位置保持（2007年启动）。

### Eutelsat-172b —— 欧洲首颗全电推通信卫星

欧洲空中客车防务与航天公司建造的Eutelsat-172b卫星于2017年6月1日发射，重约3.5吨，是欧洲建造的首颗全电推通信卫星。4个月后，卫星到达地球同步轨道的目标位置。

Electra平台基于OHB公司的SGEO平台进行开发，基本配置为4台大功率霍尔推力器，计划在轨道提升阶段使用两台推力器（需总功率9.6kW），位置保持阶段在每个轨道节点处采用一台推力器（每台最大功率3.2kW），推力器具有两种工作模式。
