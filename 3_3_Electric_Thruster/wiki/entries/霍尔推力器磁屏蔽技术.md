# 霍尔推力器磁屏蔽技术

> **来源**: [第8课-霍尔推力器_2.pptx](../raw/第8课-霍尔推力器_2.pptx) | **编号**: [REF-0007](../REFERENCES.md#ref-0007)

## 推力器通道壁面溅射侵蚀

推力器通道壁面溅射侵蚀是影响推力器运行稳定性和制约寿命的重要问题。推力器通道壁面溅射侵蚀过程取决于离子轰击条件，它与通道内的磁场构型设计与运行参数密切相关。

采用BN陶瓷材料的推力器通道寿命：
- SPT-100 通道寿命已达 8000h
- SPT-70 为 5000h
- 进一步推高BN材料通道的寿命已十分困难

## 磁屏蔽技术的发现

2010年，JPL的Ioannis G. Mikellides 等人在对BPT-4000 霍尔推力器进行10000h的长寿命实验的过程中发现，当寿命实验进行到5600h的时候，推力器的磁场与通道几何结构形成一种特殊的磁场构型，推力器的加速通道腐蚀速率大幅度降低甚至停止。

由于在该现象中磁场起到了屏蔽加速通道的效果，这种特殊的磁场构型称之为**磁屏蔽构型**。

## 磁屏蔽的磁场特点与原理

**磁场特点**：磁力线进入通道内部，深入到阳极附近，且与壁面不相交。

**原理**：
1. 磁力线的**等温、等势特性**，将阳极附近高电势、低电子温度引到通道壁面。
2. 通过壁面低电子温度降低壁面鞘层电势，减弱对进入鞘层内离子的加速；同时等势特性使得轴向电势梯度较弱，降低壁面附近离子的轴向加速。
3. 两者共同作用，大大减弱离子对壁面的撞击，提高寿命。

## 磁屏蔽技术的验证与影响

磁屏蔽技术在中等功率级推力器（BPT-4000、NASA-300-MS 和 H6MS）得到了效果的验证。

**磁屏蔽的附加影响**：

| 方面 | 影响 |
|------|------|
| 壁面削蚀 | 降低 |
| 壁面热流密度 | 降低，推力器整体温度下降 |
| 高比冲模式 | 高放电电压会降低磁屏蔽效果 |
| 振荡特征 | 比传统霍尔推力器多出一个振荡频率范围（75~90kHz） |
| 磁极顶表面 | 磁屏蔽磁力线收尾于磁极顶表面，导致磁极顶表面会产生削蚀，一定程度上影响羽流场的粒子成分 |
| 小功率推力器 | 应用磁屏蔽技术时会出现性能严重下降的问题 |
