# 节流元件-烧结型多孔材料

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 概述

"烧结型"多孔材料流量控制器的技术状态相对成熟，是 [[热节流流量控制器|流量控制器]] 中一种重要的节流元件类型。其核心零件是由金属多孔烧结材料形成的。

## 制造工艺

多孔材料是金属粉末颗粒在一定的温度和压力下通过烧结工艺成型。在烧结过程中金属颗粒不熔化，成型后颗粒与颗粒之间仍然存在很多微小的可供介质通过的缝隙。

## 材料选择

粉末冶金多孔金属材料有青铜、铜-镍、铝、普通钢以及不锈钢等。节流器要求多孔金属材料具有耐腐蚀、变形小、强度高、热容大以及焊接性较好等特点。

## 多孔不锈钢材料的特点

多孔不锈钢材料是节流器的优选材料，具有以下特点：

1. 强度好，具有一定的塑性，焊接性能较好
2. 使用温度达到 500°C
3. 耐腐蚀，可以进行清洗除污
4. 具有较强的热交换能力，热稳定性好
5. 在空间环境中结构性能稳定

## 工艺优势

多孔不锈钢材料在节流器加工过程中的加工工艺良好，能够通过焊接等手段很好地与节流腔组合，易于制成重量轻、结构紧凑的节流器。同时节流器在空间环境中性能稳定，能满足长寿命的要求。
