## 里程碑：唯一一次在轨测试

1995 年 3 月，日本空间宇航科学研究院研制的小功率 SF-MPDT 推进系统搭载 **H-II 火箭**升空，成功进行了**在轨测试**。发动机重复点火超过 **40,000 个脉冲**，验证了在轨推力性能。

这是 MPDT **唯一一次在轨测试**。虽然还不是真正意义上的高功率 MPDT，但其验证了大电流情况下的发动机工作状态和系统可靠性，为今后 MPDT 的研究和应用奠定了基础。

### 在轨测试系统参数

| 参数 | 数值 |
|------|------|
| 推进剂 | N₂H₄（肼） |
| 系统质量 | ＜41kg |
| 系统功率 | ＜430W |
| 点火频率 | 0.5-1.8Hz |
| 放电电流 | 6kA |
| 比冲 | ＞1000s |

## 大阪工业大学 — 四种 MPDT 原理样机

大阪工业大学在日本宇航探索局（**JAXA**）项目支持下开发了四种 MPDT 原理样机，最终目标是为**载人火星探测**开发一个辐射冷却的稳态 MPDT。

| 样机 | 年份 | 特点 |
|------|------|------|
| 永磁体多通道空心阴极稳态 MPDT | 2013 | 空心阴极 + 永磁体，水冷 |
| 永磁体稳态水冷 MPDT | 2015 | 永磁体 + 水冷 |
| 阳极辐射冷却 MPDT | 2015 | 阳极辐射冷却 |
| 全辐射冷却 MPDT | 2015 | 全辐射冷却，面向空间应用 |

从水冷到辐射冷却的演进路径，体现了日本向**空间可应用的全辐射冷却 MPDT**迈进的技术策略。
