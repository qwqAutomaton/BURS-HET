# 霍尔推力器放电室设计

> **来源**: [第8课-霍尔推力器_2.pptx](../raw/第8课-霍尔推力器_2.pptx) | **编号**: [REF-0007](../REFERENCES.md#ref-0007)

## 重要设计要求

放电室设计需满足以下五项重要要求：

1. 材料的二次电子发射性能
2. 材料的耐离子溅射能力
3. 结构的力学性能
4. 材料的耐高温能力
5. 绝缘性能

## 材料选择

放电室材料的二次电子发射系数是关键选择依据：

| 材料 | 二次电子发射系数评估 |
|------|----------------------|
| Al2O3 | 过高，不适用 |
| BN/SiO2 | 合适 |
| 纯BN | 合适 |

**BN/SiO2 综合优势**：
- 二次电子发射系数合适
- 耐溅射能力较好
- 加工性能好

## 结构设计

- 保证结构强度和绝缘性能良好
- 通道出口处增加**翻边结构**以延长寿命

## 热设计

1. 放电室温度最高，但导磁材料温度不能过高，应尽可能减少放电室与导磁底板的接触面积，降低热传导。
2. 放电室与金属接触位置需考虑高温下的热膨胀，预留足够的热胀空间，防止放电室因热应力破裂。
3. 热设计结果可通过简单的热学仿真进行确认和调整。
