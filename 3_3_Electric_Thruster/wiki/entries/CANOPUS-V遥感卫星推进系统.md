# CANOPUS-V遥感卫星推进系统

> **来源**: [第8课-霍尔推力器_2.pptx](../raw/第8课-霍尔推力器_2.pptx) | **编号**: [REF-0007](../REFERENCES.md#ref-0007)

## 卫星任务

CANOPUS-V遥感卫星的主要任务包括：

- 监测人为和自然紧急灾害情况
- 监测农业活动，自然资源尤其是水资源活动
- 观察土地利用率情况
- 执行对地球表面快速观测任务，根据各行业不同的利益需求监测指定地表情况

## 推进系统结构组成

CANOPUS-V卫星的推进系统包括以下单元：

| 单元 | 说明 |
|------|------|
| 推力器单元 | 包括两台SPT-50推力器（主份和备份） |
| 流量控制器 | 向主推力器和备份推力器供应氙气 |
| 气体压力控制单元 | 控制气体压力 |
| 氙气储存单元 | 储存推进剂氙气 |

## SPT-50 推力器

SPT-50是俄罗斯法克尔试验设计局研制的小功率霍尔推力器，用于CANOPUS-V遥感卫星的推进任务。

> 卫星于2015年5月6日莫斯科时间发射。
