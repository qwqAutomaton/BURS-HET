# 栅极组件几何参数设计

> **来源**: [第5课-离子推进_3.pptx](../../raw/第5课-离子推进_3.pptx) | **编号**: [REF-0004](../../REFERENCES.md#ref-0004)

## 影响因素

栅极组件几何参数设计需综合考虑以下因素：

1. 较高的束流密度需要减小屏栅厚度以及屏栅和加速栅之间的间距。这样，屏栅极的小孔孔径就可以减小，产生推力器的孔数量就增加。
2. 两栅的靠近程度受限于推力器的口径，而且放电室工作条件改变时，由于栅极温度分布引起的**栅极热形变**，使得栅极间距很难再减小。
3. 栅极系统的设计要使离子引出时不会直接轰击到加速栅上对其产生**溅射腐蚀**。
4. 加速栅厚度对离子引出性能的影响不大，所以通常加速栅做的比屏栅厚一些。
5. 将加速栅的负电压减小，从而减小轰击加速栅的交换电荷离子的动能，从而提高加速栅的寿命。但加速栅电压的最小值受**电子返流**的影响。
6. 如果不考虑加速栅腐蚀的负面影响，则可以提高加速栅电压，从而提高引出束流的密度，推力密度也就增大。但是，加速栅电压增大时（R变小），**束流发散角**也会增大。
7. 决定束流发散角的参数包括：归一化导流系数、净总加速电压比和栅间距。

> 参见《航天器推进系统及应用》P338

## 参数选取

屏栅孔径 d_s 和厚度 t_s 首先决定离子光学特性，特别是屏栅极孔径 d_s 参数成为设计离子光学系统其他栅极的基本参照尺寸。

国内外研究机构在大量试验数据的基础上，得到了栅极结构参数优选值（以下 d_s 为屏栅孔径基准值）：

| 参数 | 符号 | 优选范围 |
|---|---|---|
| 屏栅厚度相关参数 | t_s / d_s | 0.125 ~ 0.175 |
| 加速栅厚度相关参数 | t_a / d_s | 0.2 ~ 0.4 |
| 加速栅孔径相关参数 | d_a / d_s | 0.6 ~ 0.7 |
| 减速栅厚度相关参数 | t_d / d_s | 0.2 ~ 0.4 |
| 减速栅孔径参数 | d_d / d_s | 0.8 ~ 0.9 |

## 补偿设计（大口径）

一般大口径的离子光学系统都用**球面栅极**，以保证各栅极在热循环工况和力学环境中栅极形变方向的一致性。但采用球面栅极会明显增大束流发散，导致推力器的推力损失。

这种束流发散由两部分组成：
1. 由球面本身的形状产生的束流发散
2. 由球面栅极加工时造成屏栅极与加速栅极孔中心线的相对位移而产生的束流发散

为了使单孔束流的轨迹接近轴向，需要对其中一个栅极的孔中心距做调整。孔中心距小于 **0.5%** 的改变量就足以使得束流发散显著减小，这种孔中心距的改变称为**"补偿"**。

这种补偿作用是通过让每个单孔束流向推力器的轴向偏转，从而抵消由球面栅极产生的发散作用而实现的。
