# Bepi-Colombo水星探测器与T6离子推进

> **来源**: [第13课-电推进系统与卫星的集成.pptx](../raw/第13课-电推进系统与卫星的集成.pptx) | **编号**: [REF-0009](../REFERENCES.md#ref-0009)

## 任务概述

"贝皮-科伦布"（Bepi-Colombo）水星探测器由欧洲航天局（ESA）和日本宇宙开发研究机构（JAXA）联合研制，应用4台T6离子电推进系统把磁圈轨道器和星体轨道器送入水星轨道。于2018年10月20日发射，计划2025年到达水星。

## 探测器组成

Bepi-Colombo由三个主要部分组成：

| 组成部分 | 研制方 | 质量 | 科学仪器 | 功耗 |
|----------|--------|------|----------|------|
| 水星行星轨道器（MPO，主探测器） | 欧洲ESA | 1147 kg | 11台 | 174 W |
| 水星磁层轨道器（MMO，次探测器） | 日本JAXA | 275 kg | 5台 | 90 W |
| 水星转移模块（MTM） | 欧洲ESA | — | — | — |

## 水星转移模块（MTM）

MTM由太阳能电推进舱（SEPM）和化学推进舱（CPM）组成。

### 太阳能电推进舱（SEPM）

| 参数 | 数值 |
|------|------|
| 太阳电池翼总面积 | 33 m² |
| T6氙离子推力器数量 | 4台 |
| 每台推力器推力 | 170 mN |
| SEPM净质量 | 365 kg |
| 氙气（MPO用） | 230 kg |
| 氙气（MMO用） | 238 kg |

### 化学推进舱（CPM）

| 参数 | 数值 |
|------|------|
| 推进剂类型 | 双组元 |
| 20 N推力器（姿控） | 8台 |
| 4000 N推力器（轨道射入） | 1台 |
| CPM净质量 | 71 kg |
| 燃料（MPO用） | 156 kg |
| 燃料（MMO用） | 334 kg |

## T6离子推力器

T6是直径22 cm的离子推力器，继承了T5具有调节推力和比冲能力的设计。
