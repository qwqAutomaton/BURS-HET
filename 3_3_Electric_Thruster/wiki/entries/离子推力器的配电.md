# 离子推力器的配电

> **来源**: [第4课-离子推进_2.pptx](../raw/第4课-离子推进_2.pptx) | **编号**: [REF-0003](../REFERENCES.md#ref-0003)

## 配电要点

离子推力器的配电遵循以下基本原则：

- **阳极电位比阴极高**：阳极和阴极之间为放电电压，放电电压一般在 **20~40V**。
- **阴极和屏栅极电位相等**：这是为了保证等离子体电势比屏栅极电势高，从而有利于离子被屏栅极引出。
- **屏栅极电压**：决定了引出离子的能量，一般在 **1000V** 左右。
- **加速栅极电位**：为阻止下游的电子返流而为负值，一般在 **-200V** 左右。

## 需配电的部件

离子推力器需要配电的部件及所需电源数量：

| 部件 | 所需电源数量 |
|------|------------|
| 阳极 | 1 个电源 |
| （空心）阴极 | 3 个电源 |
| 屏栅极 | 1 个电源 |
| 加速栅极 | 1 个电源 |
| 中和器 | 3 个电源 |

## 接线方式

离子推力器有两种主要接线方式：

### 接线方式 1

屏栅极电源位于阳极和中和器之间。阳极电源与屏栅电源的输出正线合并，输出为同一端。NSTAR、LIPS200 均为此方式。

### 接线方式 2

另一种接线方式（具体电路布局有所不同，详见电路图），两种方式的主要区别在于电源接地参考点的选择和屏栅极电源的连接位置。

## 说明

不同推力器型号（如 NSTAR、LIPS200）可能采用不同的配电拓扑，但都需满足上述电压分配要求，确保等离子体稳定产生、离子有效引出以及电子返流的抑制。
