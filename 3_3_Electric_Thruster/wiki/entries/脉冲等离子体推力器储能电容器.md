# 脉冲等离子体推力器储能电容器

> **来源**: [第10课-脉冲等离子体推力器和真空电弧推力器.pptx](../raw/第10课-脉冲等离子体推力器和真空电弧推力器.pptx) | **编号**: [REF-0011](../REFERENCES.md#ref-0011)

## 功能与重要性

脉冲储能电容器是推力器的核心部件之一，担负着能量的存储和传递作用。其性能的优劣对推进系统性能有重要影响。

## 主要性能要求

对电容器性能的主要要求是：

1. 为了获得尽可能高的能量传输效率，电容器及其引线的电阻和电感要尽可能小（电容本身的损耗小）
2. 电容器要有尽可能高的能量密度，以保证系统的体积小、质量轻
3. 能在真空环境下长期可靠工作
4. 脉冲寿命长（>10^7次）

## 现有技术

这些要求常规产品满足不了，需专门研制。在已应用的PPT样机中（如LES-8/9、MDT-2A），大多采用**同轴、圆形单绕卷伸出箔纸膜（高介电常数介质膜）复合介质浸油电容器**。

实践证明，这种电容器具有工作电压高、通流能力强和寿命长的优点。缺点是能量密度较低，比能量（J/kg）还不够高，在推力器中，其质量占系统质量的25%~40%。

## 替代技术

为了解决能量密度问题，正在寻找性能更优的电容器：

- **金属化膜电容器（MF）**：能提供很高的功率
- **多层陶瓷膜电容器（MLC）**：具有很低的电感和极高的能量密度

两者都可在100 Hz的频率和良好的效率下运行，但寿命如何还有待进一步证实。
