# 放电室磁场的作用与构型

> **来源**: [第4课-离子推进_2.pptx](../raw/第4课-离子推进_2.pptx) | **编号**: [REF-0003](../REFERENCES.md#ref-0003)

## 磁场的作用

磁场是提升[[柱形会切场放电室概述与参数设计]]和推力器性能的关键，主要用来约束电离室内由气体放电形成的等离子体。没有磁场的电离室几乎是无法正常工作的。

使推进剂原子电离的主要是空心阴极发射的原初电子，而实际上原初电子的平均自由程远大于电离室的尺寸。并不是每个原初电子都会撞击到中性原子，如果不采取措施，大部分的原初电子会直接撞击到阳极（电离室壁）上，而起不到电离的作用。

为了解决上述问题，在电离室中加入磁场，使电子在磁场的作用下做螺旋运动，增加了电子在电离室中运动的距离，因此也就增加了电子与中性原子撞击的机会，提高了电离效果。

## 磁场构型的发展历程

国外离子推力器磁场构型经历了以下发展过程：

**发散场 -> 径向场 -> 多极场 -> 尖角场 -> 环尖场**

发展过程中推力器性能不断得到提高。目前，只有两种磁场构型仍在离子推力器中得到使用：

1. **发散式螺线管磁场**
2. **环尖磁场**（环形会切磁场）

除英国的 T5 和 T6 离子推力器外，其余离子推力器都采用环尖磁场构型。

## 磁场构型的实现——永磁体布置

目前的离子推力器多采用会切磁场构型，由永磁体布置实现。

### (1) 环形会切场——环状和块状永磁体

在电离室的底面上靠近空心阴极的外圈安装一个永磁环，在电离室圆柱壁面上安装两排永磁块，从而形成环形会切磁场，磁力线中止于阳极表面。一般采用钐钴永磁体（SmCo）。

### (2) 柱形会切场——柱状永磁体 + 极靴

采用柱状永磁体配合极靴（软磁材料）形成柱形会切磁场。

## 两种会切磁场的对比

| 对比项目 | 环形会切场 | 柱形会切场 |
|---------|-----------|-----------|
| 重量 | 较轻（无需屏栅筒和极靴） | 较重（增加了屏栅筒和极靴，极靴为软磁材料，密度较大） |
| 放电损耗 | 较高 | 较低 |
| 束流均匀性 | 较好 | 较差 |
| 放电电压 | 较低 | 较高 |
| 双荷离子比 | 较低 | 较高 |
| 寿命与可靠性 | 较好 | 较差 |

环形会切场在重量方面较柱形会切场存在优势，其主要原因是柱形会切场相比环形会切场增加了屏栅筒和极靴，又由于极靴一般为软磁材料，密度较大。柱形会切场比环形会切场具有放电损耗低的优点，但其较差的束流均匀性、较高的放电电压和双荷离子比，使其在寿命和可靠性方面劣于环形会切场。
