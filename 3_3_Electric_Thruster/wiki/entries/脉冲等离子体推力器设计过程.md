# 脉冲等离子体推力器设计过程

> **来源**: [第10课-脉冲等离子体推力器和真空电弧推力器.pptx](../raw/第10课-脉冲等离子体推力器和真空电弧推力器.pptx) | **编号**: [REF-0011](../REFERENCES.md#ref-0011)

## 设计步骤

### 步骤1：确定元冲量和总脉冲数

根据给定的飞行任务要求（已知需要提供的总冲Itot和执行某种控制功能的推力F），选定一个脉冲频率f，然后计算出元冲量Ibit和总脉冲数Np：

- Ibit = T / f
- Np = Itot · f / T

### 步骤2：确定储能电容器

选定一种推力器喷口结构（尾部供给或侧边供给），用前述有关公式即可求出放电能量E₀。知道E₀后，选定一个工作电压U，即可算出储能电容器的容量C。根据能量、工作电压和总的脉冲数（脉冲寿命），选定一种合适的储能电容器产品，可决定储能电容器的质量mc。

### 步骤3：确定工质

求出比冲Is，然后算出工质的质量：

mp = Itot / Is

知道了mp，按公式即可求出工质暴露于放电的表面积A及工质棒的长度。根据放电的能量、选定的工质供给方式，利用运行的经验，决定出电极板的宽度、极距和极板加速部分的长度。

## 设计注意事项

这种计算不是唯一的，它可根据飞行任务的要求和应用资源的限制，从不同的角度（功率最少或系统质量最小），算出几组性能参数，进行比较，然后选择其中最合适的一组。
