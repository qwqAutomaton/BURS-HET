# NSTAR PPU组成原理

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 概述

NSTAR [[电源处理单元PPU概述|PPU]] 是深空一号（DS1）探测器离子推进系统的电源处理单元，具有典型的参考价值。

## 接线方式

NSTAR PPU采用了一种特殊的接线方式：
- 将阳极电源与屏栅电源的输出正线合并，输出为同一端
- 阳极（放电）电源和主阴极触持极电源合并

这种接线方式简化了电路连接，减少了高压绝缘需求。

## 电路组成

NSTAR PPU包含以下主要电源电路：

| 电源类型 | 拓扑结构 | 主要特点 |
|----------|----------|----------|
| [[束流屏栅极电源|屏栅（束流）电源]] | 全桥拓扑，多模块串联 | 输出1000V，提供80%功率 |
| [[放电阳极电源|放电（阳极）电源]] | H桥臂形供电级 | 电感输出滤波 |
| 加速栅极电源 | 全桥臂，共用上桥臂 | 四路共享方案 |
| 中和器触持电源 | 全桥臂，共用上桥臂 | 独立PWM控制 |
| 阴极加热电源 | 全桥臂，共用上桥臂 | 独立PWM控制 |
| 中和器加热电源 | 全桥臂，共用上桥臂 | 独立PWM控制 |
| [[放电室与中和器点火电源|放电室点火电源]] | 高压脉冲 | 30～650V击穿电压 |
| [[放电室与中和器点火电源|中和器点火电源]] | 高压脉冲 | 高压电弧启动 |

## NSTAR PPU的典型参数

- **输入**：80～160VDC（太阳能电池）、28VDC（控制电源）
- **屏栅电源输出电压**：最高1000V
- **屏栅电源功率占比**：约80%
- **各模块输入输出转换**：80VDC → 300VDC（单模块）
