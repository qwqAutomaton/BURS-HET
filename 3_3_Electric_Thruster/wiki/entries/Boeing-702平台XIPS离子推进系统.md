# Boeing 702平台XIPS离子推进系统

> **来源**: [第13课-电推进系统与卫星的集成.pptx](../raw/第13课-电推进系统与卫星的集成.pptx) | **编号**: [REF-0009](../REFERENCES.md#ref-0009)

## 平台概述

Boeing 702（HS 702）平台是Boeing公司（原Hughes公司）继Boeing 601平台后开发的新一代采用离子推进系统的通信卫星平台。首次应用于1999年12月22日发射的Galaxy 11通信卫星，卫星质量4484 kg，寿命15年，卫星末期太阳阵功率为15 kW。

## 卫星平台结构

平台采用桁架式结构，装有4台25 cm氙离子推力器，安装在推力指向机构上。

| 组件 | 配置 |
|------|------|
| 远地点发动机 | 490 N（变轨用） |
| 化学推力器（备份） | 10个 |
| 化学推进剂贮箱 | 4个（安装在底板上） |
| 气罐 | 6个（2个装化学燃料，2个装氦气，2个装电推进工质氙气） |
| 化学推进剂装填量 | 1925 kg |
| 氙气装填量 | 224 kg |

## XIPS-25离子推力器

25 cm离子推力器（XIPS-25）可在两种高低不同的功率模式下工作：

| 参数 | 高功率模式 | 低功率模式 |
|------|-----------|-----------|
| 用途 | 轨道转移阶段 | 位置保持 |
| 总线功率 | 4.5 kW | 2.2 kW |
| 离子束参数 | 1.2 kV, 3 A | 1.2 kV, 1.43 A |
| 推力 | 约165 mN | 约79 mN |
| 比冲 | 3500 s | 有所降低 |

离子束加速电压在两种模式下保持不变，低功率模式时放电电流和气体流量减小。

## 推力器布局与指向

四台推力器都安装在卫星背地面的结构板上，南端和北端各两台。每台推力器独立安装，由一个独立的指向机构控制推力方向：
- 在入轨段，推力指向机构在卫星尾部控制推力方向
- 在南北位保期间，推力指向机构可以保证推力通过质心

电推进的两个电源中，每个电源为对角线上的两台推力器供电，从而可在推力器或电源故障时提供完全的冗余。

## 矩形构型

电推力器布局采用**矩形构型**，即4台电推力器在背地板上呈矩形安装，其中对角线上2台电推力器属于同一电推进子系统。

该构型可视为V型构型的扩展：在V型构型的基础上，使电推力器绕星体Y轴转过一定角度，推力将产生切向分量，能够同时控制倾角、偏心率和平经度，实现完整的位置保持。

## 系统冗余设计

Boeing 702卫星平台氙离子推进系统包括两个全部冗余的系统，分别由两个推力器、两个电源、一个氙气供给装置组成。

卫星定点后，四个推力器每个每天都要点火一次，以满足轨道控制需求，包括：
- 南北位置保持（NSSK）
- 东西位置保持（EWSK）
- 姿态控制
- 动量卸载

推力器也可提供任意位置改变和轨道提升策略，并在卫星寿命末期提供脱离轨道的动力。

## 角动量卸载

星上角动量卸载的目的是释放星上角动量交换执行机构（动量轮、控制力矩陀螺等）因环境干扰力矩而造成的角动量积累，以免达到饱和状态。常用的卸载方式有磁力矩器和推力器卸载。

## 位置保持与动量卸载联合控制

Boeing 702将位置保持控制的点火位置、点火时长及电推力器偏转角度作为控制参数进行迭代优化。该方法能够同时对位置保持和角动量卸载的控制量实现较为精确的求解，但需要进行反复迭代，计算量相对较大。

BSS-702平台在轨执行位置保持和动量轮卸载任务是同时进行的。电推力器在进行角动量卸载的过程中同时改变轨道参数，使其能够抵消摄动影响。基本思路是：
- 4台电推力器按照对角线分成2对
- 其中一对按照角动量卸载需求确定点火位置及推力方向，同时消除一部分轨道摄动
- 另一对则保证推力过质心，主要针对轨道摄动进行控制而不参与动量轮卸载

## 电推进辅助轨道转移

BSS-702平台还通过电推进系统执行部分轨道转移任务：
1. 首先双组元推进系统将卫星由GTO轨道转移到一个轨道周期24h的椭圆轨道，并消除倾角
2. 之后由电推进系统进行轨道圆化并完成最后的定点
