# 中国霍尔推力器研究与应用

> **来源**: [第8课-霍尔推力器_2.pptx](../raw/第8课-霍尔推力器_2.pptx) | **编号**: [REF-0007](../REFERENCES.md#ref-0007)

## 上海空间推进研究所（801所）

801所研制的霍尔电推进产品系列：

| 型号 | 功率 | 备注 |
|------|------|------|
| HET-20 | 0.4kW | — |
| HET-40 | 0.7kW | 2012年11月在实践-9A卫星成功完成首次飞行试验 |
| HET-50 | 1kW | — |
| HET-80 | 1.35kW | 已应用于中国空间站"天和"核心舱，用于轨道提升任务 |
| HET-300 | 4.5kW | 双模式 |
| 20kW大功率 | 20kW | 2020年1月成功完成点火试验 |

### 重大突破

- **20kW大功率霍尔推力器**（2020年1月）：实测推力1牛，比冲3068秒，效率大于70%。实现了我国霍尔电推力器推力从毫牛级向牛级的跨越。
- **HET-2000HP超高比冲霍尔推力器**（2022年1月）：实测比冲超过5300s（氙气工质），打破了氙气工质下霍尔电推进的国际最高比冲记录。在此之前的比冲记录保持者是俄罗斯的D-100超高比冲霍尔电推进，最高比冲为4250s。

## 北京控制工程研究所（502所）

502所与哈尔滨工业大学联合开发了1.4kW单模式和5kW双模式磁聚焦霍尔电推进。

### 关键事件

- **2016年11月**：新技术验证卫星-2卫星（实践十七号）霍尔电推进飞行试验，搭载了502所的1.4kW磁聚焦霍尔电推进系统和510所的LHT-100霍尔电推进系统。
- **2022年9月20日**：由502所研制的300瓦霍尔电推进系统完成某低轨卫星的升轨任务，历时110余天，共点火600余次，累计工作400余小时，将卫星轨道提升近300公里。这是我国首次采用电推进系统完整执行低轨卫星的变轨任务。
- 截至2022年9月，502所研制并在轨运行的各类霍尔电推进系统已达20套。

## 兰州空间技术物理研究所（510所）

510所同时开展了离子和霍尔类型电推进技术研究及产品研制。

### 霍尔电推进产品系列

| 型号 | 功率 | 模式 |
|------|------|------|
| LHT-30 | 0.3kW | 单模式 |
| LHT-40 | 300W级 | 电推进+冷气双模式，功率100-300W可调 |
| LHT-70 | 0.7kW | 单模式 |
| LHT-60D | 1.3kW | 双模式 |
| LHT-100 | 1.35kW | 单模式 |
| LHT-140 | 4.5kW | 双模式 |
| HET-450 | 百千瓦级 | 大功率 |

### 关键事件

- **2022年初**：研制出百千瓦级大功率霍尔电推进HET-450，成功实现点火运行。
- **2022年10月13日**：300W级LHT-40霍尔电推进系统在微厘空间北斗导航增强星座S5卫星上完成首次在轨测试。LHT-40具备电推进和冷气双推进模式，采用推力器和推进剂贮存单元一体化结构。
