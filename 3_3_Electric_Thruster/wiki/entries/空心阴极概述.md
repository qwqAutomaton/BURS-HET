# 空心阴极概述

## 定义与功能

空心阴极是离子推力器和霍尔推力器的关键组件，其核心功能是发射电子，被称为电推力器的"心脏"。

## 阴极技术分类

根据材料和结构的不同，阴极技术可分为以下几类：

1. **金属热阴极**：以钨（W）、钽（Ta）、铼（Re）等难熔金属为发射体。金属阴极的功函较高，相应工作温度也更高。例如钨丝发射体的工作温度高达2600 K，耗能很高且蒸发速度快，寿命只有几百小时。
2. **薄膜阴极**
3. **厚涂层阴极**
4. **金属陶瓷阴极**：以钡钨阴极（Ba-W）为代表，由烧结的多孔钨浸渍氧化物构成。
5. **其它发射材料阴极**：以六硼化镧（LaB6）为代表。
6. **场发射阴极**

相比金属阴极，钡钨阴极和镧化物阴极具有一定优势——工作温度更低、发射电流密度更高。
