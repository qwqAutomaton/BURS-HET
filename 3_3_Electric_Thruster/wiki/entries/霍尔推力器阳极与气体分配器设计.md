# 霍尔推力器阳极与气体分配器设计

> **来源**: [第8课-霍尔推力器_2.pptx](../raw/第8课-霍尔推力器_2.pptx) | **编号**: [REF-0007](../REFERENCES.md#ref-0007)

## 概述

一般采用**气体分配器与阳极二合一**方案，通过给气体分配器加阳极电压作为阳极。

## 阳极设计

**材料选择**：耐高温、抗电子轰击。

**热设计**：
- 结合磁场设计，尽量降低轰击阳极的电子能量
- 尽量避免阳极高温向周围的磁极材料扩散

## 气体分配器设计

气体分配器的设计目标是将推进剂气体**均匀地喷入放电室通道**，并尽可能延长中性气体在通道内的驻留时间。

### 气体分配过程

工质进入放电室的路径为：

1. 工质通过进气管进入阳极
2. 工质进入一级、二级缓冲腔
3. 工质通过节流孔减速后被挡板阻拦，损失轴向动能
4. 自由扩散、轴向喷出

采用多级缓冲腔和节流孔+挡板的设计，可以有效地使推进剂气体均匀分布并延长气体在通道内的驻留时间。
