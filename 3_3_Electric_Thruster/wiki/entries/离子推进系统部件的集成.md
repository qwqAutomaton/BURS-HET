# 离子推进系统部件的集成

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 概述

离子推进系统各部件在交付飞行前需要进行一系列的集成试验，以验证各子系统之间的接口兼容性和功能正确性。

## 1. DCIU与XFS的集成试验

验证 [[数字控制与接口单元DCIU概述|DCIU]] 与 [[推进剂储供系统XFS概述|XFS（氙气供给系统）]] 之间的接口，具体验证项目包括：

1. 每台DCIU能否驱动系统中的每个阀门
2. 接到指令时，阀门是否正常工作
3. 每台DCIU是否能正确判断所有压力传感器和温度传感器的测量值
4. 稳压增压程序是否正常工作
5. 流量控制程序能否正常工作
6. 验证预防故障的能力，包括：
   - 是否对一两个压力传感器的失效能正确响应
   - 是否对一两个温度传感器的失效能正确响应
   - 是否对模拟氙气供给系统的泄漏能正确响应

## 2. DCIU与推力方向调节装置的集成试验

验证DCIU与 [[推力方向调节装置]] 之间的接口，具体验证项目包括：

1. DCIU与推力方向调节装置能否正常工作
2. 推力方向调节装置能否指向期望的方向
3. 推力方向调节装置能否完成全部预期的运动范围
4. 推力方向调节装置角位移能否与CAD模型的预计值一致

## 3. DCIU与PPU的集成试验

验证DCIU与 [[电源处理单元PPU概述|PPU]] 之间的接口，具体验证项目包括：

1. PPU与DCIU之间能否正常通信
2. PPU对所有DCIU的指令能否正常响应
3. 在整个PPU输入功率范围内，PPU与DCIU能否正常工作
4. 对于选择的PPU模拟故障，DCIU能否正确反应

## 4. DCIU与PPU及推力器的集成试验

验证DCIU、PPU与推力器三者之间的联合工作能力，具体验证项目包括：

1. 推力器能否成功点火并转换到稳态工作
2. 在整个推力器输入功率范围内推力器是否正常工作
3. 在不同调节功率下，能否正常调节推力

## NSTAR系统集成测试

NSTAR推力器/DCIU/PPU的集成是由NASA GRC、HED和SAI共同参与完成的。

测试科目包括：
- **电磁干扰测试**（EMI Test）
- **热真空试验**（Thermal Vacuum Test）
- **推力器振动测试**（由JPL实施）

其中的一套飞行硬件组件被安装在了深空一号（DS1）探测器上并在JPL进行了热真空试验。在此次试验中推进器点火工作了 **15分钟**。

在所有测试都顺利完成后，推力器/DCIU/PPU的组装件被选为深空一号的飞行任务套件。
