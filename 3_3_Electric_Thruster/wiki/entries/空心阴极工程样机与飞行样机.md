## 工程样机设计和验证

工程样机阶段的设计重点是**环境适应性、寿命、可靠性**等关键技术攻关、原材料选型、工艺可行性及寿命可靠性方面的进一步优化设计。

### 工程设计内容

| 设计类别 | 具体内容 |
|----------|----------|
| 结构设计 | 在原理样机的基础上进一步优化 |
| 寿命设计 | [[空心阴极结构|发射体]]、阴极顶、触持极顶的寿命评估 |
| 可靠性设计 | 加热器可靠性、触持极绝缘性 |
| 安全性设计 | 电安全、气路安全 |
| 原材料选型 | 关键材料的筛选与鉴定 |
| 工艺控制 | 阴极顶小孔加工、陶瓷-金属封接焊接等 |
| 抗中毒设计 | [[空心阴极寿命|发射体材料]]选择、使用和存储条件、真空点火前的措施、推进剂纯度 |

### 试验验证

- 工作性能试验
- 力热环境试验
- 寿命试验
- 专项试验

## 飞行样机设计和应用

飞行样机以工程样机为**基线**，固化技术状态、工艺参数、试验流程和试验参数，保证批量生产过程中产品的**一致性**，以实现**型号应用的合格产品**为研制目标。

### 全寿命周期管理

| 阶段 | 工作内容 |
|------|----------|
| **发射前准备阶段** | 发射前更换产品 |
| **在轨飞行初期** | 状态自检、系统气路除气、阴极预处理 |
| **在轨飞行期间** | 故障处理 |

## 研制阶段总结

| 阶段 | 样机类型 | 重点 |
|------|----------|------|
| 原理验证 | 原理样机 | 关键技术攻关、功能实现 |
| 工程验证 | 工程样机 | 环境适应性、寿命、可靠性、工艺 |
| 飞行应用 | 飞行样机 | 状态固化、一致性、全寿命周期管理 |
