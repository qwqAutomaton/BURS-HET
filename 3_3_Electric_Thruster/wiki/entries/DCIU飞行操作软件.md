# DCIU飞行操作软件

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 软件组成

[[数字控制与接口单元DCIU概述|DCIU]] 任务飞行操作软件存储在 [[DCIU中央处理器|64KB EEPROM]] 中，由三个部分组成：

1. **启动加载程序代码**（Boot Loader）
2. **任务飞行期间的操作软件**（Flight Software）
3. **配置数据存储区**（Configuration Data）

## 运行节律

飞行操作软件的中断驱动和操作遵循 **1Hz 的频率**。每一秒，飞行操作软件都要完成下列操作：

1. 正常运行状态的数据获取
2. 指令处理
3. 故障检测
4. 模式处理
5. 遥测信号处理
6. 清空缓存

## 七种工作模式

DCIU飞行操作软件的"模式处理"有 **7种** 工作模式：

### 1. 安全（SAFE）

系统默认的安全状态模式。

### 2. 待命（STANDBY）

系统等待指令的待机模式。

### 3. 氙供应系统初始化（XFS INIT）

对 [[推进剂储供系统XFS概述|氙气供给系统]] 进行初始化配置。

### 4. 氙供应系统启动（XFS ON）

启动氙气供给系统，开始供应推进剂。

### 5. 栅极清除（GRID CLEAR）

对栅极进行清除操作，消除可能的短路或污染物。

### 6. 阴极调理（CATHODE CONDITIONING）

对空心阴极进行调理，恢复阴极发射性能。

### 7. 推力器工作（THRUST）

离子推力器运行的主要模式，包含四个子模式：

| 子模式 | 功能 |
|--------|------|
| 启动（STARTUP） | 将推力器参数调节到预置的工作状态 |
| 节流（THROTTLING） | 推力器的工作点可以不断地变化（调节流量和功率） |
| 稳态工作（STEADY STATE） | 飞行操作软件通过设定闭环控制方式，通过放电室电流值对束流电流进行连续调节 |
| 关闭（SHUTDOWN） | 推力器一旦出现故障或者接到指令要关机时，飞行操作软件就会切到关闭模式，顺序关闭PPU的供电线路、XFS的闭锁阀和电磁阀 |
