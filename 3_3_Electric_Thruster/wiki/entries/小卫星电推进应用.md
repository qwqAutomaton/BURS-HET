# 小卫星电推进应用

> **来源**: [第8课-霍尔推力器_2.pptx](../raw/第8课-霍尔推力器_2.pptx) | **编号**: [REF-0007](../REFERENCES.md#ref-0007)

## 小卫星的特点

小卫星具有以下优势：
- 体积小、质量轻、集成度高
- 研制周期短
- 成本低
- 发射灵活

## 卫星等级分类（按质量）

| 等级 | 质量（kg） |
|------|-----------|
| 大卫星 | > 1000 |
| 中型卫星 | 500~1000 |
| 小卫星 | 100~500 |
| 微小卫星 | 10~100 |
| 纳卫星 | 1~10 |
| 皮卫星 | 0.1~1 |
| 飞卫星 | < 0.1 |

## 小卫星对推进系统的要求

1. 低的推力水平，宽的推力范围，以便应付各种类型小卫星的应用要求
2. 推力精确，重复性好，推力前沿与后沿稳定
3. 速度增量（ΔV）变化范围宽，不同应用要求ΔV有所不同
4. 最小推力冲量（冲量元）要小，可以预报、精度高、重复性好，以便满足控制系统高精度要求
5. 能长时间安全地在轨工作，推进剂无泄漏
6. 推进系统重量轻、体积小，低功耗；即使对电推进器也希望功耗小，或者适中
7. 易于与各种类型微推进器组合，构成大的推进系统，从而使推进系统具有极高的比冲
8. 在技术上采用微米机电系统（MEMS）和纳米机电系统（NEMS）

## 小卫星可用的推进系统类型

用于小卫星任务的推进系统主要包括：

- 冷气推进
- 化学推进
- 电推进
