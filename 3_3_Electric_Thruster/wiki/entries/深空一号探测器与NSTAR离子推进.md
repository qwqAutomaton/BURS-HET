# 深空一号探测器与NSTAR离子推进

> **来源**: [第13课-电推进系统与卫星的集成.pptx](../raw/第13课-电推进系统与卫星的集成.pptx) | **编号**: [REF-0009](../REFERENCES.md#ref-0009)

## 任务概述

深空一号（Deep Space 1, DS-1）是美国NASA的一项深空探测任务，具有两个主要目标：
1. 验证电推进等新技术
2. 开展太阳系的行星和彗星探测

## 基本参数

| 参数 | 数值 |
|------|------|
| 国家 | 美国 |
| 任务类型 | 行星研究 |
| 运营方 | NASA |
| 平台构型 | GeoBus（Italsat Bus） |
| 推进系统 | NSTAR离子发动机 |
| 质量 | 373.7 kg |
| 电推进类型 | 离子电推进 |
| 推进剂 | 氙气 |
| 比冲 | 3100 s |
| 推力 | 9.20 × 10⁻² N |
| 任务状态 | 工作超过16000 h |

## 任务历程

- **1998年10月24日**：发射
- **1999年10月**：导航系统出现故障
- **2000年6月**：完成遥控营救
- **2001年12月18日**：深空探测器结束寿命

## 诊断子系统

诊断子系统（IDS）包含2个相互联系的硬件单元：
- **诊断传感器电子单元（DSEU）**
- **遥感器单元（RSU）**

共包括12台诊断用传感器。
