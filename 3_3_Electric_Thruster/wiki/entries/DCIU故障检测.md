# DCIU故障检测

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 概述

在离子推进系统运行时，[[数字控制与接口单元DCIU概述|DCIU]] 内部的 [[DCIU飞行操作软件|飞行操作软件]] 负责检测并纠正 [[电源处理单元PPU概述|PPU]] 和 [[推进剂储供系统XFS概述|XFS]] 内的故障。

## XFS故障保护

### 故障检测内容

通过检测缓冲罐内压力来判断闭锁阀和电磁阀是否正常"开启"和"关闭"。

### 故障响应

如果飞行操作软件检测到XFS存在故障，它就会重新配置XFS的参数使其工作在所谓的 **"单级稳压模式"**。

在单级稳压模式下，XFS中的阀门（LV5）会开启，使得推进剂从单个缓冲罐流入主管路和阴极管路。

## PPU故障类型

飞行操作软件需要检测和纠正的PPU故障类型包括：

| 故障类型 | 触发条件 |
|----------|----------|
| 推力器再启动（典型故障） | 由束流或加速极电流过高导致 |
| 中和器熄火 | 由中和器放电电流过低导致 |
| 放电室熄火 | 由放电室放电电流过低导致 |
| PPU低电压输入丢失 | 由太阳能电池板母线电压过低导致 |
| PPU高电压输入丢失 | 由太阳能电池板母线电压过高导致 |
| 多个/连续推力器再启动 | 例如：栅极之间发生短路 |
