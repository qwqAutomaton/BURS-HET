# 空心阴极仿真与试验验证

> **来源**: [第6课-空心阴极.pptx](../raw/第6课-空心阴极.pptx) | **编号**: [REF-0005](../REFERENCES.md#ref-0005)

## 仿真验证

### 1. 热仿真

计算点火过程与热稳态时的温度分布，验证工作温度能否满足需求。

**验证目标**：
- 无超温点
- 发射体达到工作温度
- 点火启动时间符合要求

### 2. 流场仿真

计算阴极内部放电区域的气压，验证孔板小孔和触持极顶孔设计的合理性。

可采用 **PIC 法**（Particle-in-Cell，粒子网格法）或 **MHD 法**（Magneto-hydrodynamics，磁流体动力学法）进行阴极工作过程的仿真，进一步验证阴极的工作性能。

### 3. 力学环境仿真

计算空心阴极在承受可能的力学载荷（震动、冲击、加速度）时各结构组件的可靠性，对结构强度进行评估。

## 试验验证

### 1. 加热器性能测试

测试发射体温度与加热器功率的关系，验证加热器设计的合理性。

### 2. 点火启动性能测试

测试**加热功率—点火电压—点火时间—工质流量**的关系。点火时间一般 **5~10 分钟**。

### 3. 放电工作性能测试

测试**发射电流—工质流量—放电电压**的关系。发射电流应满足配套推力器工作需求。

### 4. 持续工作能力测试

在要求的工况下放电工作稳定，持续工作时间满足配套推力器工作需求。

### 5. 多次点火能力测试

测试点火放电的**重复性**，多次点火能力满足配套推力器工作需求。

## 验证体系总结

| 验证类别 | 方法 | 验证内容 |
|----------|------|----------|
| 热仿真 | 数值计算 | 温度分布、超温点、启动时间 |
| 流场仿真 | PIC/MHD 数值模拟 | 内部气压分布、孔板设计 |
| 力学仿真 | 有限元分析 | 结构强度、力学环境适应性 |
| 加热器试验 | 实验测试 | 温度—功率关系 |
| 点火试验 | 实验测试 | 功率—电压—时间—流量关系 |
| 放电试验 | 实验测试 | 发射电流—流量—放电电压关系 |
| 持续工作试验 | 实验测试 | 长时间放电稳定性 |
| 多次点火试验 | 实验测试 | 点火重复性 |
