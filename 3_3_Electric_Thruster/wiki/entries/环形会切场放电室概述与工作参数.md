# 环形会切场放电室概述与工作参数

> **来源**: [第5课-离子推进_3.pptx](../../raw/第5课-离子推进_3.pptx) | **编号**: [REF-0004](../../REFERENCES.md#ref-0004)

## 概述

环形会切场是离子推力器放电室的两种主要磁场构型之一，其主要特点包括：

1. **磁路结构简单**，无极靴
2. 除与阴极和栅极配合接口外，放电室阳极为**整体密封结构**，无屏栅筒
3. 放电室遭受离子轰击的零件较少（只有屏栅极和阴极），因而放电室**溅射多余物较少**
4. 放电室**磁空区较大**，束流均匀性好，非常适合**大口径离子推力器**
5. 无法用电磁铁实现放电室优化实验，**磁场优化成本较高**，只能在有限实验基础上，通过理论计算确定

## 工作参数设计

### 放电电流设计

放电电流取决于所要求的束流和放电损耗。环形会切场离子推力器放电电流一般按照以下公式估算：

**I_d = (5~7) I_b**

其中 I_d 为放电电流，I_b 为束流。

### 放电电压与流率设计

放电电压主要取决于放电室磁场、阴极流率和推进剂利用率。

设计原则是推进剂利用率越高越好，放电电压和放电损耗越低越好，但三者之间存在**制约相关性**，须根据推力器用途权衡确定。

- 放电电压一般在 **24~30V**
- 放电室工质利用率在 **70%~95%**

一般情况下，通过放电电压和放电损耗与推进剂利用率关系曲线，先确定放电室推进剂利用率，并得到放电室总流率；再通过阴极流率与放电电压和放电损耗关系确定阴极流率。
