# 霍尔推力器发展趋势

> **来源**: [第8课-霍尔推力器_2.pptx](../raw/第8课-霍尔推力器_2.pptx) | **编号**: [REF-0007](../REFERENCES.md#ref-0007)

## 一、高比冲

发展高比冲霍尔推力器有两条技术途径：

### 1. 提高加速电压（放电电压）

| 推力器型号 | 最大工作电压 | 验证的比冲范围 |
|-----------|-------------|---------------|
| D-80 | 1700V | 1600~4100s |
| SPT-1 | 1250V | 1600~3700s |
| BHT-HD-1000 | 1000V | 1600~3300s |

在最新研制的NASA-400M推力器上，已经实现了推力器比冲随电压的单调增长。

### 2. 选择更高比冲的新推进剂

| 推进剂 | 适用场景 | 优势 |
|--------|----------|------|
| 氪（Kr） | 高比冲需求 | 相同电压下相对氙增加比冲25%，NASA-457M上试验验证1000V下比冲达4500s、效率64% |
| 铋（Bi） | 高推力需求 | 相对氙，单位质量增加推力26% |

## 二、高功率（大推力）

发展高功率推力器有两类途径：

| 途径 | 说明 |
|------|------|
| 发展高功率推力器 | 扩展单个推力器的功率上限 |
| 采用中功率推力器族 | 以多台推力器组合满足大推力需求 |

从可靠性和地面试验看，推力器族途径更为优先和可行，但目前单个推力器的工作上限功率或最大尺寸还不清楚，无法确定推力器族的最小配置数。

NASA-457M已经证明了霍尔推力器可以有效工作在50kW高功率，且推力随功率单调增加。预期通过扩大通道截面和磁场设计，可以把单个霍尔推力器功率扩展到500kW。

## 三、多（双）模式

发展双模式或多模式霍尔电推进是航天器使命的客观要求。例如对同步轨道卫星：

- **轨道转移阶段**：需要大推力工作模式，缩短转移周期，减少经历辐射带的次数
- **同步轨道运行阶段**：需要高比冲工作模式，最大限度节省推进剂消耗

实现双（多）模式工作的三种技术途径：

| 途径 | 说明 |
|------|------|
| 双级化 | 分离出电离级和加速级 |
| 离子电离与霍尔加速组合 | 采用离子推力器的放电室作为霍尔推力器的前级输入 |
| 高效工作性能范围拓展 | 采用磁场调谐技术解决800V以上电压下效率下降的问题 |
