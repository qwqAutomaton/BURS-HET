# 德国磁等离子体动力推力器研究

> **来源**: [第11课-电弧加热推力器和磁等离子体动力推力器.pptx](../raw/第11课-电弧加热推力器和磁等离子体动力推力器.pptx) | **编号**: [REF-0012](../REFERENCES.md#ref-0012)

## 研究机构

德国[[磁等离子体动力推力器概述|MPDT]]研究以**斯图加特大学（University of Stuttgart）**为代表，在美国空军和欧盟项目的支持下开展。

## 主要推力器型号

### AF-MPD ZT1 — 稳态供气推力器

| 参数 | 数值 |
|------|------|
| 类型 | 稳态供气 AF-MPDT |
| 推进效率 | 最高可达 **45%** |
| 放电电流 | 1.7-2.1kA（高放电电流） |
| 附加磁通量密度 | 90mT（相对较低） |
| 总放电功率 | 90-120kW |

**设计特点**：
- 被动冷却设计
- 单通道空心阴极和阳极
- 推进剂可通过空心阴极和阳极的环形缝隙供给

### AF-MPDT SX3 — 100kW 稳态供气推力器

| 参数 | 数值 |
|------|------|
| 类型 | 100kW 稳态供气实验室推力器 |
| 合作方 | EU HiPER 和 ESA AF-MPDT 项目框架下与 Alta 公司合作 |
| 推进效率 | 可达 **40%** |
| 放电功率 | 7-12kW |
| 放电电流 | **80A**（相对较低） |
| 磁通量密度 | **0.6T**（相对较高） |

SX3 的设计特点在于**低放电电流 + 高磁场**的技术路线，体现了[[附加场磁等离子体动力推力器|AF-MPDT]]中低功率获得高性能的特点。
