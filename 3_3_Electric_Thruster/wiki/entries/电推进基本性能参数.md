# 电推进基本性能参数

> **来源**: [第2课-等离子体放电与电推进.pptx](../raw/第2课-等离子体放电与电推进.pptx) | **编号**: [REF-0001](../REFERENCES.md#ref-0001)

## 推力

电推进通过从推力器喷出高速的带电粒子来产生推力：

```
F = ṁᵢ · vᵢ
```

其中 ṁᵢ 为喷出的离子流量，vᵢ 为离子速度。

## 总冲和比冲

**总冲**（I）是衡量推进系统在一定时间内对航天器产生的全部动量总和，是航天任务非常重要的一个考核指标。

**比冲**（Isp）定义为单位质量推进剂产生的总冲：

```
Isp = I / m = vₑ   （国际单位：m/s）
```

工程中常用秒（s）做单位，两者关系为：

```
Isp (s) = Isp (m/s) / g₀
```

其中 g₀ = 9.8 m/s²。

## 推力功率关系

电推进的推力和比冲与输入电功率密切相关。以比冲为 3000s 的电推进产生 1000 吨推力为例，需要极大的输入功率（作为参照，三峡水电站的装机容量为 22.5 GW）。

## 电源处理单元（PPU）的比质量

电源处理单元的质量 mE 与供电电功率 P 成正比，也就与出口喷气速度 vₑ 的平方成正比：

```
mE ∝ P ∝ vₑ²
```

**α** 是电源处理单元的比质量（单位功率的质量），**η** 是电推进系统总效率：

| 推力器类型 | PPU 比质量 α (kg/kW) |
|-----------|---------------------|
| [[典型离子推力器型号概览]]、[[霍尔推力器概述]] | 5 ~ 10 |
| [[电推进分类]] | 约 2 |
| [[脉冲等离子体推力器概述]] | 约 1 |

## 推进系统重量与比冲的关系

推进系统的总质量由以下部分构成：

```
ME = ṁ · (α / 2η) · Isp²    （电源处理单元质量）
MP = It / Isp                （推进剂质量）
M = M₀ + ME + MP             （系统总质量）
```

其中：
- M₀ 为航天器干重
- ME 为 PPU 质量（与比冲平方成正比）
- MP 为推进剂质量（与比冲成反比）

推进系统总重量随比冲变化存在一个最优区间（示意中约在 Isp = 1500s 附近）。这说明电推进系统的效率和供电单元的比质量是非常重要的设计参数。
