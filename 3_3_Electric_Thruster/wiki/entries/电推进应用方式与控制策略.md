# 电推进应用方式与控制策略

> **来源**: [第13课-电推进系统与卫星的集成.pptx](../raw/第13课-电推进系统与卫星的集成.pptx) | **编号**: [REF-0009](../REFERENCES.md#ref-0009)

## 电推进位保的基本挑战

离子推进的推力很小（几十mN到一百多mN），仅为原化学推进的百分之一，位保时间相对化学推进增大很多，这对卫星平台的电源、遥测遥控、东西位保、姿态控制等带来很大的难度。

核心问题：执行南北位保任务的频率和每次南北位保的持续点火时间如何确定。

## 化学推进位保方案（参考基准）

在使用化学推力器的南北位保方案中，每14天执行一次南北位保，对应的速度增量为约1.8 m/s。

## 电推进位保方案

### 两周一方案的计算

电推进系统的推力很小（几十到一百多毫牛），仅为原有化学推力器的百分之一。

计算示例：采用两台离子推力器，每台推力按83 mN计，考虑安装角为45°，实际有效推力为117 mN。要使质量2740 kg的卫星产生1.8 m/s的速度增量需要时间为11.7小时。

这样长的位保时间对卫星平台的电源、东西位保、姿态控制等都带来了很大的难度。

### 每天位保方案

因此考虑**每天执行南北位保**的方案：

| 参数 | 数值 |
|------|------|
| 每天倾角改变量 | 0.0024° |
| 每天速度改变量 | 0.1286 m/s |
| 每天工作时间 | 约52分钟（3118 s） |
| 每次工作时间（升交点/降交点各一次） | 约25分钟 |
| 每次倾角改变量 | 0.0012° |
| 每次速度改变量 | 0.0643 m/s |

在升交点和降交点附近各工作一次，每次工作时间约25分钟。

## 对遥测遥控的影响

电推进系统对卫星控制精度高，而且在星上应用时几乎每天都要工作，对遥测的精度和密度均有较高要求。

## 对星上计算机的影响

电推进系统的推力小、启动关机时间长、工作时间长、需要每天工作、开关机频繁、工作过程需要密切监视，往往需要配置专门的控制器。

如果由星上的控制计算机来完成这项工作，可以实现卫星南北位置保持时的自主运行机制，减少对地面站的依赖。

## 在轨状态检测与故障诊断

在电推进工作过程中需要通过遥测实时进行状态监控，对出现的异常要能进行初步的自诊断。故障诊断是一项难度非常大的工作，还需增加一些辅助的传感器和检测点。
