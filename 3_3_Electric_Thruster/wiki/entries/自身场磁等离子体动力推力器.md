# 自身场磁等离子体动力推力器

> **来源**: [第11课-电弧加热推力器和磁等离子体动力推力器.pptx](../raw/第11课-电弧加热推力器和磁等离子体动力推力器.pptx) | **编号**: [REF-0012](../REFERENCES.md#ref-0012)

## 定义

自身场 MPDT（Self-field MPDT, SF-MPDT）是[[磁等离子体动力推力器概述|MPDT]] 的两种基本类型之一，仅依靠放电电流自身产生的感应磁场来产生加速力。

## 与 Arcjet 的结构相似性

从结构上看，SF-MPDT 与[[电弧加热推力器概述|电弧加热推力器（Arcjet）]]有许多相似之处，但加速机理有本质区别：

| 对比维度 | Arcjet | SF-MPDT |
|----------|--------|---------|
| 主要加速机理 | 欧姆加热 → 热膨胀 → 喷管加速 | 电磁加速（洛伦兹力） + 热膨胀 |
| 主导因素（大流量） | 电热加速 | 电热加速为主 |
| 主导因素（小流量） | 电热加速（推力持续减小） | **电磁加速为主**（推力反而增加） |
| 性能限制 | 非平衡冻结损失 + 电极传热损失 | 受 onset 现象限制 |

## 加速力的构成

SF-MPDT 中，除热膨胀加速产生推力外，自身感应磁场产生的力分量包括：

1. **轴向作用力**（j_r × B_θ）：直接产生推力
2. **径向作用力**（j_z × B_θ）：导致中心电极处压力不平衡，间接增加推力

## 电磁推力公式

$$F = b \cdot J^2$$

$$b = \frac{\mu_0}{4\pi} \left[ \ln\left(\frac{r_a}{r_c}\right) + \alpha \right]$$

详见 [[磁等离子体动力推力器工作机制|MPDT 工作机制]]。

## SF-MPDT 的局限

1. **需要大电流**：推力与电流平方成正比，但只有在极高电流下才能获得显著性能
2. **电极烧蚀严重**：准稳态 SF-MPDT 的工作电流和电压大，电极温度高，烧蚀情况比较严重
3. **需要特别考虑电极热载荷和冷却技术**：降低了发动机的寿命
4. **[[MPDT Onset现象|Onset 现象]]**：阳极电势陡增导致的不稳定现象，限制比冲和推力，不利于点火启动
