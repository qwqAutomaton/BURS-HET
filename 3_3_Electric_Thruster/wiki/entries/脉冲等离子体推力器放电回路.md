# 脉冲等离子体推力器放电回路

> **来源**: [第10课-脉冲等离子体推力器和真空电弧推力器.pptx](../raw/第10课-脉冲等离子体推力器和真空电弧推力器.pptx) | **编号**: [REF-0011](../REFERENCES.md#ref-0011)

## 等效电路参数

放电回路的等效电路包含以下参数：

- **Rc、Lc**：储能电容器的内阻、内电感
- **Re、Le**：电容器到电极之间的引线电阻、电感
- **Rpe、Lpe**：等离子体的电阻、电感

对于给定的推力器，Rc、Lc、Re、Le是恒定的，只有Rpe、Lpe在加速过程中随时间变化。

## RLC电路分析

令 R = Rc + Re + Rp，L = Lc + Le + Lp。如果把R、L作为随时间变化的函数，所建立的RLC电路方程便是一带有变系数的二阶线性微分方程，很难直接求解。

但如果假定R、L为常数（实际上变化也不大），对于集中定常的RLC串联电路，其微分方程为：

L·d²q/dt² + R·dq/dt + q/C = 0

其特征方程是：Ls² + Rs + 1/C = 0

有两个根：s₁,₂ = -R/(2L) ± √[(R/(2L))² - 1/(LC)]

令 α = R/(2L)，ω₀ = 1/√(LC)

## 三种放电状态

### 临界阻尼振荡

当 α = ω₀，即 R = 2√(L/C) 时，放电呈临界阻尼振荡。

### 欠阻尼（周期放电/衰减振荡）

当 α < ω₀，即 R < 2√(L/C) 时，回路的放电为周期放电，有振荡，单调衰减。

### 过阻尼（非周期放电）

当 α > ω₀，即 R > 2√(L/C) 时，回路的放电为非周期放电，没有振荡，单调衰减。

## 实际放电特性

在实际的推力器中，很难做到 α ≥ ω₀。要满足临界阻尼条件，意味着回路中的总电感L必须小到1~10 nH（1 nH = 10⁻⁹ H）。实际上，如果不采取特殊措施，这是很难做到的。因为一个精心制作的2 μF低电感电容器，其内感就大于10 nH。

所以，在实际的推力器中，放电总是呈**衰减振荡**的形式，和测得的放电电流波形是一致的。
