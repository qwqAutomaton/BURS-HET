# 空心阴极设计概述

> **来源**: [第6课-空心阴极.pptx](../raw/第6课-空心阴极.pptx) | **编号**: [REF-0005](../REFERENCES.md#ref-0005)

## 设计目标

空心阴极的设计目标是**最大程度地降低阴极功耗和工质流率**，同时保证阴极的电子发射能力和工作寿命，满足推力器工作的需要。

空心阴极消耗的功率（包括放电功率和加热功率）不是推力器推进剂加速所必需的，是推力器功率与效率的一大损耗。空心阴极消耗的工质不参与推力器推进剂的加速，是推力器比冲的一大损耗。

## 研制流程

1. **研制目标确定**：根据背景任务要求，进行任务分析，制定实现方案，完成关键技术攻关，开展原理样机研制、调试和试验。
2. **技术指标确定**：
   - 根据电推力器单机任务指标进行分解
   - 确定空心阴极组件的放电电流、点火启动时间、寿命、点火次数等主要技术指标
   - 初步确定系统的电源和推进剂供给能力
   - 首次研制的产品，以关键技术攻关和功能实现为重点，同时兼顾尺寸、质量、寿命等指标
3. **原理样机设计**
4. **工程样机设计和验证**
5. **飞行样机设计和应用**

## 设计考虑因素

空心阴极性能受以下因素影响：

| 因素类别 | 具体内容 |
|----------|----------|
| 发射体种类 | 钡钨、六硼化镧、氧化物等 |
| 基本结构 | 有无加热器、阴极顶孔板结构、发射体结构、绝缘结构等 |
| 工作点 | 放电电流、工质质量流率 |
| 供电方式 | PPU 的供电参数和方式 |
| 供气 | 推进剂种类、纯度和杂质含量 |
