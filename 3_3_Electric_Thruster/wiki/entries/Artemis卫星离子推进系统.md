# Artemis卫星离子推进系统

> **来源**: [第13课-电推进系统与卫星的集成.pptx](../raw/第13课-电推进系统与卫星的集成.pptx) | **编号**: [REF-0009](../REFERENCES.md#ref-0009)

## 卫星概况

Artemis卫星是由Alenia Spazio公司作为主研制方，为欧空局（ESA）提供的静止轨道卫星。其主要目的是应用和提高先进的通讯技术，此外也希望在真实任务中验证离子推进系统应用于静止轨道卫星南北位保的能力。

Artemis卫星为三轴稳定卫星，发射质量3100千克，于2001年7月12日与PAS2B卫星一起用ARIANE火箭发射，设计寿命10年。

## 变轨营救

由于运载火箭上面级故障，卫星被置于很低的轨道。通过星上的电推进系统对卫星进行营救：
- 将轨道高度提高到4660 km，推进剂只消耗14.2 kg
- 一台离子推力器工作6427小时，相当于7年正常情况的工作时间
- 飞行11个月之后，于2003年1月30日抵达GEO轨道

## 卫星平台参数

| 参数 | 数值 |
|------|------|
| 入轨后总重 | 2640 kg |
| 卫星平台重 | 1460 kg |
| 推进剂重量 | 1176 kg |
| 太阳电池帆板最大功率 | 2925 W |
| 电推力器工作时功率 | 840 W |

卫星采用承力筒式结构。变轨采用410 N远地点推力器，星上装有16台化学推力器用于姿控和东西位保。动量轮组件由2个固定动量轮和2个反作用轮组成。

## 离子推进系统组成

离子推进系统配有4台推力器，其中UK-10推力器和RIT-10推力器各2台：

### 推进剂贮存和分配组件
包括Xe储箱和电子压力调节组件。

### 电子轰击式离子推力器组件（EITA）
代号UK-10，英国研制，包括电子压力调节器、推力器、推进控制电路以及推进剂供给和监控装置。

### 射频离子推力器组件（RITA）
代号RIT-10，德国研制。

### 推力器推力矢量调节组件
奥地利研制。

## 布局与南北位保策略

Artemis上的离子推进系统由Astrium GmbH牵头完成，主要用于为南北位保提供速度增量。

**工作计划**：每次卫星通过升交点时，北面的一个推力器工作3小时；通过降交点时，南面的一个推力器工作3小时。一个RITA推力器和一个EITA推力器轮流工作。

**安装方案**：推力器分别安装在卫星南北板靠近背地面一侧，推力矢量在YOZ平面内，与Z轴约45°左右。设计考虑因素包括：
- 使推力器羽流避开太阳电池帆板
- 使推力器矢量过质心
- 尽量提高推进效率（尽量减小安装角）

## 布局优缺点

**主要优点**：
- 任何时候只需1台推力器工作
- 径向方向的推力只引起小的轨道扰动

**主要缺点**：
- 推力矢量必须经过卫星质心以避免扰动力矩
- 推力矢量与南北轴的方向为45°~60°，推力效率会降低
