# 霍尔推力器放电振荡

> **来源**: [第8课-霍尔推力器_2.pptx](../raw/第8课-霍尔推力器_2.pptx) | **编号**: [REF-0007](../REFERENCES.md#ref-0007)

## 概述

SPT工作时存在较强烈的电流和电压振荡，该振荡主要由于推力器内部电离振荡与等离子体参数紊乱造成的。放电稳定技术是霍尔推力器的关键技术之一。

## 振荡类型与频率范围

Bugrova对SPT中各种频率范围的振荡进行了系统论述，指出频率从低到高主要有：

| 振荡类型 | 频率范围 |
|----------|----------|
| 电离振荡 | 低频（1~100kHz） |
| 轴向等离子体输运振荡 | 低频 |
| 电子周向漂移振荡 | 中频 |
| 电子回旋振荡 | 高频 |
| Langmuir振荡 | 高频 |

Choueiri对推力器1kHz~60MHz范围的振荡进行了理论研究，分析了该范围内各型振荡的特征、产生根源及传播方式。

混合模拟方法对SPT低频放电振荡现象实现了较好的复现。混合-PIC方法也是SPT放电振荡常用的数值研究方法。

## 放电振荡的危害

1. 降低推力器的性能（推力、比冲、效率下降），严重时将使推力器不能稳定放电而熄灭。
2. 降低推力器和推进系统的安全性与可靠性，高幅放电振荡引起的强烈感应电势叠加在工作电压上，极大地提高了推进系统供电线路上的峰值电压，在真空下高电压部件间易发生放电短路故障。
3. 加重推进系统自身PPU及航天器电源系统的负担，并可能影响航天器其他用电负载的正常工作。
4. 推力器内部的放电振荡尤其是等离子体高频振荡对航天器的电磁波通信产生干扰。
5. 增加离子的束发散角，从而加重推力器的羽流污染。
6. 振荡模式下离子对室壁的溅射加强，从而降低推力器寿命。

## 放电振荡的影响因素

1. 推进剂流量及其种类
2. 施加的放电电压
3. 阴极特性（工质流率及位置）
4. 磁场的大小与形状
5. PPU类型及振荡抑制电路的参数配置
6. 放电室的污染程度

## 低频放电振荡的形成机理

SPT低频放电振荡（1~100kHz）主要是由于放电通道内中性原子的**电离振荡**造成的。电离振荡同时伴随电子密度的振荡，这时对外表现为放电电流的振荡。

当振荡过分强烈时，中性原子在电离最强时消耗过甚，以致此后在通道内不能维持足够数量的电子数，从而导致振荡甚至熄火。振荡的周期取决于中性原子的补充时间，也即中性原子通过电离区的时间。

关于低频振荡由于其幅值较大，对推力器放电稳定性和性能影响较大，因此关于低频振荡的研究最早、成果最多。

对霍尔推力器几十MHz频段的高频振荡物理性质的理论和实验研究都是十分有限的，高频振荡实验数据的缺乏是由检测和诊断这些振荡所遇到的技术难题所造成的。

## 放电振荡的抑制

抑制放电振荡的方法分为内部和外部两个方面：

**内部途径**：从SPT的内部工作过程与放电振荡机理出发，改进推力器的设计（如增加缓冲腔）。

**外部途径**：
- 通过实验调整推力器工况，使其工作远离高振荡模式。
- 引入**振荡抑制电路**，从外部控制放电振荡的强度。
