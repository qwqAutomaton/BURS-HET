# 霍尔推力器工作原理

> **来源**: [第7课-霍尔推力器_1.pptx](../raw/第7课-霍尔推力器_1.pptx) | **编号**: [REF-0006](../REFERENCES.md#ref-0006)

## 理论基础：带电粒子在均匀恒定电磁场中的运动

霍尔推力器的工作原理建立在带电粒子在正交电磁场中运动的基础上。假定电场和磁场恒定，电场沿x方向、磁场沿z方向，带电粒子的运动方程可解得y方向的漂移速度。该漂移速度具有以下特征：

- 漂移速度方向与磁场和电场方向均垂直
- 漂移速度与电荷的正负及粒子质量（直径）无关

这一漂移运动是霍尔推力器中电子做周向漂移（即**霍尔漂移**）的物理基础。

## 工作过程

霍尔推力器的具体工作过程如下：

### 1. 推进剂注入

推进剂（通常是氙气 Xe）通过[[霍尔推力器基本组成|阳极]]喷射进入环形通道。

### 2. 电子发射与分配

从[[霍尔推力器基本组成|空心阴极]]发出的电子分为两部分：
- **一部分进入放电室**：在电场作用下进入放电通道，参与电离过程
- **另一部分向下游运动**：与轴向喷出的高速氙离子中和，保持推力器羽流的宏观电中性

### 3. 电子周向漂移

阴极发射进入放电室的部分电子，在正交的径向磁场和轴向电场的共同作用下，做周向漂移运动（即霍尔漂移）。

### 4. 碰撞电离

在漂移过程中，电子与从阳极（气体分配器）出来的中性推进剂原子发生碰撞，使氙（Xe）原子电离，产生离子和新的电子。

电子漂移运动形成的电流称为**霍尔电流**。

### 5. 电子轴向迁移与循环维持

电子在漂移的同时，受到以下因素的影响而逐渐逃离磁场的约束：
- 与推进剂原子、离子、电子的碰撞
- 轴向磁场与径向电场的存在
- 与通道壁的碰撞

这些因素使得电子逐渐向[[霍尔推力器基本组成|阳极]]运动，最终到达阳极。新的电离电子及阴极发射电子不断补偿逃逸的电子，如此循环往复，保证了通道内一定的电子数量及推进剂气体高的电离率。

### 6. 离子加速产生推力

由于离子质量远大于电子，其受磁场的影响小。离子直接在轴向电场的加速下沿轴向高速喷出，从而产生推力。

## 关键要点总结

| 环节 | 说明 |
|------|------|
| 电子运动方式 | 在正交电磁场中做周向霍尔漂移 |
| 电离机制 | 漂移电子与中性推进剂原子碰撞电离 |
| 霍尔电流 | 电子漂移运动形成的周向电流 |
| 电子循环 | 逃逸电子 → 电离新电子 + 阴极电子补偿 → 维持稳态 |
| 离子行为 | 质量大，磁场影响小，轴向电场直接加速喷出 |
| 推力来源 | 离子高速喷出的反作用力 |
