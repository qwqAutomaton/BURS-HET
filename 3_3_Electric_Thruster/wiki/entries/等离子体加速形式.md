# 等离子体加速形式

> **来源**: [第2课-等离子体放电与电推进.pptx](../raw/第2课-等离子体放电与电推进.pptx) | **编号**: [REF-0001](../REFERENCES.md#ref-0001)

## 概述

电推进中等离子体的加速形式主要分为三大类：

| 加速形式 | 说明 |
|----------|------|
| **电热加速** | 通过电能加热推进剂，使其变为高温等离子体，再经喷管膨胀加速 |
| **静电加速** | 利用静电场直接加速带电粒子（主要是离子） |
| **电磁加速** | 利用电磁场（洛伦兹力）加速等离子体 |

> 详细内容参见第一章第3节。
