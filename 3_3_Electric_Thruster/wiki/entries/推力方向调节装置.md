# 推力方向调节装置

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 基本功能

推力方向调节装置用于承载离子推力器，可以根据系统运行的实际需要（主推进或位置保持）调节推力器推力的方向，推力方向可在给定的立体锥角内调节。

## 主要任务

推力方向调节装置需完成以下四个基本任务：

1. **在轨与发射期间能支持推力器**：承受发射过程中的力学载荷
2. **操作推力器围绕两轴运动以调整推力矢量方向**：实现二维角度调节
3. **提供一个与卫星发射轴成一定角度的斜面为固定平面**：提供安装基准
4. **在推力器以及航天器之间起到隔热作用**：保护航天器免受推力器热影响

## 典型装置对比

### ITAM（Ion Thruster Alignment Mechanism）

欧空局 ARTEMIS 卫星使用的离子推进器布局装置。

### TPM（Thrust Pointing Mechanism）

Astrium 公司 EUROSTAR3000 卫星平台使用的推力方向调节装置。

### 性能参数对比

| 项目 | ITAM | TPM |
|------|------|-----|
| 质量（kg） | 4.3 | 10.35 |
| 尺寸（mm×mm×mm） | 653×388×330 | 595×389×350 |
| 角度调节范围（度） | >6 | >7 |
| 平均功率（W） | 7 | 2.9 |
| 最大功率（W） | 19 | 15.7 |
| 调节精度（度） | <0.003° | <0.01° |
| 承载能力（个数×kg） | 2×2.2 | 2×6.5 |

ITAM在调节精度和重量方面具有优势，TPM在承载能力方面更强。

## TPM的组成

以TPM为例，推力方向调节装置由 **5个部分** 组成：

| 组成部分 | 功能 |
|----------|------|
| 推力器安装板 | 安装推力器 |
| 支撑单元 | 支持推力器安装板及调节安装板姿态 |
| 驱动机构 | 控制安装板围绕两轴转动 |
| 锁紧释放装置 | 在卫星发射期间锁紧机构，到达指定轨道后释放装置 |
| 安装平台 | 以上四个部分均安装在安装平台上，通过安装平台与卫星连接 |

## 扩展：航天器跟踪指向机构

跟踪指向机构是给定目标或基准进行跟踪或指向调节的机构，通常应用于航天器的有效载荷、姿态控制、能源、推进、测控数传等分系统。

主要产品包括：
- 天线跟踪指向机构
- 扫描镜指向机构
- 卫星间激光链路终端跟踪指向机构

根据运动特性的不同，可以分为：
- 单自由度跟踪指向机构
- 两自由度跟踪指向机构
- 三自由度跟踪指向机构
- 多自由度跟踪指向机构
