# 栅极组件安装设计

> **来源**: [第5课-离子推进_3.pptx](../../raw/第5课-离子推进_3.pptx) | **编号**: [REF-0004](../../REFERENCES.md#ref-0004)

## 基本结构

栅极组件主要由**双栅**、**双栅极支撑环**、**绝缘支撑**等组成。几何要求双栅极必须**互相平行**。它们分别安装在各自的支撑环上。

两块支撑环通过栅极绝缘体联接，联接处由陶瓷件绝缘，每个陶瓷件都有屏蔽罩，以此来减少陶瓷件的溅射污染沉积物。

## 绝缘与支撑结构设计

### 栅极片之间的绝缘设计

主要考虑两栅极之间的**安全距离**，需要给推力器工作冷热交变情形下的热变形留足够安全余量，即最大热变形情况下，栅极片之间也有足够的绝缘距离。

### 栅极片之间连接固定结构的绝缘设计

主要考虑电极间气压足够低和防止电极间存在放电荷源。在具体的放电荷源设计中：
1. 防止外界等离子体进入栅极组件连接支撑区域
2. 栅极组件与放电室之间的隔离设计，防止放电室等离子体或中性气体进入栅极组件连接支撑区域

### 小口径栅极结构特点

小口径栅极采用**碟状加速栅**，增加栅极间的绝缘壁面路径，减少栅极沿绝缘面击穿概率。

## 材料选用

### 栅极材料

栅极常用的材料有钼、钛和碳基材料，其关键性能如下表：

| 材料种类 | 热膨胀系数 / K^(-1) | 典型氙离子能量下的溅射产额 |
|---|---|---|
| | | E=200eV | E=400eV |
| 钼 | 5.2 x 10^(-6) | 0.29 | 0.70 |
| 钛 | 10.8 x 10^(-6) | 0.13 | 0.34 |
| 碳基 | 接近0甚至负值 | 0.04 | 0.12 |

**碳基材料**具有优异的热稳定性和耐离子溅射，是较为理想的栅极材料，可解决栅极热变形和溅射腐蚀失效问题，从而有效地提高离子推力器的可靠性和寿命，被美国、日本和英国用于离子推力器栅极组件的研制。但碳基材料也存在缺点：力学强度较低，加工制造工艺复杂。

现阶段国内外大多数栅极材料采用的仍是**金属钼**，其成孔和成型工艺均已比较成熟，应用成熟度较高。

### 栅极安装（支撑）环材料

栅极安装（支撑）环材料选择应与栅极材料的**热膨胀系数接近**，以减小两种材料热形变不一致导致的栅极过应力或永久变形。

常见材料为钛合金、钼和碳基材料。其中前两种材料与钼栅极配套使用，碳基材料安装环与碳栅极配套使用。

### 栅极绝缘支撑材料

栅极绝缘支撑的热变形是影响双栅极间距和气体流导的重要因素，需要选择热膨胀较小的支撑材料，同时保证栅极间绝缘。一般选择 **A95氧化铝陶瓷** 作为栅极绝缘支撑的原材料。

## 抗力学设计

离子光学系统特殊的薄壁结构决定了其属于离子推力器的**力学薄弱部件**。对于大推力、高比冲技术指标，推力器口径将会同步增大，力学薄弱问题越加显得突出，因此在设计时必须考虑其在发射环境中的应力和形变。

**球面设计**：一般口径大于10cm的栅极，为增加其刚性，都采用球面设计。金属钼栅极球面加工首先要预成型，然后进行热处理消除加工应力并保持最终形状。

**栅极间距**：理论上在栅极安全电场允许的条件下，栅极间距越小离子引出性能越好。但在振动和冲击过程中，较小的栅极间距易导致栅极之间发生碰撞，直接造成栅极破损，栅极间距不宜过小。

**拱高设计**：拱高也是影响栅极组件力学性能的一个因素。拱高设计受栅极材料延伸率的限制，不能过高。拱高和弦的比值一般取值 **0.5~0.6**。

**减振缓冲**：从推力器角度也可以考虑增强栅极组件力学性能的设计。例如，栅极安装接口处增加减振缓冲装置，减弱传递到栅极组件的振动和冲击。
