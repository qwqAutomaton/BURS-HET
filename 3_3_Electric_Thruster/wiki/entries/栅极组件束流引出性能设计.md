# 栅极组件束流引出性能设计

> **来源**: [第5课-离子推进_3.pptx](../../raw/第5课-离子推进_3.pptx) | **编号**: [REF-0004](../../REFERENCES.md#ref-0004)

栅极组件束流引出性能由以下三个关键参数决定：

## 归一化导流系数 K

对于氙工质，归一化导流系数 K 最佳取值为 **2.0~2.4 x 10^(-9) A/V^(3/2)**（一般为最大值的35%~50%）。当栅极出现明显的离子截获时，所对应的 K 为设计的使用上限值。

## 净加速电压与总加速电压之比 R

净加速电压与总加速电压之比 R 的最佳取值为 **0.75~0.9**。

## 栅极间距 L_g / d_s

为使束散角小和抽取较大束流，栅极间距与屏栅孔径之比 L_g / d_s 的最佳取值为 **1~0.75**。

## 设计示例

### NSTAR离子推力器栅极参数

以NASA的NSTAR离子推力器为例。

### 某3cm射频离子推力器栅极参数示例

| 参数 | 屏栅极（s） | 加速栅极（a） |
|---|---|---|
| 栅极材料 | 316不锈钢 | 钼 |
| 栅极厚度（mm） | 0.3 | 1.0 |
| 栅极间距（mm） | 0.7 | — |
| 栅极孔径（mm） | 1.9 | 1.2 |
| 栅极孔数目（个） | 91 | 91 |
| 栅极透明度 | 36.5% | 14.56% |

设计内容涵盖：
- 材料、厚度、间距与栅孔参数
- 栅极电压
- 栅极结构

设计工况为：
- 推进剂利用率 55%，电效率 40%
- 束流 18mA
- 推力 1.2mN，比冲 2931s
- 推进剂流量 0.5sccm
