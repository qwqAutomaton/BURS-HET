# DCIU中央处理器

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 处理器核心

NSTAR [[数字控制与接口单元DCIU概述|DCIU]] 的中央处理器以 **4MHz 主频的 80C86RH 微处理器**为核心设计。80C86RH 是抗辐射加固型的 8086 兼容处理器，适用于空间环境。

## 存储器配置

| 存储器类型 | 容量 | 用途 |
|-----------|------|------|
| 静态随机存储器（SRAM） | 64 KB | 存储运行数据 |
| 电可擦只读存储器（EEPROM） | 64 KB | 存储程序代码 |

## 控制逻辑

一块单线程的 **ACTEL A1280** 芯片实现低能级状态的控制逻辑，包括：
- 一组用来和 [[电源处理单元PPU概述|PPU]] 通信的 VME 总线控制器接口
- RS-422 串行接口

## 通信接口

CPU 电路板上安装着符合美军标 **MIL-STD-1553** 的输入/输出芯片组，该芯片组被封装为能与探测器通信的**远程终端**（Remote Terminal）。

## EEPROM分区

飞行任务所需要的软件均存储在 64KB 的 EEPROM 内，其内部被分割为 3 个部分：

1. **启动加载程序代码**（Boot Loader）
2. **飞行期间的操作软件**（Flight Software）
3. **配置数据**（Configuration Data）
