# 柱形会切场放电室概述与参数设计

> **来源**: [第5课-离子推进_3.pptx](../../raw/第5课-离子推进_3.pptx) | **编号**: [REF-0004](../../REFERENCES.md#ref-0004)

## 概述

柱形会切场是离子推力器放电室的另一种主要磁场构型，与环形会切场相比具有不同的特点。

### 主要优点

1. **锥段磁场较强，柱段磁场较弱**
2. 极靴深入放电室内部，更有利于形成平行于阳极表面的磁场分布
3. 磁铁置于屏栅筒外，降低了对磁体材料工作温度的要求

### 不利之处

1. 磁柱数量有限，垂直于轴线的切面**磁场均匀性较差**
2. 放电室为屏栅筒与阳极筒**双层结构**，重量较大
3. 磁极深入放电室内部，存在离子刻蚀产生**多余物**的潜在隐患

## 几何参数设计

柱形会切场放电室的设计，目前并没有完整设计方法可借鉴，多采用**理论与经验公式相结合、仿真与试验相迭代**的技术途径。

### 放电室口径设计

放电室口径一般大于束口径，但不超过束口径的1.2倍。一般最大引出束流不超过栅极最大引出能力的60%，由半经验公式表述如下：

**I_max <= 0.6 * n * P_max * V_T^(3/2)**

其中：I_max 为最大引出束流，n 为栅极孔数，P_max 为最大导流系数，V_T 为总加速电压。

### 放电室几何构型设计

仿真计算表明，锥段-柱段型放电室具有最长原初电子约束长度，放电效率最高，并且随着束流口径的增加，该优势更加明显。因此，柱形会切场直流放电室一般建议采用**锥段-直段型**结构。

| 放电室几何构型 | 原初电子约束长度/m |
|---|---|
| 锥形放电室 | 23.4 |
| 柱形放电室 | 50.5 |
| 锥段-柱段放电室 | 58.9 |

> 参考文献：[1] Mahalingam S, Menart J A. Primary electron modeling in the discharge chamber of an ion engine[C]. AIAA 2002-4262

### 主阴极位置

一般阴极顶位置选择使形成的磁力线在阴极出口处沿径向发散，磁场强度沿轴线快速衰减，并减小中心轴处磁场对原初电子的约束；使得原初电子远离中心轴，以达到兼顾电离效率和束流均匀性的目的。

### 特征几何参数经验公式

在柱形会切场直流放电室设计初期，可以按照经验公式得到初步的特征几何参数，在此基础上通过试验加仿真的迭代方法完成优化方案的确定。

柱形会切场放电室特征几何参数定义如下：

- **D_b** — 束口直径
- **phi_1** — 上极靴内径，**phi_2** — 中间极靴内径，**phi_3** — 下极靴内径
- **D_d** — 柱段阳极筒内径，**H** — 锥段阳极筒高度，**D_2** — 锥段阳极筒小圆内径
- **L_d** — 放电室长度，**L_1** — 放电室柱段长度，**L_2** — 放电室锥段长度
- **L_3** — 上极靴长度，**L_4** — 下极靴长度，**L_5** — 阴极深入放电室长度

经验公式如下：

| 参数 | 经验公式 |
|---|---|
| D_d | D_h + 28 |
| L/D_d | 2/3 |
| L_1 = L_2 = H = D_2 | L/2 |
| D_1 | D - 14 |
| D_3 | D - 6 |
| D_4 | D_2 - 8 |
| L_3 | <= 0.1 * L_2 |
| L_4 | <= 0.1 * L_1 |
| L_5 | 0.3 * L_1 |

## 工作参数设计

### 阳极电流估算

阳极电流与束流的比例一般按以下经验公式进行计算：

**I_d approx (4~6.5) I_b**

其中，I_d 为阳极电流，I_b 为束流。一般而言，口径较小的推力器取上限，口径较大的推力器取下限。

例如，LIPS-200离子推力器为5.6，LIPS-300柱形离子推力器在不同工况下为4.0~5.0。

### 阳极电压估算

相较而言，柱形会切场放电室阳极电压低于发散场放电室，但高于环形会切场放电室，一般按 **35~38V** 估算。
