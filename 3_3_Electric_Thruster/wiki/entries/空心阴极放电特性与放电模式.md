# 空心阴极放电特性与放电模式

> **来源**: [第6课-空心阴极.pptx](../raw/第6课-空心阴极.pptx) | **编号**: [REF-0005](../REFERENCES.md#ref-0005)

## 放电特性测量

实验中，空心阴极对阳极板放电，且保持阳极板与触持极之间的距离不变。主要采集在固定的放电电流下，放电电压值及其振荡幅度随阴极流率（氙气流量）的变化。

空心阴极的放电性能随流率的变化呈现两种明显不同的模式。

## 亮斑状模式（Spot Mode）

**发生条件**：氙气流量比较大时（例如 **≥ 1.50 ml/min**）

**特征**：
- 放电电压值**较低**
- 放电电压的振荡幅度一直维持在**较低**的水平
- 放电羽流比较稀薄，仅在阴极小孔出口附近存在一明显的**亮斑**

## 羽毛状模式（Plume Mode）

**发生条件**：氙气流量较小时（例如 **≤ 1.10 ml/min**）

**特征**：
- 阴极推进剂流率的略微变化，都会使放电电压值**大幅度**地变化
- 放电电压的振荡幅度也随阴极流率**大幅度**地变化
- 阴、阳极间隙内的放电羽流整体上呈现出**羽毛状**，阴极流率越小，羽毛状的放电羽流在间隙内弥漫越强，并且逐渐向间隙外扩展
- 放电电压**较高**、电压振荡幅度**较大**

## 两种模式对比

| 特征 | 亮斑状模式 | 羽毛状模式 |
|------|-----------|-----------|
| 氙气流量 | 较大（≥ 1.50 ml/min） | 较小（≤ 1.10 ml/min） |
| 放电电压 | 较低 | 较高 |
| 电压振荡幅度 | 较小 | 较大 |
| 羽流形态 | 稀薄，小孔附近亮斑 | 羽毛状弥漫 |
| 稳定性 | 稳定 | 对流率变化敏感 |
