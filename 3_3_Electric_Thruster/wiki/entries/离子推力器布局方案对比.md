# 离子推力器布局方案对比

> **来源**: [第13课-电推进系统与卫星的集成.pptx](../raw/第13课-电推进系统与卫星的集成.pptx) | **编号**: [REF-0009](../REFERENCES.md#ref-0009)

## 布局方案概述

在通信卫星平台上安装离子推力器实现南北位保，有两种主要的布局方案。

## 方案一：南北板布局（Artemis方案）

参见 [[Artemis卫星离子推进系统]]。

**布局方式**：推力器安装在卫星南北板靠近背地面一侧，推力矢量在YOZ平面内，与Z轴约45°左右。

**特点**：
- 推力矢量必须经过卫星质心以避免扰动力矩
- 任何时候只需1台推力器工作
- 径向方向推力只引起小轨道扰动
- 推力矢量与南北轴方向为45°~60°，推力效率降低

## 方案二：东西面南北侧布局（替代方案）

**布局方式**：4台推力器分别安装在卫星东西面的南北两侧。

**工作方式**：南北位保时，南侧或北侧的两个推力器同时工作，东西方向的推力分量可以相互抵消。推力矢量不用过卫星质心，可以选择更合适的夹角。

| 对比维度 | 方案一（南北板布局） | 方案二（东西面布局） |
|----------|---------------------|----------------------|
| 同时工作推力器数 | 1台 | 2台（同侧） |
| 推力矢量约束 | 必须过质心 | 不必过质心 |
| 安装夹角 | 45°~60°（较大） | 可选择更小夹角 |
| 总冲需求 | 较大 | 较小 |
| 电源需求 | 较小（1台） | 较大（2台同时） |
| 可靠性 | 较高 | 较低（2台同时工作降低可靠性） |

## 方案二优缺点

**优点**：
- 夹角可以更小，总冲需求也更小
- 推力矢量不受质心约束，安装更灵活

**缺点**：
- 2台推力器同时工作，增加对电源的需求
- 同时工作会降低工作可靠性

## 实际应用总结

从现有应用案例来看：

| 特点 | Artemis | Boeing 702 |
|------|---------|------------|
| 推力方向调节 | 有推力调节装置，推力方向过质心 | 有独立指向机构控制推力方向 |
| 安装位置 | 南北板靠近背地面 | 背地面结构板，南北端各两台 |
| 功能定位 | 仅南北位置保持 | 兼多种功能（同步轨道转移、NSSK、EWSK、动量轮卸载） |
| 化学推进备份 | 保留化学推力器位保功能 | 保留化学推力器位保功能 |

**发展趋势**：
- 目前在应用电推进进行位保任务的同时，化学推力器位保功能并未取消，以增加卫星可靠性
- 随着离子推进技术成熟，可将化学推进取消而完全采用电推进完成通信卫星的位保及姿态控制任务
