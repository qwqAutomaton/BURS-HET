# 空心阴极寿命

> **来源**: [第6课-空心阴极.pptx](../raw/第6课-空心阴极.pptx) | **编号**: [REF-0005](../REFERENCES.md#ref-0005)

## 限制寿命的主要因素

1. **发射体源材料耗尽**：发射体中的活性物质（如钡、氧化钡）在高温下不断消耗，最终耗尽导致发射能力丧失。
2. **发射体有效发射表面被难挥发沉积物覆盖**：工作过程中产生的沉积物覆盖发射表面，阻碍电子发射。
3. **源材料活性分子不能到达发射体表面**：发射体内部通道堵塞或表面污染，阻止活性分子扩散迁移。
4. **触持极、顶板、加热器被溅射腐蚀损坏**：等离子体中的高能离子对结构部件的溅射腐蚀，最终导致结构失效。
5. **加热器损坏**：加热丝在高温下的熔断或氧化损坏。
6. **发射体化学中毒**：发射体材料与活性气体（主要是氧和水）发生化学反应，导致功函数升高、发射能力下降。

## 发射体化学中毒

### LaB₆ 和 Ba-W 电子发射能力与氧/水分压的关系

发射体中毒可表现为电子发射能力降低、工作温度升高、工作寿命缩短等。研究表明：除表面沉积和吸附污染外，引起钡钨发射体化学中毒的主要活性成分为**氧**和**水**。
