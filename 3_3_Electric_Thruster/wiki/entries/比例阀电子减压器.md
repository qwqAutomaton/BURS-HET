# 比例阀电子减压器

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 基本原理

利用比例阀构成的电子减压器工作过程与 [[Bang-Bang电子减压器]] 相似，但由于比例阀是一种"无级"调整设备，比例式电子减压器具有更优越的性能。目前比例阀技术状态不如通断式电磁阀成熟。

## 比例阀分类

比例阀分为以下三类：

| 类型 | 特点 |
|------|------|
| 电磁比例阀 | 通过电压调节阀口的开度，得到所需的压强或流量 |
| 磁致伸缩比例阀 | 利用磁致伸缩效应驱动阀芯 |
| 压电比例阀 | 利用压电效应驱动阀芯 |

上述类型的共同特点都是通过电压来调节阀口的开度，从而得到所需要的压强或流量。

## 压电比例阀

近年来，基于压电驱动的比例控制阀技术得到了长足的发展。压电比例控制阀具有以下特点：
- 低功耗
- 高精度
- 高分辨率
- 低电磁干扰

集推进剂高-低压隔离、压力调节与流量控制三种功能为一体的多功能阀在国外已经研制成功，并达到工程应用水平。例如，法国Alcatel Alenia公司研制了一种具有高压隔离（关断）功能的比例阀工程样机。

## 应用

比例阀电子减压器是 [[三代氙气贮供系统|第二代和第三代氙气贮供系统]] 中压力调节模块的核心部件。
