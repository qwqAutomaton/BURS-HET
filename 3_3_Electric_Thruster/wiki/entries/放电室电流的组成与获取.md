# 放电室电流的组成与获取

> **来源**: [第4课-离子推进_2.pptx](../raw/第4课-离子推进_2.pptx) | **编号**: [REF-0003](../REFERENCES.md#ref-0003)

## 放电室电流的组成

放电室中包含多种电流成分：

| 符号 | 名称 | 说明 |
|------|------|------|
| I_e | 阴极电子电流 | 空心阴极发射的电子电流 |
| I_k | 返回阴极的离子电流 | 离子返回到阴极形成的电流 |
| I_L | 阳极原初电子电流 | 原初电子到达阳极的电流 |
| I_a | 阳极二次电子电流 | 二次电子到达阳极的电流 |
| I_ia | 阳极离子电流 | 离子到达阳极的电流 |
| I_B | 离子束流电流 | 通过栅极引出的离子束流 |
| I_s | 屏栅极（离子）电流 | 离子打到屏栅极形成的电流 |

## 放电室电流平衡

放电室各电流之间存在平衡关系，分别在阴极处和阳极处满足电流守恒：

- **阴极处**：屏栅电势与阴极相等，发射电子电流与返回离子电流之间满足电流平衡。
- **阳极处**：原初电子电流、二次电子电流和离子电流之和满足阳极电流守恒。

## 放电室电流的获取方法

### (1) 实验测量

通过直接测量放电电压和放电电流来获取放电室电参数。实验方法可以直接获得推力器运行时的宏观电气参数。

### (2) 理论方法——零维模型

零维模型（Goebel, 2006）是一种简化的理论分析方法，通过对放电室进行整体能量和粒子平衡分析来估算放电室各电流成分。零维模型虽简单，但能够快速估算放电室的性能趋势。

零维模型的局限性：零维模型假设放电室中等离子体参数均匀分布，忽略了空间变化，因此对某些细节物理过程的描述不够精确。

### (3) 粒子模拟方法（PIC/MCC）

PIC/MCC（Particle-In-Cell / Monte Carlo Collision）方法可以对放电室进行更精确的数值仿真，追踪每个粒子的运动轨迹和碰撞过程。静磁场（永磁体）的计算涉及磁势 A_θ 和磁场强度 H_c，是PIC仿真的重要组成部分。粒子模拟方法能够给出放电室中粒子分布、电场和磁场的详细信息。
