# 离子推力器设计总体思路与参数选择

> **来源**: [第5课-离子推进_3.pptx](../../raw/第5课-离子推进_3.pptx) | **编号**: [REF-0004](../../REFERENCES.md#ref-0004)

## 设计总体思路

离子推力器设计过程包括以下主要环节：

1. **离子推力器参数选择** — 根据任务需求确定推力器基本参数
2. **放电室设计** — 包括环形会切磁场和柱形会切磁场两种方案
3. **栅极组件设计** — 几何参数、束流引出性能、安装设计
4. **离子推力器耦合匹配设计** — 放电室与阴极、栅极、中和器及电气参数的匹配

放电室的磁场设计分为两种主要方案：
- **环形会切磁场**：磁路结构简单，无极靴，适合大口径离子推力器
- **柱形会切磁场**：锥段磁场较强，极靴深入放电室内部

## 参数选择

根据任务需求，离子推力器参数选择遵循以下步骤：

1. 根据任务和推进剂类型，确定离子推力器**比冲**
2. 根据任务确定出适宜的推力器**推力**和**所需功率**
3. 根据推力、比冲，确定推力器所需的**束流大小**和**束流电压**
4. 确定适当的**束流密度**（参考束流密度极限值），由此得出推力器的**束径**
5. 根据上述参数，估算出**阳极电流**（为束流的4~7倍），再由电流平衡关系，估算出**主阴极的发射电流**
