# 离子推进系统的组成

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

离子推进系统按照功能可以分为四个组成部分：

## 1. 推力器（Thruster）

推力器是离子推进系统的核心部件，包括：
- 电离室
- 空心阴极
- 永久磁体
- 离子光学系统（栅极系统）
- 中和器

## 2. 推进剂供给系统（PFS）

推进剂供给系统按照发动机工作要求的压力和流量提供推进剂。详见 [[推进剂储供系统XFS概述]]。

## 3. 电源处理单元（PPU）

电源处理单元为发动机提供电能，将航天器供电母线的电能转换为推力器各部件所需的各种电气条件。详见 [[电源处理单元PPU概述]]。

## 4. 数字控制与接口单元（DCIU）

数字控制与接口单元接收来自地面的控制信号、PPU、PFS、电离室的反馈信号，然后进行综合判断，发出控制PPU、PFS、电离室的信号。详见 [[数字控制与接口单元DCIU概述]]。
