# BepiColombo水星探测器

> **来源**: [第3课-离子推进_1.pptx](../raw/第3课-离子推进_1.pptx) | **编号**: [REF-0002](../REFERENCES.md#ref-0002)

## 概述

BepiColombo（贝皮-科伦布）是欧洲航天局（ESA）和日本宇宙开发研究机构（JAXA）联合研制的水星探测器，是欧洲迄今开展的难度最大的空间探测任务，目前估计需耗资近20亿美元。探测器于2018年10月20日发射，预计2025年12月5日进入水星轨道。

## 组成

"贝皮·科伦布"由三部分组成：

| 组成部分 | 研制方 | 质量 | 说明 |
|----------|--------|------|------|
| 水星行星轨道器（MPO） | 欧洲 | 1147 kg | 主探测器，装有11台科学探测仪器，功耗174 W |
| 水星磁层轨道器（MMO） | 日本 | 275 kg | 次探测器，装有5台科学探测仪器，功耗90 W |
| 水星转移模块（MTM） | 欧洲 | — | 负责探测器的星际转移 |

## 水星转移模块（MTM）

MTM 由太阳能电推进舱（SEPM）和化学推进舱（CPM）组成。

### 太阳能电推进舱（SEPM）

| 参数 | 数值 |
|------|------|
| 太阳电池翼面积 | 33 平方米 |
| 离子推力器 | 4台 T6 氙离子推力器 |
| 每台推力 | 170 mN |
| 净质量 | 365 kg |
| 氙气（MPO） | 230 kg |
| 氙气（MMO） | 238 kg |

### 化学推进舱（CPM）

| 参数 | 数值 |
|------|------|
| 推进剂类型 | 双组元推进剂 |
| 姿态控制推力器 | 8台 × 20 N |
| 轨道射入推力器 | 1台 × 4000 N |
| 净质量 | 71 kg |
| 燃料（MPO） | 156 kg |
| 燃料（MMO） | 334 kg |
