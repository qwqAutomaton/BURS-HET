# GOCE卫星与T5离子推力器

> **来源**: [第13课-电推进系统与卫星的集成.pptx](../raw/第13课-电推进系统与卫星的集成.pptx) | **编号**: [REF-0009](../REFERENCES.md#ref-0009)

## GOCE卫星概述

GOCE（Gravity Field and Steady-State Ocean Circulation Explorer）卫星是欧空局（ESA）于2009年3月17日发射的地球重力场科学测量卫星。能够测量地球重力场和稳态海洋环流，并提供高精度和高分辨率的地球重力场和大地水准面模型。

### 卫星构型

为最大程度减少空间环境扰动导致卫星姿态的变化，GOCE设计为严格对称的八角形棱柱体：
- 总长度：4 m
- 横截面积：0.8 m²
- 总质量：770 kg

### 测量模式

GOCE卫星采用卫星跟踪卫星高低模式（SST-HL）和卫星重力梯度模式（SGG）的结合，即除基于高轨道的GPS和GLONASS卫星对低轨道的GOCE进行精密跟踪定位外，同时利用定位于卫星质心处的重力梯度仪高精度测量卫星轨道高度处引力位的二阶导数。

## 非保守力补偿

GOCE卫星的飞行轨道为近似圆形的太阳同步轨道，高度约为250 km，这导致卫星受到的大气阻尼在一个绕轨飞行内有很大的变化范围。

GOCE卫星采用了**非保守力补偿技术**：
1. 利用重力梯度仪测量由非保守力引起的卫星质心的线加速度与卫星平台的角加速度
2. 结合卫星平台姿态测量数据
3. 通过离子推力器补偿卫星受到的非保守力

由于卫星重力梯度观测值受非保守力的影响较小，因此进一步提高了地球重力场恢复的精度和空间解析度。

## 重力梯度仪

重力梯度仪是GOCE上的核心部件之一，采用重力梯度测量方式，即利用星载重力梯度仪直接测定卫星在轨处引力位二阶导数张量，以此来确定地球重力场。GOCE上装载的梯度仪采用差分加速度测量原理。

## T5离子推力器

### 研发背景

英国对离子电推进的研究开始于1967年，主要是Kaufman型离子推力器，研发离子推力器主要以通信卫星的南北位保和飞行IPA为应用目标。

英国QinetiQ公司针对重力测量卫星大气阻尼补偿的应用需求，从上世纪90年代末开始，在QinetiQ T5推力器基础上发展了推力可连续精细调节的离子推力器。

### 主要性能特征

| 参数 | 数值 |
|------|------|
| 比冲 | 3000 s（最佳工作点3500 s） |
| 推力调节范围 | 0.6 ~ 20.6 mN |
| 稳态推力矢量稳定度 | ±0.02° |
| 推力噪声 | 小 |

### T5推力器设计

T5离子推力器设计为发散场，磁场源为6个螺线管电磁铁。

| 组件 | 设计 |
|------|------|
| 栅极口径 | 10 cm |
| 离子光学系统 | 屏栅 + 加速栅（双栅结构） |
| 加速栅材料 | 抗溅射的石墨材料（C/C复合材料） |
| 屏栅材料 | 冲压和热处理的钼材料 |
| 空心阴极 | 3 mm 钡钨阴极 |

研制初期栅极系统为钼材质的三栅极结构，后针对GOCE卫星应用，研制了C/C材料加速栅的双栅结构。

## 系统配置

GOCE卫星总共搭载了两套IPA（Ion Propulsion Assembly）作为主备份，分别为主系统A和备份系统B。在整个任务运行过程中，除试车阶段启动B系统外，其余工作时间只启动A系统。

总系统包括：
- 2台T5离子推力器（ITA）
- 2套控制系统（IPCU）
- 2套氙气比例供给系统（PXFA）
- 1个氙气罐（XST）

## IPCU模块

IPCU模块集成了电源处理单元和控制单元，主要功能是向ITA和PXFA提供各种要求的电源、实现与卫星通讯和数据接口、执行推力调节控制等。为保证实现推力的快速调节，IPA设计的工作频率为100 Hz。

## PXFA模块

PXFA模块由荷兰Bradford研制，采用主备份设计，两单元气路之间的切换由电磁阀完成。两单元都采用比例流量控制方式为ITA准确地提供三路推进剂流率。

推进剂比例流量调节组件由压力控制和流量控制两部分组成。主流量的调节由一个流量调节阀和热测量原理的流量传感器组合的子系统完成，并采用闭环控制调节，实现了在0.01 ~ 0.63 mg/s范围内的流量调节。

流量需求指令采集频率为10 Hz，执行器控制指令为100 Hz。
