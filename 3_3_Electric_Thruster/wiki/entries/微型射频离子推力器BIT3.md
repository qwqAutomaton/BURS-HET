# 微型射频离子推力器BIT3

> **来源**: [第3课-离子推进_1.pptx](../raw/第3课-离子推进_1.pptx) | **编号**: [REF-0002](../REFERENCES.md#ref-0002)

## 概述

BIT3 是美国 Busek 公司研制的微型射频离子推力器，采用碘推进剂。碘推进剂的优势在于降低推进剂存贮难度，缩小系统体积。

## 月球冰立方星应用

月球冰立方星（Lunar IceCube）是一颗 6U 立方星，于2022年11月16日发射，执行绕月探测任务。该卫星采用 BIT3 微型离子推进系统。

### BIT3 性能参数

| 参数 | 数值 |
|------|------|
| 推力范围 | 0.65 ~ 1.15 mN |
| 比冲 | 1200 ~ 2100 s |
| 推进系统总功耗 | 约 75 W |

## 技术特点

- 碘工质推进剂，便于存贮
- 微型化设计，适用于立方星等小型航天器
- 射频电离方式
