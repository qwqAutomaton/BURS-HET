# Bang-Bang电子减压器

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 基本工作原理

Bang-Bang电子减压器是 [[推进剂储供系统XFS概述|推进剂储供系统]] 压力调节模块中的一种核心减压方案。其减压功能的实现过程如下：在数字控制与接口单元（DCIU）的控制下，通过压力传感器来监测缓冲气瓶的压力，将采样结果与内部程序的设定值相比较，根据比较的结果输出阀门驱动指令，通过控制Bang-Bang电磁阀的开关，将压力控制在要求范围内。

## 控制特点

Bang-Bang控制鲁棒性好、可靠性高，但是压力控制波形呈现"锯齿状"，压力调节精度低，其典型值为 **±3%**。

## 完整控制周期

以深空1号（DS1）为例，Bang-Bang压力控制的工作周期如下：

当缓冲罐中的压力 P2 下降到 P2min 时：
1. 将上游电磁阀打开给中间小容腔充气，经过时间 t1 后关闭
2. 然后两个电磁阀同时处于关闭状态且经过时间 t2
3. 最后下游电磁阀打开将中间小容腔中的氙气释放到下游缓冲罐中，经过时间 t3 后关闭
4. 完成一个完整的Bang-Bang控制周期

## 电磁阀结构

Bang-Bang电磁阀由两个电磁阀（V1和V2）串联组合而成，两个电磁阀中间有一个固定的小气容。

## 工作模式

根据系统压力，Bang-Bang电磁阀有两种工作模式：

### 分步开关工作模式

当低压压力传感器检测到缓冲气瓶的输出压力低于设定的工作压力时，由DCIU发出指令使压力控制电磁阀按以下方式工作：

1. 上游电磁阀打开
2. 气瓶中的高压氙气开始向压力控制电磁阀中间的小气容充气
3. 经过t1秒后，上游电磁阀关闭
4. 经过t2秒后，下游电磁阀打开，小气容中的氙气开始流入缓冲气瓶中，缓冲气瓶压力逐渐升高
5. t3秒后，下游电磁阀关闭，一个工作周期结束

### 同步开关工作模式

当低压压力传感器检测到缓冲气瓶的输出压力低于设定的工作压力时，由DCIU发出指令使Bang-Bang电磁阀上阀和下阀同时打开，直至缓冲气瓶压力增至设定的压力上限值，关闭压力控制电磁阀。

## 工作模式选择

两种工作方式各有千秋。从系统角度分析，**以分步开关方式为主**，在系统压力较低时（如 2MPa 以下时），采用同步开关工作方式。
