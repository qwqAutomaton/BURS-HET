# 电推进系统概述

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 推进系统的功能

推进系统为航天器提供动力。推进系统可分为冷气推进、化学推进、电推进等类型。

## 电推进的特点

与化学推进相比，电推进系统多了电源处理单元（PPU）和数字控制与接口单元（DCIU）两个关键部件。

电推进的主要特点：

1. **比冲高** -- 相比化学推进，电推进具有显著更高的比冲，推进剂利用效率更高
2. **推力小** -- 电推进产生的推力远小于化学推进，适用于在轨推进任务
3. **属外能系统** -- 电推进需要外部电能输入来维持工作，与化学推进（利用推进剂自身化学能）不同

## 电推进系统基本组成

电推进系统基本组成示意图中，除推力器外，还包括供电母线、电源处理单元（PPU）、数字控制与接口单元（DCIU）和推进剂储供系统（XFS/PFS）。

## 涉及的学科领域

离子推进系统各组成部分涉及多学科知识：

| 组成部分 | 涉及学科 |
|----------|----------|
| 推力器 | 电磁学、等离子体物理、机械设计、传热学 |
| 储供系统 | 流体力学、机械设计、材料力学、工程热力学 |
| 电源处理单元 | 电路、电力电子技术 |
| 数字控制与接口单元 | 自控原理、微机原理 |
