# 数字控制与接口单元DCIU概述

> **来源**: [第12课-电推进系统(储供_PPU_DCIU).pptx](../raw/第12课-电推进系统%28储供_PPU_DCIU%29.pptx) | **编号**: [REF-0008](../REFERENCES.md#ref-0008)

## 基本功能

数字控制与接口单元（DCIU，Digital Control and Interface Unit）为推进系统提供控制，并按一定的程序使离子推力器完成以下完整工作流程：

- 启动
- 点火
- 放电
- 加电压
- 引出束流
- 稳态运行
- 关机

DCIU同时监控推进系统的工作和状态，完成离子推进系统的遥控/遥测数据与卫星数管分系统的通讯。

## NSTAR DCIU总体参数

NSTAR数字控制接口单元（DCIU）控制着整个NSTAR系统，其基本参数如下：

| 参数 | 数值 |
|------|------|
| 总重 | 2.47 kg |
| 消耗功率 | 7 W |
| 电路板数量 | 3 块 |

## 三块电路板

NSTAR DCIU由以下三块电路板组成：

1. **中央处理器**：系统的控制核心，详见 [[DCIU中央处理器]]
2. **阀驱动板**：驱动XFS中的电磁阀和闭锁阀，详见 [[DCIU阀驱动板]]
3. **数据采集板**：采集传感器信号，详见 [[DCIU数据采集系统]]

此外，DCIU还通过 [[DCIU与PPU接口卡|PPU接口卡]] 与PPU进行通信。
