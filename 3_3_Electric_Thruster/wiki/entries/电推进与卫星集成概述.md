# 电推进与卫星集成概述

> **来源**: [第13课-电推进系统与卫星的集成.pptx](../raw/第13课-电推进系统与卫星的集成.pptx) | **编号**: [REF-0009](../REFERENCES.md#ref-0009)

## 背景：通信卫星的轨道保持需求

通信卫星是用作无线电通信中继站的人造地球卫星，通过转发无线电信号，实现卫星通信地球站之间或地球站与航天器之间的通信。通信卫星一般采用地球静止轨道（GEO）。

在宇宙空间中，卫星会受到各种各样的摄动作用：
- 太阳、月球的引力作用
- 地球因其椭圆形状而对卫星产生的作用
- 太阳对卫星的辐射力作用

这些作用会使卫星渐渐偏离其原本的工作轨道（地球静止轨道），对通信卫星的工作造成极大影响。

## 南北位置保持的重要性

由于太阳-月球的引力作用，同步卫星的轨道面相对于赤道会产生纬度的变化，变化量为 0.75°/年 ~ 0.95°/年，相当于轨道速度变化率 (40~51 m/s)/年。若不修正，卫星的天线波束将在地球表面上画出一个拉长的"8"字形，这对通信卫星而言是不可接受的。

通信卫星需要采取措施保持其轨道位置，南北位保（南北位置保持）是其中重要一环。地球静止轨道平台卫星的服役期限一般在 10~20 年，在整个寿命期间卫星轨道南北位置保持精度要求为 0.01°~0.05°。

## 电推进引入南北位保的优势

南北位保的具体做法是在卫星特定位置安装推力装置，在特定轨道位置按一定规律点火，以抵消摄动。

南北位保是一种很费冲量的控制，因需改变轨道平面，每年约需提供 50 m/s 的速度增量，差不多是东西位置保持的 10 倍。

随着通信卫星寿命要求越来越长，为使卫星在静止轨道上保持定点位置，所需的推进剂越来越多，大大压缩了有效载荷的搭载。离子推进具有比冲高、消耗工质少等优点，可以大大延长卫星的工作寿命，提高卫星的有效载荷。

## 电推进系统与卫星集成的核心问题

将电推进系统应用于通信卫星平台时，需要解决以下集成问题：

1. 离子推进系统应该安装在什么位置？
2. 推力器保持什么样的角度？
3. 安装几台推力器才能实现位保功能？
4. 离子推进系统的安装对卫星平台有什么影响？

这些问题的回答需要综合考虑以下因素：

1. **推力器布局与安装原则**
2. **应用方式与控制策略**
3. **对电源系统的影响**
4. **对热控系统的影响**
5. **羽流及电磁兼容影响**

## 集成需考虑的因素概览

| 因素 | 核心关注点 |
|------|-----------|
| 推力器布局与安装 | 不改变原平台、减小耦合、干扰力矩小、避免羽流污染、降低电磁干扰 |
| 应用方式与控制策略 | 小推力带来的长时间位保、频繁开关机、遥测遥控需求、故障诊断 |
| 对电源系统的影响 | 大功率需求、太阳翼供电能力、启动浪涌电流 |
| 对热控系统的影响 | PPU发热、推力器热辐射、氙气贮存温控 |
| 羽流及电磁兼容 | 溅射腐蚀、沉积污染、静电环境改变、电磁信号干扰 |
